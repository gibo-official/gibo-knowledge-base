## Chapter 1: Pre-Installation Planning

### 1.1 Site Assessment Checklist

| Assessment Item | Key Considerations |
|----------------|-------------------|
| Water Supply | Pressure range, hot/cold water availability, pipe diameter |
| Power Supply | AC outlet location, battery access, AC/DC dual-power options |
| Drainage | Floor drain position, waste pipe diameter, slope requirements |
| Wall/Counter Structure | Material, thickness, mounting space |

### 1.2 Power Supply Preparation

| Power Method | Pre-Wiring Requirements | Suitable Scenarios |
|-------------|------------------------|-------------------|
| AC 110–240V | Waterproof outlet within 1.5m, dedicated circuit recommended | High-traffic commercial venues |
| DC 6V (4×AA) | Battery box accessible for replacement | Low-to-medium traffic, retrofit projects |
| AC/DC Dual Power | Both AC outlet and battery box | Critical applications requiring redundancy |
| Hydroelectric Self-Power | No external power needed | Water-saving retrofit projects |

### 1.3 Water Supply Preparation

| Requirement | Specification |
|------------|--------------|
| Water Pressure | 0.05–0.7 MPa (dynamic) |
| Pipe Diameter | DN15 (1/2") standard; DN20 (3/4") for high-flow applications |
| Water Quality | Install Y-strainer filter upstream; hardness ≤450 mg/L recommended |
| Hot/Cold Marking | Clearly labeled supply lines |

## Chapter 2: Category-Specific Installation

### 2.1 Sensor Basin Faucet

| Installation Step | Key Points |
|------------------|-----------|
| Mounting Hole | Standard 35mm diameter; verify counter thickness |
| Sensor Module | Position sensing window facing user approach direction |
| Control Box | Secure under-counter; ensure ventilation and drip protection |
| Water Connection | Use flexible braided hoses; avoid stress on connections |
| Seal Check | Test all connections at 0.8 MPa for 5 minutes |

### 2.2 Sensor Kitchen Faucet

| Installation Step | Key Points |
|------------------|-----------|
| Mounting | Single-hole or three-hole configuration; verify sink clearance |
| Pull-Out Hose | Ensure smooth retraction; check weight position |
| Spray Head | Verify mode switching function |
| Hot/Cold Supply | Connect per markings; verify anti-scald setting |

### 2.3 Sensor Flush Valve (Urinal)

| Installation Step | Key Points |
|------------------|-----------|
| Inlet Pipe | DN15 connection; verify flush water volume setting |
| Sensor Position | Mount at recommended height; avoid false triggers from passing traffic |
| Flush Pipe | Ensure proper slope; no sags or kinks |
| Water Hammer | Install water hammer arrestor if pipe runs exceed 10m |

### 2.4 Sensor Flush Valve (WC)

| Installation Step | Key Points |
|------------------|-----------|
| Mounting Height | Per product specifications; typically 800–900mm from floor |
| Flush Volume | Set per local water conservation codes |
| Dual-Flush | Full flush 6L, half flush 3L (verify local requirements) |
| Backflow Prevention | Install check valve per plumbing code |

### 2.5 Sensor Soap Dispenser

| Installation Step | Key Points |
|------------------|-----------|
| Counter Mounting | 25–28mm mounting hole; near basin but outside splash zone |
| Soap Reservoir | Under-counter, accessible for refill; use manufacturer-recommended soap |
| Tube Routing | Avoid kinks; minimum bend radius 50mm |

## Chapter 4: Commissioning and Acceptance

### 4.1 Functional Test Checklist

- [ ] Power-on self-test passes (LED indicator normal)
- [ ] Sensing distance meets specifications (typically 5–30 cm)
- [ ] Response time ≤0.5 seconds
- [ ] Water flow stable without sputtering
- [ ] Hot/cold mixing functional (if applicable)
- [ ] Auto shut-off after user departure (≤2 seconds)
- [ ] Timeout protection active (typically 60 seconds)
- [ ] No false triggers from ambient light or reflections

### 4.2 Acceptance Criteria

| Test Item | Acceptance Standard |
|-----------|-------------------|
| Watertightness | No leakage at any connection after 30-minute static test |
| Sensing Consistency | Trigger rate ≥99% over 100 test activations |
| Flow Rate | Within ±10% of rated specification |
| Noise Level | ≤55 dB(A) at 0.3 MPa (per EN 817) |
| Installation Stability | No movement or loosening under normal use |

## Chapter 6: Maintenance

### 6.1 Routine Maintenance Schedule

| Frequency | Task |
|-----------|------|
| Daily | Visual inspection; clean sensing window |
| Weekly | Check for leaks; verify auto shut-off |
| Monthly | Clean filter screen; test all functions |
| Quarterly | Check battery voltage; inspect hoses |
| Annually | Full functional test; solenoid valve performance check |

### 6.2 Common Troubleshooting

| Issue | Possible Cause | Solution |
|-------|---------------|----------|
| No water output | Power loss / solenoid valve failure | Check power; replace solenoid valve |
| Continuous flow | Debris in valve / sensor obstruction | Clean valve seat; check sensing window |
| False triggers | Strong ambient light / reflective surface | Adjust sensing angle; apply anti-reflective film |
| Reduced sensing range | Low battery / dirty sensing window | Replace batteries; clean window |
| Water hammer noise | No arrestor installed / high pressure | Install water hammer arrestor; add pressure reducer |
