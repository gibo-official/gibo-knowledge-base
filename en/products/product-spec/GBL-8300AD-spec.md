## I. Product Introduction

The GBL-8300AD is a concealed squat-toilet Sensor Flush Valve launched by GIBO for high-density-traffic public restrooms. Its core differentiator is the **Triangulation Ranging** sensing technology it adopts. Unlike ordinary infrared diffuse-reflection sensing, a triangulation sensor can precisely measure the actual distance of the target object and activates the flush logic only when the user is detected within the preset "usage zone."

This feature is especially critical in places such as high-speed rail stations, EMU stations, and airport terminals — the squat stalls in these places are usually narrow with frequent user in-and-out. Traditional infrared sensing easily causes false flushing from non-usage actions like stall-door opening/closing or cleaning staff passing by, wasting water and potentially disturbing the user. The GBL-8300AD effectively eliminates such false triggers through precise zone determination, and the detection zone can also be flexibly set via remote control.

The whole unit adopts a pre-embedded-box concealed structure; the stainless steel panel is marked with INLET/OUTLET direction indicators, and internally integrates a brass solenoid valve and a slow-close spring assembly, making it compact and reliable.

## II. Features

### 2.1 Triangulation Ranging Sensing Technology

Computes the distance of the reflector through the geometric relationship between the infrared emitter and the line-array receiver, controlling the distance error for reflectors of all colors and materials within 5%. This is a qualitative leap over the traditional infrared solution, whose error for different colors/materials can exceed 90cm.

### 2.2 Intelligent Zone Determination

A built-in algorithm distinguishes between two behavior patterns: "brief pass-by" and "continuous stay." Only when the target stays within the effective zone longer than the set time (default approx. 2 seconds) is it marked as "in use," completely eliminating false triggers caused by door-gap light changes and people quickly passing by.

### 2.3 Slow-close Shock Absorption

The valve closes in stages, slowly released, with the internal spring damping chamber absorbing water-hammer energy; peak pressure ≤0.2MPa, protecting the pipeline system and reducing noise.

### 2.4 Two-stage Smart Flush

An optional two-stage mode of front low-flow wall-rinsing + rear main flush; flush volume and time are both remotely adjustable. Three water-saving levels are supported: Level 1 (≤0.5L), Level 2 (≤1.5L), Level 3 (≤2.5L).

### 2.5 AC/DC Dual Power Supply

AC100–240V power adapter and DC6V battery operate in parallel. On mains power loss, it automatically switches to battery power, ensuring uninterrupted service.

### 2.6 LITEON Ultra-low Power

Standby power consumption ≤10μA (national standard 33μA), extending battery life by 50%. Battery mode can run for longer.

### 2.7 Pre-embedded-box Concealed Design

A full stainless steel pre-embedded box with INLET/OUTLET markings makes installation clear and standardized. From the wall, only a square panel is exposed; pipelines, valve body, and control module are all hidden inside the wall, clean and tidy.

### Selling Point 1: Triangulation Ranging Precise Positioning — Activates Only When the User Is Truly "Present"

Adopts Triangulation Ranging sensing technology to replace the traditional infrared diffuse-reflection solution, precisely measuring target distance (error <5%), able to distinguish between "passing by" and "using." In narrow stalls it greatly reduces the false-flush rate, with significant water-saving effect.

### Selling Point 2: Adjustable Detection Zone — Set On-site via Remote Control, Adapts to Different Stall Sizes

Via remote control, the distance range and angle threshold of the effective detection zone can be precisely set. Whether the stall depth is 80cm or 150cm, it can be adjusted to the best matching position, with no need to return to the factory for reprogramming.

### Selling Point 3: 500,000+ Cycles Ultra-long Life — Withstands Hundreds of Daily High-frequency Uses

GIBO's self-developed brass solenoid valve + slow-close spring combination has a service life of 0.5–1.0 million cycles, far exceeding the national standard requirement of 200,000 cycles. Especially suited to long-term stable operation in high-daily-traffic places such as EMU stations.

## V. Installation Instructions

### 5.1 Before Installation

- Select the corresponding pre-embedded box model (E/F) according to top-inlet or rear-inlet method; wall thickness ≥120mm
- The pre-embedded box is marked with INLET/OUTLET direction; pay attention to correct inlet/outlet direction during installation
- Connect the power line to the terminal; place the adapter in a dry, ventilated location

### 5.2 Precautions

- Always shut off the water path and power before installation and maintenance
- The triangulation ranging window must be kept clean (dust coverage affects accuracy); recommend inspection and wiping every quarter
- For high-frequency-use locations, recommend checking the solenoid valve filter every six months
- If missed or false triggering occurs, prioritize adjusting zone parameters via remote control
- A blinking indicator prompts battery replacement when under-voltage

### 5.3 Installation Steps

1. Select the pre-embedded box (E/F) and install it per the top-inlet / rear-inlet method, confirming wall thickness ≥120mm
2. Confirm the pre-embedded box INLET/OUTLET direction; pay attention to correct inlet/outlet direction during installation
3. Connect the power line to the reserved terminal; place the AC adapter in a dry, ventilated location
4. After powering on, use the remote control to precisely set the detection zone boundary — recommend testing trigger conditions at different positions inside the stall to ensure no trigger when passing the stall door and normal trigger when using the squat position

### 5.4 Power-on Self-check

After powering on, use the remote control to precisely set the detection zone boundary; recommend testing trigger conditions at different positions inside the stall, ensuring no trigger when passing the stall door and normal trigger when using the squat position, then enter standby.

### 5.5 Maintenance

- The triangulation ranging window must be kept clean (dust coverage affects accuracy); recommend inspection and wiping every quarter
- For high-frequency-use locations, recommend checking the solenoid valve filter every six months
- If missed or false triggering occurs, prioritize adjusting zone parameters via remote control
- A blinking indicator prompts battery replacement when under-voltage

## VI. Application Scenarios

### 6.1 High-speed Rail Station / EMU Station Restrooms

Triangulation ranging precise zone determination prevents false triggers from door opening/closing in narrow stalls (usually <1.5m²). High daily traffic and flush frequency; the 500,000-cycle life ensures long-term stable operation.

### 6.2 Airport Terminal / Transport Hub

Huge international passenger flow; false flushing wastes water and creates a bad experience impression. Precise ranging technology makes flush accuracy >99% while significantly saving water costs.

### 6.3 Highway Service Area

Service-area passenger flow fluctuates greatly; triangulation ranging is unaffected by ambient light changes, performing consistently day and night. The slow-close structure protects water pipelines in remote areas from water-hammer shock.

### 6.4 Large Exhibition Center / Stadium

During events/exhibitions, short-term passenger flow is extremely dense; high-frequency continuous flushing tests product reliability. The dual-power design ensures uninterrupted service even during mains fluctuations.
