# GIBO 产品营销文案风格规范

**文档版本**：V1.0

## 一、文档定位与适用边界

### 1.1 这是什么

一套 **技术型 B2B 营销文案 / 解决方案式产品手册**，本质是**销售赋能文档**——供销售工程师、设计院、工程商、经销商用于说服甲方、投标、培训，而非面向终端消费者的广告。

### 1.2 适合用在哪里 ✅

| 场景 | 适配度 | 说明 |
|------|:----:|------|
| 工程投标 / 技术标书附件 | ★★★★★ | 参数全、有执行标准、有 ROI，评标专家最爱 |
| 设计院 / 甲方选型手册 | ★★★★★ | 技术定位表 + 规格参数表，方便入图集 |
| 经销商 / 代理商培训 | ★★★★☆ | 卖点"金句+效益"可直接当话术 |
| 官网产品详情页内容源 | ★★★★☆ | 需拆图、配产品图，但骨架现成 |
| 展会样本册 / 画册文字 | ★★★★☆ | 配视觉即可成册 |
| 销售工具书 / 投标话术库 | ★★★★★ | 六段式天然适合做"一页纸卖点卡" |

### 1.3 不适合用在哪里 ❌

- C 端消费者广告 / 小红书 / 抖音脚本（太长太技术）
- 电商详情页（京东/天猫，需更多图、更短句、更情绪化）
- 海外社媒 / 英文站（需翻译+本地化，且欧美买家更信第三方认证）
- 技术白皮书 / 论文（营销语气重，不够学术中立）

## 二、六段式标准结构（强制）

每篇文案必须包含以下六个一级章节 + 附录，顺序固定：

```
一、产品介绍
二、功能特点
三、核心卖点
四、规格性能参数
五、安装说明
六、应用场景
附录（A.核心技术索引 / B.产品认证与资质 / C.联系方式）
```

### 2.1 一、产品介绍（单段叙述 + 3 个子节）

**开头为一段连贯叙述，不得拆成 1.1~1.4 子标题。** 必须在一口气内把四件事讲清楚：这款产品是干什么的 → 用在哪些地方 → 靠什么技术站稳 → 对用户到底值什么。四者糅合为 2~4 段自然衔接的散文，不列小标题、不打 bullet。

| 子节 | 要求 |
|------|------|
| （开头叙述） | 无子标题，糅合"功能→场景→技术→价值"四要素；首次出现产品全称加粗 |
| 1.1 技术定位 | **必须是一张对比表**（代际/原理/模式/功耗/GIBO代表产品），把本品放在技术演进坐标系中 |
| 1.2 关键指标 | 3~6 条 `-` bullet 列最硬的几个数字（精度/功耗/寿命/防护/流量…），标题曾用"几个关键数字"，统一改名"关键指标" |
| （无 1.3） | **「关于洁博利」品牌背书不放在正文**，统一移入文末附录 B. 认证与资质 开头段 |

### 2.2 二、功能特点（建议 5-7 条）

- 每条 `### 2.x 功能名 —— 副标题`（破折号分隔）
- 技术原理用 bullet 拆解（探测单元/处理单元/主控单元…）
- 关键性能用**内联表格**呈现（测试项目/条件/结果）

### 2.3 三、核心卖点（固定 3 条）

每条卖点固定套路：

```
### 卖点N：短标题 —— 一句价值主张

> **金句引用**（加粗，点出客户痛点或理念）

[原理/机制说明 1-2 段]

**实际效益**：[量化 ROI —— 省多少水/工时/成本，配具体测算场景]
```

- "实际效益"必须**量化**（数字+单位+测算前提），禁止空话
- 3 条卖点应覆盖：技术差异化 / 成本(功耗/维护) 或 节水体验 / 可靠性或工程便利 三个角度；挑最硬的三点，不凑数

### 2.4 四、规格性能参数（表格化，分 5-7 组）

- 电气参数 / 水路参数 / 感应参数 / 工作环境 / 机械与防护 / 寿命与可靠性 / 执行标准
- 全部用 Markdown 表格，参数项左、规格右
- 执行标准必须列出 CJ/T 194-2014 等真实标准编号

### 2.5 五、安装说明

- 5.1 安装前检查（bullet 清单）
- 5.2 安装注意事项（`⚠️` 标记关键警告）
- 5.3 安装步骤（编号有序列表）
- 5.4 上电自检说明
- 5.5 电池更换（如适用）

### 2.6 六、应用场景

- 按行业切分（商场/写字楼/交通枢纽/酒店/医院/学校…），每场景含：
  - **典型需求**：该行业客户的痛点
  - **[产品] 方案优势**：本品如何逐一破解（对应前文卖点）
- 终端成品写"应用场景"；**组件级产品改写为"适用整机与集成方案"**（见 §四）

### 2.7 附录（固定三段）

- A. GIBO 核心技术索引表（编号/技术名称/在本品应用）—— 编号引用 `zh/technology/core-technologies.md` 的 18 项索引
- B. 认证与资质：**开头第一段为「关于洁博利」品牌背书**（20 年 / 参编（起草单位）GB/T 41863-2022 及 T/XMBK 002-2024 / 国家高新技术企业 / 专精特新 / 沸腾质量金奖等），随后列认证实号（CE/CUPC/NSF/WRAS/WaterMark/ISO 三体系）
- C. 联系方式（公司/中英文官网/热线/邮箱/地址）

## 三、写作规范（强制约定）

1. **核心技术引用**：功能/卖点中提及 GIBO 技术时，标注`（核心技术#N）`，并在附录 A 建索引表。
2. **量化效益**：所有"实际效益"必须有数字；测算基准（如"50 个洗手位"）全文统一，便于横向对比。
3. **金句引用**：核心卖点用 `>` 引用块承载痛点金句，加粗。
4. **表格优先**：参数、对比、测试结果一律表格，不用散文罗列。
5. **首屏定位**：文档顶部 `>` 引用块写明版本/日期/产品定位一句话。
6. **emoji 用法**：亮点速览用 emoji 作视觉锚点（🔋💧🛡️ 等），正文不用 emoji。
7. **免责声明**：文末固定免责声明 + 版权，注明源规格书版次与日期。

## 四、组件级产品的特殊处理

当产品是**部件/模块**（如控制盒、感应模块）而非终端成品时：

- 第六章改标题为 **「适用整机与集成方案」**，内容写配套整机、ODM 集成价值
- 明确标注"配合 XX 整机/模块"的协同关系，不把整机指标据为己有
- 安装说明侧重"与整机配合要点"，可较简
- 品牌实力、核心技术索引仍保留（体现平台能力）

## 六、雷区 / 禁忌

1. ❌ **循环表述**：如"耐潮湿：适应高湿环境（详见…参数）"——等于没说。源规格书若有笔误（如 9168 耐潮湿条目录入成低温试验），须核实修正并标注，不可照搬。
2. ❌ **编造参数**：规格书没有的数据不得凭空生成；确需补充的标准测试条件（如潮湿试验 40±2℃/95%RH/48h）须注明依据并打标。
3. ❌ **把整机指标据为组件所有**：组件文案中标注"配合龙头感应模块"的指标，不可写成自身独立指标。
4. ❌ **卖点空话**：禁止"质量优良""性能卓越"类无数字表述。
5. ❌ **核心技术编号引用错**：`#N` 必须与 `core-technologies.md` 索引一致。
