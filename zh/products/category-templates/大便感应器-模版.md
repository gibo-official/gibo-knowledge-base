## 一、产品介绍

大便感应器管的是公共厕所里最脏、最不能出错的那件事：人一站起来，蹲便或坐便自动冲干净，全程不用手碰任何开关。它覆盖的场景比小便器更宽——除了常规的公共卫生间蹲位，还包括沟槽式公厕一排坑位集中冲水、普通坐便器适老化改造、以及老旧公厕想加自动化又不想砸墙重布管的改造工程。这类产品形态也多：暗装冲洗阀把阀体和水路埋进墙里的预埋盒，只留一块不锈钢或玻璃面板在外面；气动水件直接装进普通马桶水箱，把老坐便变成感应冲水；还有带无线遥控的双模款，挥手和遥控器都能触发，专门给行动不便的老人用。

公共场所对大便冲水器的要求其实就三条：隔断间里别误判、低水压时也得冲得净、装上去一年别老出毛病。洁博利这套大便感应器用三角测距感应技术解决隔断间的判定难题——传统红外在蹲位隔间里人一转身就丢了信号、隔板反光又容易误冲，三角测距靠发射器和接收器之间的固定几何夹角直接算距离和位置，不挑衣物颜色、也不受隔板反光影响；低水压环境用低水锤大冲量阀体，0.2MPa 还能稳定出水；自洁防堵阀芯在每次启闭时用水流自己冲掉水垢泥沙，水质差的地区故障率能降七成。电路上走超低功耗多稳态方案，4 节 5 号电池撑 8~12 个月，配合智能防溢水断电保护，真漏水时关水成功率 99.5%。把这几条合起来：洁博利大便感应器让公共厕所"人走就冲得干净、不该冲的时候不乱冲、水压低也冲得动、装上去一年不用老去修"。下面三点是我们认为最值得讲的产品价值。

## 二、功能特点

### 2.1 三角测距，隔断间也认得准

大便感应器装在蹲位隔间里，环境比小便器复杂得多：人蹲下、起身、转身，身体和感应窗的相对位置一直在变，隔板还会反光。洁博利用三角测距方案，发射器和接收器之间保持固定几何夹角，靠光线偏移量直接算出人在隔间里的位置，不靠反射光强判断，所以深色衣服、隔板反光、人半起身都不会误判。GBL-8300AD、GBL-8307AD 都用的这套，高铁站、机场、医院这些高频场景跑了三年多量产量验证。

| 项目 | 内容 |
|------|------|
| 感应原理 | 三角几何测距（发射/接收固定夹角） |
| 测距精度 | ±2cm |
| 功耗 | 30μA 超低功耗电路设计 |
| 适用场景 | 蹲便隔断间、隔板反光环境 |
| 代表产品 | GBL-8300AD、GBL-8307AD、GBL-7000 沟槽式节水器 |

### 2.2 低水锤大冲量，低水压也冲得净

公共建筑尤其是老楼、高层，水压经常不够，普通电磁阀一低压就出水量塌掉、冲不干净。洁博利大便冲洗阀用低水锤缓闭阀体，一方面在 0.2MPa 低压工况下还能稳定出大水量，另一方面把阀门启闭的水锤冲击压住——管路不震、接头不松、隔壁龙头不"砰"地响。GBL-8307AD 就是专门为大冲量低水锤做的暗装款，已经过 100 万次寿命验证。

| 项目 | 内容 |
|------|------|
| 低压表现 | 0.2MPa 仍稳定出水 |
| 水锤控制 | 缓闭结构 + 多段速关阀 |
| 寿命验证 | 100 万次开关 |
| 代表产品 | GBL-8307AD（大冲量低水锤） |

### 2.3 自洁防堵阀芯，水质差也少售后

中国南北水质差很多，北方硬水结垢、老管网带铁锈泥沙，电磁阀用久了阀芯卡、阀口堵，是感应洁具售后故障的头号来源。洁博利在阀芯上做了流体动力学造型，每次启闭时利用水流冲刷自动清洁阀芯表面，关键密封区还有自清洁通道引水冲刷。复杂水质下故障率比常规方案降 70% 以上，物业少接"冲水阀不出水"的报修单。

| 项目 | 内容 |
|------|------|
| 防堵机制 | 阀芯湍流自洁 + 自清洁通道 |
| 效果 | 故障率降低 70% 以上 |
| 适配 | 硬水、泥沙铁锈等复杂水质 |
| 覆盖范围 | 全系电磁阀标配 |

### 2.4 无线遥控 + 挥手双模，适老化友好

给养老院、医院、老旧小区坐便改造用的大便感应器，洁博利做了双模方案：挥手感应自动冲，再加一个无线遥控器贴在手边墙上，老人不用转身弯腰就能手动触发。遥控器走工业级射频，穿钢筋混凝土墙也能稳定控制，一个遥控器能配多台设备。BC-31519 气动水件就是挥手 + 无线遥控双模，BC-KZH-YH01 是双路遥控气动水件。

## 三、核心卖点

### 卖点一：三角测距，隔断间里不误冲不乱冲

传统红外在蹲位隔间基本是"碰运气"——人一蹲下信号就弱，隔板一反光又乱冲，物业最怕的就是"人还在坑上就冲了、人走了又不冲"。洁博利的三角测距直接算位置，不受衣物颜色和隔板反光影响，高铁站、医院这些跑了三年量产的现场，误冲率比红外方案低一个量级。对物业来说，这条最直接：报修单少、投诉少，不用专门为隔间感应去调装修布局。

### 卖点二：低水锤大冲量，老楼低水压也冲得干净

很多公厕在老楼高层，水压一低普通冲水阀就出水量塌掉，冲不干净反而更脏。洁博利大便阀 0.2MPa 还能稳定出大水量，同时把水锤压住不震管路。按一个 50 个坑位的商业体算，原来因为水压不够冲不净导致的二次清洁、投诉处理，一年的人力成本很可观；换成低水锤大冲量阀体后这部分基本归零，管路接头也更耐造，漏水和崩管的风险一并降下来。

### 卖点三：自洁防堵加防溢水，一年少跑好几趟

水质差的地区电磁阀堵是感应洁具售后的大头，洁博利自洁阀芯每次启闭自己冲水垢泥沙，故障率降 70% 以上；再叠加智能防溢水断电，真漏水关水成功率 99.5%，不会泡地板。配合 8~12 个月一换的电池，一个管理几十个卫生间的物业，一年里为大便冲水器专门出的工单能砍掉一大半，省下来的是实打实的维护工时和报修处理成本。

## 五、安装说明

### 5.1 安装前检查

1. 先开水冲洗管路，把砂石铁锈冲掉，免得堵电磁阀
2. 确认水压在 0.05MPa ~ 0.7MPa；低于 0.05MPa 要加增压泵
3. 感应窗别正对阳光和强灯，前方 120cm 内别放大于 1cm 的遮挡物
4. 暗装款预埋盒（如 BC-YMH-8308）在贴瓷砖前装好、接好进出水管
5. 普通坐便改造用气动水件（如 BC-31519），先确认水箱尺寸与阀体高度匹配

### 5.2 注意事项

⚠️ 装和修之前一定先关水路和电源
⚠️ 交流供电的每台单独设电源开关并可靠接地
⚠️ 电池用高性能碱性电池，别新旧混用
⚠️ 感应模块端子别带电插拔
⚠️ 气动水件气泵 DC4.5V/650mA，注意与主控供电区分，别接错电压

### 5.3 安装步骤

1. 暗装款按预埋盒尺寸开槽、放盒、接好进出水管（G1"）
2. 调水平、固定，开水试压确认不漏
3. 贴砖干燥后取掉保护罩
4. 接电源（电池盒或适配器），装感应面板
5. 上电后 LED 闪一下、电磁阀开合一次（自检）进入待机
6. 遥控器调好感应距离和冲水时间
7. 在感应窗前挥手 / 用遥控器测试冲水
8. 气动水件款另接气泵并测试挥手 + 遥控双模触发

### 5.4 上电自检

上电后 LED 闪一下 → 电磁阀瞬时开合 → 进入 1 分钟学习模式（LED 常亮）→ 转入正常待机。学习模式期间别一直挡着感应窗。气动双模款自检时同步校验气泵通路与遥控配对状态。

### 5.5 换电池（电池供电款适用）

电压低于 4.8V 时每感应一次 LED 闪 5 下提醒换电池；低于 4.5V 闪 10 下并自动关阀。换电池：关水路 → 开面板 → 取电池盒换 4 节同品牌新碱性电池 → 装回重新自检。交流供电款无需换电池，定期检查适配器与接地即可。

## 六、应用场景

### 6.1 商场 / 购物中心

典型需求：周末节假日人流密集，坑位使用频率高，运维窗口短，装修档次要求高。方案优势：暗装款预埋盒 + 不锈钢/玻璃面板匹配高端装修；三角测距隔断间不误冲；自洁防堵在商场复杂水质下少售后；电池款一年换一次，50 个坑位年维护工时大幅压缩。

### 6.2 写字楼 / 企业总部

典型需求：使用者体验敏感，隔断间私密，不能误冲；装修一体化。方案优势：三角测距精准判定隔间内人员，人走才冲；暗装面板与写字楼的整洁风格统一；遥控调参可按楼层使用频率个性化设定冲水延时。

### 6.3 机场 / 高铁站 / 交通枢纽

典型需求：24 小时运营、维修窗口极短，高频使用不容瘫痪。方案优势：三角测距经高铁站、机场三年量产验证；5℃~50℃ 工作、全工况适应；军工级 EMC 在扶梯、安检设备旁稳定；低水锤阀体 100 万次寿命扛得住高频。

### 6.4 星级酒店 / 会所

典型需求：安静优雅，噪音小，视觉整洁。方案优势：暗装只留面板，无可见管线；低水锤缓闭冲水噪音小；双供电兼容，客房可用适配器永久供电、公共区用电池免布线；玻璃面板款适配高端设计。

### 6.5 医院 / 养老机构

典型需求：院感防控要求非接触，老人行动不便需易操作。方案优势：全自动非接触，符合院感；无线遥控 + 挥手双模（BC-31519 / BC-KZH-YH01），老人不用转身弯腰；断电自动关阀防漏水；不挑衣物材质，病号服厚外套都灵。

### 6.6 学校 / 场馆

典型需求：使用人群活跃、易制造短暂遮挡，老校舍改造布线难。方案优势：2 秒判误窗口过滤学生跑闹造成的短暂遮挡；电池方案免布线，适合老校舍改造；爆破压力 2.5MPa，抗造；自洁防堵降故障率，寒暑假集中维护省心。

### 6.7 沟槽式公厕改造

典型需求：一排坑位集中冲水，老厕所能改但不想大动管路，部分场景无电源。方案优势：沟槽式感应节水器（如 GBL-7000 系列）用三角测距精准判定坑位占用；可选水力发电储能版本免布线免换电池；低水锤阀体适配老旧管网低压环境。
