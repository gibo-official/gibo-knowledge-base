## 一、产品介绍

一体化感应花洒头（淋浴洒水头）把感应控制器、电磁阀与花洒喷淋本体集成在同一终端里——伸手或挥手即出水，离开后延时自动关水，全程不用去碰开关或旋钮。它要解决的是公共浴室、健身房、泳池更衣室这类地方最闹心的事：墙面开关沾满水垢和肥皂、多人共用一杆花洒交叉感染、忘关水长流浪费、还有老人小孩够不到或拧不动旋钮。

商场、写字楼、交通枢纽、星级酒店、医院、学校、运动场馆的淋浴区，每天人来人往、对卫生和可靠性要求高，又最怕设备"该出不出、不该出乱喷"。一体化感应花洒头就是为这种高频、公开、运维敏感、且常处于高湿蒸汽环境的地方做的。

它默认搭载洁博利第三代 dTOF 激光测距技术，和老式红外感应不是一回事：红外靠"看反射光强不强"判断有没有人，遇到深色瓷砖、不锈钢花洒杆、蒸汽水雾就容易失准；dTOF 直接测激光打到人体再弹回来的飞行时间，精度到毫米级，不挑材质、也不怕水雾蒸汽。电路上做了超低功耗管理，4 节 5 号电池能撑 12 个月以上，装在花洒头内腔或吊顶暗盒里平时基本不用管。可选项里还带智能恒温（控温精度 ±1.5℃）和无线遥控——前者在公共卫生间多点同时用水时也把水温锁住不跳，后者让物业在淋浴区前就能调好模式和温度，不用拆面板。

把上面几点合起来说：一体化感应花洒头让公共淋浴"该喷的时候喷得准、不该喷的时候不浪费、装上去一年不用频繁操心"。下面三点是我们认为最值得拿出来讲的产品价值。

## 二、功能特点

### 2.1 伸手即出、离手延时关

感应控制集成在花洒头或顶喷本体内，人进入感应区自动出水，离开后延时 0.5~3 秒关水。深色瓷砖墙、不锈钢花洒杆、蒸汽水雾都不影响判定；全程非接触，避免多人共用一杆花洒带来的交叉感染。

| 项目 | 说明 |
|------|------|
| 感应方式 | dTOF 激光飞行时间（940nm VCSEL + SPAD + TDC） |
| 触发动作 | 伸手 / 挥手进入感应锥，离场延时关水 |
| 防误触 | 双重识别校验，过滤水滴、水雾、飞虫短暂遮挡 |
| 出水逻辑 | 人性在则持续出，人离场进入延时倒计时后关断 |

### 2.2 智能恒温，水温不跳

选配智能淋浴精准恒温控温技术（#14），实时监测出水温度和冷热进水压力，用 PID 算法毫秒级动态调节冷热水混合比例。公共卫生间里隔壁的马桶冲水、洗手盆开水，都不会让正在淋浴的人被烫到或激到。

| 项目 | 规格（典型值） |
|------|------|
| 控温精度 | ±1.5℃ |
| 响应速度 | 毫秒级动态补偿 |
| 安全保护 | 出水超温自动限温、水温定期自校准、故障自检 |
| 适用场景 | 酒店会所、公共浴室、运动场馆多点同时用水 |

### 2.3 无线遥控调温与模式

标配无线遥控器，隔着墙体也能把淋浴温度、出水模式、感应距离调好，不用拆面板、不用开吊顶。遥控器待机超低功耗，电池续航 2 年以上。一个遥控器可配对多台设备，做"一键切到节能模式"这类场景化操作。

| 项目 | 说明 |
|------|------|
| 通信方式 | 工业级射频，钢筋混凝土墙体可穿墙控制 |
| 可调项 | 设定温度、出水模式、感应距离、节能模式 |
| 续航 | 遥控器电池 2 年以上（典型值） |
| 适用 | 物业集中调参、适老化改造顺手粘贴大按钮 |

### 2.4 多路出水与按需节水

支持顶喷、手持花洒、下出水多种出水终端组合，按使用习惯一键切换。出水采用"人在即开、人离即关"逻辑，杜绝忘关水长流；公共场所高频连续使用时可切节水模式，减少空喷，单台年节水可观。

| 项目 | 说明 |
|------|------|
| 出水组合 | 顶喷 / 手持 / 下出水（按型号配置） |
| 节水逻辑 | 离场延时关断 + 高频节水模式 |
| 停水保护 | 持续遮挡超时自动关断，防长流水 |

### 2.5 强光免疫与军工 EMC

感应模组融合了双模强光免疫抗干扰算法（#11），覆盖 23 种光源干扰模式，落地窗旁、浴霸、频闪灯下都不误触发。整机按军工级电磁兼容技术（#12）设计，靠近变频空调、大型 LED 屏、消毒设备也稳定工作，通过静电放电 4 级（±15KV）、快速群脉冲 4 级测试。

## 三、核心卖点

### 卖点一：伸手即出，不摸开关也干净

传统公共淋浴的墙面开关沾满水垢肥皂、多人轮流拧，交叉感染和卫生投诉是常态。一体化感应花洒头把感应做到花洒头里，伸手就喷、离场就关，全程不碰任何表面。对物业最直接：少接"花洒开关脏/坏了"的投诉，也更适配医院、学校这类对卫生敏感的场所。

### 卖点二：±1.5℃恒温，不用再躲冷热水

公共浴室最怕隔壁一冲马桶，正在淋浴的人被烫一跳。选配的恒温控温模块用 PID 算法毫秒级补偿冷热水压力波动，控温精度 ±1.5℃，多点同时用水水温也不跳。对酒店、健身场馆来说，这是实打实的体验分——客人不会因为水温忽冷忽热给差评，运营方也少了烫伤纠纷的隐患。

### 卖点三：4 节电池用一年，公共浴室少跑两趟

整机待机功耗只有 0.2mW 出头，4 节碱性电池典型续航 12~18 个月。算一笔账：一个 30 个淋浴位的运动场馆，如果设备月月要换电池，一年光爬梯子换电池就得十几个工时；用一体化感应花洒头一年换一次，这部分工时基本归零。对管理几十间淋浴房的运营方，积少成多是很实在的节省，节水模式再叠加进去，水费也往下走。

## 五、安装说明

### 5.1 装之前检查

1. 先开水冲洗管路，把砂石铁锈冲掉，免得堵电磁阀和花洒喷头
2. 确认水压在 0.05MPa ~ 0.7MPa；低于 0.05MPa 要加增压泵，预约恒温款需确认冷热水双路供水
3. 感应窗别正对强光和强灯，前方感应锥范围内别放大于 1cm 的固定遮挡物
4. 暗装/吊顶款在贴砖或封吊顶前装好预埋盒与管路

### 5.2 注意事项

- ⚠️ 装和修之前一定先关水路和电源
- ⚠️ 交流供电的每台单独设电源开关并可靠接地，禁止带电插拔感应模块端子
- ⚠️ 恒温款冷热水路不可接反，否则控温失效甚至烫水
- ⚠️ 电池用高性能碱性电池，别新旧混用、别正负极装反
- ⚠️ 高湿蒸汽环境安装后确认感应窗灌封完好，避免长期凝水渗入

### 5.3 安装步骤

1. 按预留接口接好冷热水进出管与花洒杆/顶喷
2. 调水平、固定花洒头或顶喷本体
3. 开水试压，确认管路与接口不漏
4. 装感应模组（内置 dTOF 激光窗朝感应区），接好电源（电池盒或适配器）
5. 上电后 LED 闪一下、电磁阀开合一次（自检）进入待机
6. 遥控器调好感应距离、出水模式与设定温度（恒温款）
7. 在感应锥前伸手/挥手测试出水和离场关水

### 5.4 上电自检

上电后 LED 闪一下 → 电磁阀瞬时开合 → 进入约 1 分钟学习模式（LED 常亮）→ 转入正常待机。学习模式期间别一直挡着感应窗，让模组完成环境基线校准。

### 5.5 换电池（如适用电池款）

电压低于提示阈值时每感应一次 LED 闪数下提醒换电池；低于关阀阈值闪多下并自动关阀。换电池：关水路 → 取电池盒 → 换 4 节同品牌新碱性电池 → 装回重新自检。适配器供电款无需换电池，但需确认接地与防水接头密封。

## 六、应用场景

### 6.1 商场 / 购物中心

周末节假日人流密集，非接触淋浴避免共用开关交叉感染；一年换一次电池，30 个淋浴位年维护工时降到个位；中庭天窗直射与复杂灯光下 dTOF 激光照常工作，不会误喷或失灵。

### 6.2 写字楼 / 企业总部

使用者体验敏感，伸手即出、不用去拧开关；遥控调参能按楼层使用频率个性化；暗装不锈钢面板配高端装修，恒温款杜绝同事同时用水时的水温跳变。

### 6.3 机场 / 高铁站 / 交通枢纽

24 小时运营、维修窗口短。全工况适应，5℃~50℃ 工作、-10℃~55℃ 储存；蒸汽弥漫的淋浴区 IP65 防护照常工作；靠近扶梯安检设备也稳（军工级 EMC）。

### 6.4 星级酒店 / 会所

恒温 ±1.5℃ 让客人不再被冷热水激到，差评和烫伤纠纷都少；非接触更显干净优雅；双供电兼容，客房可用适配器永久供电、公共区用电池免布线。

### 6.5 医院 / 养老机构 / 学校

全自动非接触，符合院感与校园卫生防控；不挑衣物材质，病号服厚外套都灵；断电自动关阀防泡水；适老化改造可用大按钮无线遥控粘贴在顺手位置，老人不用转身弯腰操作。

### 6.6 运动场馆 / 健身房 / 泳池更衣室

高湿蒸汽、多人高频使用是常态，IP65 三层灌封不怕水汽；低水锤静音不吵人；节水模式在高峰期自动减少空喷，水费明显往下走；爆破压力 2.5MPa，抗造耐用。
