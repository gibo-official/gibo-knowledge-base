## 一、产品概述

GBL-6197D 感应节水水嘴是一款适配于厨房高弯/高脚菜盘龙头的非接触式感应出水装置，采用红外感应技术，实现挥手出水 / 伸手出水两种智能控制模式。

_安装步骤图_

### 安装步骤

1. **取下水嘴**：
   - 内牙水嘴：取下水嘴 → 安装M22转M24接头 → 装上垫片 → 旋紧接头
   - 外牙水嘴：取下水嘴 → 安装M22接头 → 装上垫片 → 旋紧接头

2. **安装主机**：将感应节水水嘴主机旋紧到接头上

3. **打开手柄**：打开龙头手柄，通水检测是否有渗漏

4. **感应测试**：伸手或挥手测试感应功能

> ⚠️ **注意**：安装前，请先将产品充满电后，再进行安装。
>
> 💡 **建议**：根据使用习惯，建议安装时侧感应窗朝内或左右两侧，使用效果更佳。

### 日常保养

1. 感应窗口部位，请勿使用粗糙物品擦洗，如：粗糙麻布、刷子、钢丝球等
2. 请勿用水冲淋或滴水的湿布擦拭产品，以免造成感应失灵或产品损伤
3. 请勿使用强酸、强碱类洗涤剂进行清洗
4. 水龙头长时间不使用时，请将手柄关闭
5. 请确保供水水压在0.05-0.8MPa范围内，否则可能出现滴水或漏水的情形
6. 产品使用时，请确保USB充电保护塞扣紧贴合，以防水气进入，锈蚀充电口

## 七、常见问题处理

| 问题 | 处理方法 |
|------|---------|
| **安装后漏水** | 1.1 请确认进水接头处是否有装垫片，及垫片厚度是否合适 |
| | 1.2 请确认水压是否在0.05-0.8MPa范围内 |
| **感应时不出水** | 2.1 请确认龙头手柄和进水角阀是否已开启，以及是否停水 |
| | 2.2 请确认侧、下感应窗口表面是否有水珠或被雾气覆盖，擦拭干净即可 |
| | 2.3 请确认侧、下感应窗口30cm范围内不应有障碍物 |
| | 2.4 请确认伸手感应时，侧感应窗口指示灯闪烁一次，若连续闪烁或不闪烁，请充电后使用 |
| **间歇出水或出水不停** | 3.1 请确认侧、下感应窗口表面是否有大颗水珠或被雾气覆盖，擦拭干净即可 |
| | 3.2 请确认侧、下感应窗口30cm范围内不应有障碍物 |
| **出水量小** | 4.1 请确认管路水压是否变小，角阀是否有调到最大 |
| | 4.2 过滤网堵塞：请参照使用维护的清理过滤网垫片流程操作 |

## 八、使用注意事项

1. **安装规范**：请严格按照安装步骤操作，确保各连接处密封良好
2. **环境要求**：水压 0.05-0.8MPa，水温 1-40℃，湿度 ≤95%RH
