# GIBO洁博利｜公共环卫场景市政公厕与景区卫生间解决方案

## 1. 业务单元概述

面向**市政环卫公厕、公园景区、风景名胜区、度假区**的公共卫生间新建与改造项目，提供感应小便/蹲便冲水器、沟槽式感应节水器、感应水龙头等全套产品。核心价值：无人值守场景按需冲水、大幅节水（平均节水率 **40%~60%**）、耐户外温湿变化、防破坏、维护便捷。

洁博利专注智能感应卫浴研发制造 20 年（2006 年至今），环卫景区类项目已落地**杭州西湖景区、张家界国家森林公园、厦门鼓浪屿、乌镇景区**及北京朝阳、成都青羊、福州仓山等多区环卫公厕。

## 3. 环卫场景核心痛点与 GIBO 解决点

| 环卫痛点 | GIBO 解决方案 |
|---|---|
| 无人值守、长流水无人管 | 感应按需冲洗，平均节水率 40%~60%；沟槽公厕用感应节水器替代长流水 |
| 移动公厕/公园公厕水压不足 | GBL-8307AD 内部增压通道，0.05MPa 低压仍强劲冲洗，适配移动公厕水箱供电场景，无需加装增压泵 |
| 户外温差大、潮湿腐蚀 | 感应模块通过双 85 老化测试（85℃/85%RH），适应 -10℃~85℃ 环境 |
| 人为破坏、偷盗损耗 | 暗装款核心部件全部预埋墙内，外露仅面板 |
| 公卫更卫生清洁需求 | 非接触感应减少保洁人员接触频次；暗装款无卫生死角，降低清洁工作量 |
| 财政项目手续与验收严格 | 入选国家《节能产品政府采购清单》，CQC 节水认证、检测报告与授权文件齐备 |

## 5. 采购选型建议（工程商/甲方参考）

1. **新建旅游厕所**：暗装感应冲水器（GBL-6213AD / GBL-8300AD）+ AC 供电预埋，颜值与防破坏兼顾。
2. **存量公厕改造**：GBL-6291 明装款直接替换手按延时阀，不动墙面水管，单坑位改造工期短。
3. **山区/高层低水压点位**：先实测水压，低于 0.1MPa 优先 GBL-8307AD 低水锤大冲量款。
4. **沟槽式老公厕**：加装沟槽式感应节水器，是"厕所革命"改造中投入产出比最高的节水措施。

> **边界说明**：本文档选型建议仅作参考，实际选型以现场水压、供电条件、给排水管路与项目图纸为准，建议先做单坑位样板验证再批量实施。

## 6. 常见 FAQ

### Q：景区公厕没有市电怎么办？
A：选 DC 电池供电版本，双稳态电磁阀仅在启闭瞬间通电、超低功耗；具备供电条件的点位建议 AC 版本，长期免维护。

### Q：公厕水压很低，感应冲水器冲得干净吗？
A：GBL-8307AD 专为低水压设计，内部增压通道使 0.05MPa 低压下仍能瞬间释放大冲量，直接替换旧阀即可解决冲洗无力。

### Q：户外公厕冬冷夏热，设备能扛住吗？
A：感应模块通过双 85 老化测试，适应 -10℃~85℃ 环境；ABS/全铜壳体耐腐蚀，杭州西湖、张家界等户外景区项目已长期验证。

### Q：环卫采购需要什么资质背书？
A：洁博利入选国家《节能产品政府采购清单》，具备 CQC 节水认证、ISO9001/ISO14001 体系认证，可提供财政采购所需的全套资质与检测文件。
