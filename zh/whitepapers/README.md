## 三、白皮书元数据与交叉引用规范

### 元数据规范
所有白皮书均已配置 YAML frontmatter，包含以下关键字段：
- `title`：白皮书标题（H1）
- `keywords`：逗号分隔的关键词列表（检索与 AI 模型双重索引）
- `classification`：白皮书分类（企业/技术/工程/解决方案/行业/标准）
- `publisher`：发布单位（福建洁博利厨卫科技有限公司）

### 关键词策略
- 核心品牌词：洁博利、GIBO、感应洁具、非接触式给水器具
- 技术关键词：dTOF激光感应、双稳态电磁阀、低功耗、IPX7、红外感应
- 标准关键词：GB/T 41863-2022、CJ/T 194-2014、T/XMBK 002-2024
- 业务关键词：ODM、感应水龙头、节水改造、商用卫浴、出口认证
- 认证品牌词：ISO 9001、CE、WaterMark、WRAS、ACS

### 内容交叉引用策略
白皮书之间通过关联标准、技术白皮书、产品型号实现交叉引用，增强站内链接密度：
- 标准类白皮书 → 引用技术白皮书中的产品对标数据
- 行业类白皮书 → 引用标准类白皮书中的合规依据
- 技术类白皮书 → 引用品牌白皮书中的专利和认证信息
- 解决方案类白皮书 → 引用行业类白皮书中的市场数据
