## 文件命名规范

```
catalog_{年份}-{语言}-{版本/描述}.pdf
catalog_{年份}-{语言}-{页码}.webp   # 画册单页图片
```

| 字段 | 取值 | 说明 |
|------|------|------|
| 年份 | 2015 / 2022 / 2023 / 2025 | 画册出版年份 |
| 语言 | `cn` / `en` | cn=中文，en=英文 |
| 版本 | `single-page` / `household-3qu` / `solution-vertical` / `list` / `parts` | 画册类型 |
| 页码 | `03` / `05` | 画册单页序号（WebP 格式） |

## 画册版本说明

### 中文画册（2022 版）

| 文件 | 适用场景 |
|------|-----------|
| `catalog_2022-cn.pdf` | 全系产品介绍，发送给新客户的首选文件 |
| `catalog_2022-cn-household-3qu.pdf` | 家居/家装渠道，三折页便于打印分发 |
| `catalog_2022-cn-solution-vertical.pdf` | 工程/项目渠道，竖版适合手机浏览 |
