# EN1111:2017卫生龙头一恒温混合阀一通用技术规范

## 1 范围

本标准规定了PN10恒温混水阀的通用构造、性能以及材料要求，包括验证在低于 $4 5 ^ { \circ } C$ 下使用时混合水温性能的测试方法。若适用，本标准并不排除可以选择更高的使用温度。当装置用于防止儿童、老年人和残障人士烫伤时，需将混合水的水温设置在合适的淋浴温度(体温约 $3 8 ^ { \circ } C )$ ，因为相较于成年人，儿童在更低的温度下仍存在被烫伤的风险。幼儿在使用恒温混水阀淋浴时仍需有人进行监护。

本标准适用于表1规定条件下，安装在厨房、盥洗室（包括所有含卫生龙头洁具的房间，如卫生间和更衣室)、浴室的卫生洁具上的混合阀。

本标准允许家用装置上使用的恒温龙头，带有一个单独出水口或少量出水口(如同时控制淋浴出水、浴缸出水、面盆出水和/或妇洗出水的混水阀)，但特殊设计的带有大量出水口的混水阀除外(如公用)。

本标准描述的测试为型式检测(实验室检测)，并非生产过程执行的质量控制检验。

## 3 术语与定义

下列术语与定义适用于本标准

3.1恒温混合阀（TMV）

带一个或多个出水口，可混合冷热水并自动控制混合水的温度至所选温度的阀

3.2精确性 fidelity

温度选择的再现性和准确性

3.3阀芯

阀的可移动部件，位于水流通道处，用于允许、限制或阻断水流

注1：无流量到最大流量之间可由同一个流量控制装置或由单独的流量控制装置来控制

3.4 出水口 1

转换开关的默认位置(7.1 处有涉及)

3.5出水口 2

除出水口1外的其它出水口

## 5 分类

恒温混合阀分为：

a) 类型1---单控：由单个控制装置调节流量及温度的阀（控制装置在两个平面内移动）

b) 类型2---双控：由不同的控制装置调节流量及温度的阀

c) 类型3---单把顺序控制：由一个控制装置按照预定的流量及温度顺序进行控制的阀。该类阀应有一个闭合装置（控制装置在一个平面内移动）

d) 类型4---无流量控制装置的恒温混合阀

e) 类型5---预置型：不能由卫生洁具使用者调节的阀

f) 类型6---其它：带特殊控制装置的恒温混合阀

## 7标志/标识

7.1 标识

恒温混合阀应永久且清晰地标识出：

a) 在恒温混合阀的本体或把手上标出生厂商或代理商的名称或标识

b)噪声组别以及流量等级

对于浴缸/淋浴器混合阀应同时标出两个流量等级(第一为浴缸出水口(出水口1)，第二为淋浴出水口(出水口2))

对于节水型混合阀，应向安装者和使用者提供相应信息。

7.2标志

恒温混合阀上的温度控制装置应使用刻度或符号或颜色或其组合进行标识。

应清晰地标识出混合阀的冷/热进水口

注：外露型恒温混合阀的冷/热进水口仅需一处有标识

## 12密封性能

## 12.1 概述

## 12.1.1 原理

验证恒温混合阀在冷水压力下的密封性能。见下述12.2\~12.6条款

## 12.1.2 设备

液压测试设备，要求在整个测试过程中能保持所要求的水压。

## 12.2 阀芯及阀芯上游密封性能

## 12.2.1 概述

应堵住无流量控制装置（类型4，条款5）的恒温混合阀的出水口

对于单把顺序控制恒温混合阀(类型3，条款5)，其流量控制装置应处于关闭位置

## 12.2.2步骤

a)将恒温混合阀的两个进水端均接入测试设备中；

b)出水口打开，关闭流量控制装置，向恒温混合阀施加 $( 1 . 6 { \pm } 0 . 0 5 ) \mathrm { M P a }$ 的水压，保压 $( 6 0 \pm 5 ) \mathrm { s } $ 转动温度控制装置，在温度装置控制的整个范围内进行试验。

## 12.2.3要求

恒温混合阀的阀芯及阀芯上游过水通道均无渗漏。

## 12.3进水口之间的冷热隔墙

## 12.3.1概述

应堵住无流量控制装置（类型4，条款5）的恒温混合阀的出水口

对于单把顺序控制恒温混合阀(类型3，条款5)，其流量控制装置应处于关闭位置

## 12.3.2 步骤

a)将恒温混合阀的冷水端进水口接入测试设备中；

b)出水口打开，关闭流量控制装置，向恒温混合阀施 $\hbar \sigma ( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的水压，保 $\mathcal { F } ( 6 0 \pm 5 ) \mathrm { s }$ 转动温度控制装置，在温度装置控制的整个范围内进行试验。

c)将冷水端进水口从设备上拆下，恒温混合阀的热水端进水口接入测试设备中，重复上述试验12.3.3 要求

恒温混合阀未连接的进水端应无渗漏。恒温混合阀随后应进行条款12.4阀芯下游密封测试。若使用止回阀，则应满足EN13959。

## 12.4 阀芯下游密封性能

## 12.4.1 步骤

a)将恒温混合阀接入测试设备

b)人工堵住出水口，逐渐向下开启阀芯

c) 向恒温混合阀的进水端施加 $\mathsf { \Omega } ^ { \prime } ( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的水压，保压 $( 6 0 \pm 5 ) \mathrm { s } $ ，转动温度控制装置，在温度装置控制的整个范围内进行试验。

d) 在(5±1)s 内将水压减小至 $( 0 . 0 2 { \pm } 0 . 0 0 2 ) \mathrm { M P a }$ ，保压 $( 6 0 \pm 5 ) \mathrm { s } $

## 12.4.2 要求

应无渗漏。含转换开关的恒温混合阀随后应进行条款12.5或12.6的测试

## 12.5 手动转换开关的密封性能

## 12.5.1 步骤

a)将恒温混合阀按使用状态安装在试验设备上

b)将转换开关调节至出水口2(水流至淋浴位)，人工堵住出水口2(淋浴出水口)，打开出水口1（浴缸出水口）

c) 施加 $\mathrm { \hbar } ( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的水压，保压 $( 6 0 \pm 0 5 ) \mathrm { s }$ ，检查出水口1（浴缸出水口)有无渗漏现象

d) 在(5±1)s 内将水压减小至(0.02±0.002)MPa，保压 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查出水口1（浴缸出水口）有无渗漏现象

e) 将转换开关调节至出水口1(水流至浴缸位)，人工堵住出水口1(浴缸出水口)，打开出水口

2(淋浴出水口)

f)施加(0.4±0.02)MPa的静水压，保压(60±5)s，检查出水口2(淋浴出水口)有无渗漏现象

g)在(5±1)s内将静水压减小至(0.02±0.002)MPa，保压(60±5)s，检查出水口2（(淋浴出水口） 有无渗漏现象。

## 12.5.2 要求

在整个试验过程，上述所需检查的出水口均应无渗漏现象

## 12.6 自动复位转换开关的密封性能

## 12.6.1步骤

a)将恒温混合阀按使用状态安装在试验设备上，所有出水口均处于开启状态

b)将液阻A连接到出水口2(淋浴出水口)

c) 将转换开关调节至出水口1(水流至浴缸位)，施加(0.4±0.02)MPa的动压，保压(60±5)s，检查出水口2（淋浴出水口)有无渗漏现象

d)将转换开关调节至出水口2（淋浴出水口)，施加(0.4±0.02)MPa的动压，保压(60±5)s，检查出水口1（水流至浴缸位)有无渗漏现象

e)转换开关仍处于调节至出水口2(淋浴出水口)，将动压减小至(0.05±0.005)MPa，检查转换开关，应不复位至出水口1（水流至浴缸位)。保压(60±5)s，检查出水口1（水流至浴缸位)有无渗漏现象

f) 关闭水流，检查自动复位转换开关是否自动复位至出水口1(水流至浴缸位)

g)重新施加(0.05±0.005)MPa动压，保压(60±5)s，检查出水口2（淋浴出水口）有无渗漏现象 12.6.2 要求

在整个试验过程，均应无渗漏现象

## 附录 B(规范性） 测量

## B.1 压力

热水水压Ph，冷水水压Pc，其测量精度应达到1.0%

## B.2流量

热水流量Qh，冷水流量Qc，其测量精度应达到2.0%。混合水的流量为 $\left( \mathrm { Q h + Q c } \right)$

## B.3 温度

## B.3.1安装

确保传感部件的热敏部分完全浸入。测量混合水温时，将温度计元件牢固地安装在与出水口接触处，并使排放出的水流完全流过或沿着温度计元件的整个热敏部分传递。将温度计的热敏部分置于离出水口末端30mm\~50mm的空气中。

## B.3.2 精度

热水供水温度Th，冷水供水温度Tc，混合水温度Tm，其测量精度应达到0.5K

## B.3.3响应时间

使用带显示系统响应总值的设备测量混合水温度。设备读数变化等于温度阶跃变化的90%，该读数变化在 $( 0 . 3 \pm 0 . 0 5 )$ s显示出。可通过本文件中描述的步骤验证该响应时间。

## B.4 角度位置

测量温度控制装置的角度位置应精确至 $0 . 5 ^ { \circ }$ ，测量线性位移应精确至0.5mm

## 附录D(资料性) 噪声分类（示例）

D.1带出水口/喷嘴的恒温混合阀

若出水口/喷嘴安装了流量调节器，则恒温混合阀按下述进行分类：

a)按噪声组别：组或组Ⅱ或无组别

b)按试验所使用的液阻

1) 浴缸恒温混合阀：D,C 或 B

2)其它混合阀：D\~Z。除非生产商有要求，否则测试一般从液阻Z开始

若出水口/喷嘴没有安装流量调节器，则恒温混合阀按噪声组|或组Ⅱ分类

D.2 带花洒或花洒头出水

恒温混合阀分为：

a)按噪声组别：组或组Ⅱ或无组别

b)按试验所使用的液阻：D,C,B,S,A 或 Z

D.3带出水口/喷嘴以及花洒或花洒头出水的恒温混合阀

若出水口/喷嘴安装了流量调节器，则恒温混合阀按下述进行分类：

a)当两个出水位置的噪声组别一致时，以相应噪声组别定级

b)当两个出水位置的噪声组别不一致时，以噪声最大者定级

需注意的是：

---用于测试出水口/喷嘴的液阻等级为：D,C或B

---用于测试花洒或花洒头的液阻等级为：D,C,B,S,A 或Z

---若两个出水位置的等级一致，则只需给出相应等级的字母

---若出水口/喷嘴没有安装流量调节器，则恒温混合阀仅根据噪声最大组别定级

---已经定级的恒温混合阀，不可安装更高等级的配件（流量调节器、花洒配件）

---已经定级的恒温混合阀，可安装较低流量等级的配件

---必须满足条款17.3.3的要求

示例：出水口/喷嘴处使用液阻C，噪声为组|，花洒处使用液阻A，噪声为组|，则该恒温混合阀定为|C/A级

出水口/喷嘴处使用液阻B，噪声为组Ⅱ，花洒处使用液阻B，噪声为组Ⅰ，则该恒温混合阀

定为ⅡB/B 级
