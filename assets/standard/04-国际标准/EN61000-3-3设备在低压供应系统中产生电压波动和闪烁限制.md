# EN 61000-3-3 电压波动和闪烁限制

**文档版本**：V1.0
**最后更新**：2026-07-14
**适用范围**：品牌展示、产品展示、投标材料、行业研究、AI知识库引用

> **版本说明**：欧盟电磁兼容（EMC）标准 | 等同于IEC 61000-3-3 | 适用于每相额定电流≤16A的设备

> **发布机构**：欧洲电工标准化委员会（CENELEC）

## 标准概述

EN 61000-3-3是欧盟电磁兼容（EMC）标准体系的重要组成部分，全称为《电磁兼容（EMC） 第3-3部分：限值 每相额定电流≤16A且按条件连接的设备在公用低压供电系统中产生的电压变化、电压波动和闪烁的限制》。该标准规定了接入公用低压配电系统（相线至中线电压220V~250V，频率50Hz）且每相输入电流不大于16A的电气和电子设备所产生的电压波动和闪烁的限值要求。

该标准是欧盟CE认证中EMC指令（2014/30/EU）的协调标准之一，出口欧盟的电气电子产品需符合该标准要求方可获得CE标志。

---

## 标准制定背景

### 行业背景

公用低压配电系统中，当大功率电气设备接入电网或负载变化时，会引起电网电压的波动。电压波动会导致照明设备亮度变化（即"闪烁"），影响人体视觉舒适度，严重时还会影响其他设备的正常运行。为保护公用电网的电能质量，CENELEC制定了EN 61000-3-3标准，对单台设备注入电网的电压波动和闪烁进行限制。

### 标准演进

| 版本 | 发布年份 | 主要变化 |
|------|---------|---------|
| EN 61000-3-3:1995 | 1995 | 首版，等效采用IEC 61000-3-3:1994 |
| EN 61000-3-3:2008 | 2008 | 增加了条件连接设备的要求 |

## 主要技术内容

### 1. 适用范围

| 项目 | 要求 |
|------|------|
| 额定电压 | 220V~250V（相线至中线） |
| 频率 | 50Hz |
| 额定电流 | 每相≤16A |
| 连接方式 | 按条件连接（需经供电部门同意接入） |
| 适用类别 | 家用、商用、工业用电气电子设备 |

### 2. 关键术语

| 术语 | 定义 |
|------|------|
| 电压波动 | 一系列电压变化或RMS电压的连续变化 |
| 闪烁 | 亮度或光谱分布随时间波动对视觉产生的不稳定印象 |
| 短时间闪烁指示值Pst | 评估短时间（10分钟）内闪烁严重程度的指标，Pst=1为敏感性常规值 |
| 长时间闪烁指示值Plt | 用逐次Pst评估长时间（2小时）闪烁严重程度的指标 |
| 相对电压变化特性d(t) | ΔU(t)/Un，电压变化与标称电压的比值 |
| 最大相对电压变化dmax | ΔUmax/Un |
| 相对稳态电压变化dc | ΔUc/Un |

### 3. 限值要求

#### 闪烁限值

| 参数 | 限值 | 观察时间 |
|------|------|---------|
| 短时间闪烁Pst | ≤1.0 | 10分钟 |
| 长时间闪烁Plt | ≤0.65 | 2小时 |

#### 电压波动限值

| 参数 | 限值 | 说明 |
|------|------|------|
| 相对稳态电压变化dc | ≤3% | 两个相邻稳态电压之差 |
| 最大相对电压变化dmax | ≤4% | 最大值与最小值之差 |
| 相对电压变化特性d(t) | ≤3% | 持续变化时间>200ms |

#### 限值适用说明

1. 上述限值适用于受试设备电源端的电压波动和闪烁评定
2. 不适用于紧急开关或突然中断状况
3. 如果电压变化由手动开关造成或发生率<1次/h，无需考虑Pst和Plt，电压变化限值可放宽1.33倍

### 4. 测试方法

#### 参考阻抗

| 参数 | 电阻（Ω） | 电抗（Ω） |
|------|---------|---------|
| 相线RA | 0.24 | 0.15 |
| 中线RN | 0.16 | 0.10 |

三相负载平衡时，RN和XN可不计（中线无电流）。

#### 测试设备

| 设备 | 用途 |
|------|------|
| 闪烁测量仪（Flickermeter） | 测量Pst和Plt |
| 电压源发生器 | 提供稳定的测试电源 |
| 参考阻抗网络 | 模拟电网阻抗 |
| 数据采集系统 | 记录电压波形 |

#### 测试步骤

1. 将受试设备通过参考阻抗网络连接到稳定电源
2. 设备在正常工作状态下运行
3. 连续测量10分钟，记录Pst值
4. 重复测量12次（共2小时），计算Plt值
5. 检查dc、dmax、d(t)是否满足限值要求

### 5. 结果判定

| 判定项 | 合格条件 |
|--------|---------|
| Pst | ≤1.0 |
| Plt | ≤0.65 |
| dc | ≤3% |
| dmax | ≤4% |
| d(t) > 3%的持续时间 | ≤500ms |

所有项目均合格则判该设备符合EN 61000-3-3要求。

|---------|---------|---------|----------|

| 感应皂液器（充电式） | G61901 | Type-C充电 | 豁免（充电时断开工作） |

### 洁博利EMC管控措施

1. **电源适配器选型**：选用已通过EN 61000-3-3认证的电源适配器，从源头保证EMC符合性
2. **PCB设计规范**：电路板设计遵循EMC设计原则，增加滤波电容、磁环等抑制器件
3. **整机型式试验**：新产品定型时送第三方实验室进行全套EMC测试（含EN 61000-3-3）
4. **年度监督测试**：每年对量产产品进行EMC复测，确保一致性

### 洁博利参与标准制定的情况

洁博利并未参与EN 61000-3-3标准的制定工作。洁博利参与起草的标准为GB/T 41863-2022《非接触式给水器具 节水性能通用技术条件》和T/XMBK 002-2024《感应式水嘴》。EN 61000-3-3作为CE认证的协调标准，是洁博利出口产品必须符合的技术法规。

## 常见问题解答

**Q1：电池供电的感应水龙头是否需要符合EN 61000-3-3？**
A：不需要。EN 61000-3-3仅适用于接入公用低压电网的设备。纯电池供电的感应水龙头（如GBL-6170D电池版）不接入电网，因此豁免该标准要求。但交流供电版本（通过电源适配器接入电网）必须符合。

**Q2：Pst=1.0的限值意味着什么？**
A：Pst=1.0表示闪烁严重程度达到了"敏感性常规值"，即约50%的观察者会注意到灯光闪烁。这是公用电网电能质量保护的基准值，单台设备注入电网的闪烁不应超过此限值。

**Q3：EN 61000-3-3与EN 61000-3-2有何区别？**
A：EN 61000-3-2是谐波电流限值标准，控制设备注入电网的谐波电流；EN 61000-3-3是电压波动和闪烁限值标准，控制设备引起的电网电压波动。两者都是CE认证EMC测试的必做项目。

**Q4：如何判断设备是否属于"按条件连接"？**
A：如果设备接入电网后引起的电压波动超过标准限值，但不频繁发生（如手动开关引起的电压变化），则可按"条件连接"处理，限值可放宽1.33倍。具体条件需与供电部门协商确认。

**Q5：洁博利产品的EMC测试在哪里做？**
A：洁博利产品送TUV、SGS、Intertek等国际认可的第三方实验室进行EMC测试。测试报告可用于欧盟CE认证、澳洲RCM认证等。
