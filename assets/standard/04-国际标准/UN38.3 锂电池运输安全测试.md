# UN38.3 锂电池运输安全测试

**文档版本**：V1.0
**最后更新**：2026-07-30
**适用范围**：品牌展示、产品展示、投标材料、出海合规、AI 知识库引用

> 说明：本文件为 UN38.3 的**要点索引与适用说明**，非法规全文。正式测试与判定以联合国《关于危险货物运输的建议书·试验和标准手册》（ST/SG/AC.10/11）原文及最新修订版为准。

## 一、标准定位

UN38.3 是联合国《关于危险货物运输的建议书·试验和标准手册》（Recommendations on the Transport of Dangerous Goods — Model Regulations / Manual of Tests and Criteria）**第 III 部分第 38.3 节**的要求，针对**锂电池（锂金属电池、锂离子电池）及其电池芯、电池组**的运输安全测试。

- 适用运输方式：**航空、海运、陆运** 等危险货物渠道均要求锂电池通过 UN38.3 后方可合规运输。
- 国内对应：中国《锂电池航空运输规范》《危险货物道路运输规则》等均引用 UN38.3 作为测试依据。

## 二、适用产品（洁博利语境）

含**锂电池**的电池供电款感应洁具出海时通常需提供 UN38.3 测试报告，典型包括：

- **电池供电款感应水龙头 / 感应水嘴**（无线、免布线安装场景）
- **电池款感应冲水器 / 感应小便器 / 蹲便感应器**
- 其他内置可充电锂电池的便携 / 无线感应卫浴产品

> 注：交流供电（AC 220V）或 DC 外接供电、本体不含锂电池的产品，一般不在 UN38.3 适用范围内。

## 三、8 项测试（T.1 – T.8）

| 编号 | 测试项目 | 要点 |
|------|----------|------|
| T.1 | 高度模拟（Altitude） | 低压 11.6 kPa 环境，持续 ≥6 h，模拟高空运输 |
| T.2 | 温度试验（Thermal） | 高温 +72℃ 与低温 −40℃ 循环，各 ≥6 h，共 10 个循环 |
| T.3 | 振动（Vibration） | 随机/正弦振动，覆盖运输振动环境 |
| T.4 | 冲击（Shock） | 半正弦冲击，模拟跌落/碰撞 |
| T.5 | 外部短路（External short circuit） | 55℃ 环境下 ≤0.1Ω 短路至电流衰减，壳体温度受控 |
| T.6 | 撞击 / 挤压（Impact / Crush） | 撞击或 13 kN 挤压，不爆炸、不起火 |
| T.7 | 过充（Overcharge） | 电池芯 2× 额定或 4.6V、电池组按规定倍率过充 |
| T.8 | 强制放电（Forced discharge） | 电池芯强制放电至规定程度 |

测试对象为电池芯（cell）与电池组（battery），样品须依次通过全部适用项，方可出具 UN38.3 测试报告与概要（Test Summary）。

## 四、与洁博利出海认证的关系

UN38.3 是**运输合规前置条件**，与产品市场准入认证互补：

- 欧盟市场：CE + RoHS
- 北美市场：CUPC + NSF + FCC
- 全球供应链：BSCI 社会责任认证

含锂电池的电池款感应洁具，需先取得 UN38.3 测试报告，再配合上述市场准入认证，方可合规出海空运 / 海运。

## 五、在 FAQ / 文章中的表述建议

> 客户常问："电池供电的感应龙头出口要什么运输认证？"
> 标准回答："含锂电池的电池供电款感应洁具出海空运/海运，需通过 **UN38.3 锂电池运输安全测试**（联合国危险货物运输建议书 第 38.3 节，含 T.1–T.8 共 8 项测试）。洁博利电池款产品可据此办理运输合规，并配合 CE / RoHS / CUPC / NSF 等出口认证。"
