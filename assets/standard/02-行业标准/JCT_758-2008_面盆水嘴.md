## 前 言

本标准参考了欧州标准 EN200：2004《单控和混控—卫生用水嘴技术规范》及 EN817：1997《机械混合式水嘴通用技术规范》。并增加了水嘴与饮用水直接接触的铜材质铅析出限量的要求、水嘴流量上限值的规定、水嘴冷热疲劳要求，在节水和提高水嘴应用可靠性方面更趋于合理。

本标准是对 JC/T758-1983(1996)《陶瓷洗面器普通水嘴》的修订。

本标准自实施之日起代替 JC/T758-1983(1996)。

本标准与 JC/T758-1983(1996)相比，主要变化如下：

增加了对水嘴扭力矩试验以及寿命的要求。

——增加了非接触式水嘴的标准内容。

——增加了水嘴流量上限值，符合国家节水政策。

——修改了对水嘴材料、加工与装配、外观质量的要求。

——修改了对水嘴阀体强度性能、密封性能的要求。

本标准由中国建筑材料联合会提出。

本标准由全国建筑卫生陶瓷标准化技术委员会归口。

本标准负责起草单位：国家建筑材料工业建筑五金水暖产品质量监督检验测试中心、北京市建筑五金水暖产品质量监督检验站、唐山惠达陶瓷（集团）股份有限公司、中宇建材集团有限公司、申鹭达集团有限公司、辉煌水暖集团有限公司、广东朝阳卫浴有限公司、广东华艺卫浴实业有限公司。

本标准主要起草人：岳敬平、王巍、史红卫、邓贵智、赵钢。

本标准所代替标准的历次版本发布情况为：

## 面 盆 水 嘴

## 1 范围

本标准规定了面盆水嘴的产品分类、技术要求、试验方法、检验规则及标志、包装、运输和贮存。

本标准适用于安装在建筑物内的冷、热水供水管路上，公称压力不大于 1.0MPa，介质温度不大于 90℃条件下的面盆水嘴。

4 一般要求

4.1 产品所使用的所有与饮用水直接接触的材料，应符合 GB/T17219 的规定。

4.2 产品使用的材料应符合相应的材料标准要求。

5 技术要求

5.1 材料

产品所使用的与饮用水直接接触的铜材质铅析出限量，应符合 JC/T1043 的规定。

5.2 加工与装配

5.2.1 管螺纹精度应符合 GB/T7306.1 或 GB/T7306.2 或 GB/T7307 的规定。

5.2.2 螺纹表面不应有凹痕、断牙等明显缺陷，表面粗糙度 Ra 不大于3.2μm。

5.2.3 机械式双控面盆水嘴冷热水标志应清晰，蓝色(或C 或冷字)表示冷水，红色(或H 或热字)表示热水。双控水嘴冷水标志在右，热水标志在左。连接牢固。轮式手柄逆时针方向转动为开启，顺时针方向转动为关闭。

5.2.4 机械式面盆水嘴操作手柄开启、关闭，应平稳，轻便、无卡阻。

5.2.5 与面盆水嘴配接的软管应符合 JC886 的规定。

## 5.3 外观质量

5.3.1 产品外表面涂、镀层色泽均匀，光滑，不应有起泡、烧焦、露底、划伤等缺陷。

5.3.2 产品表面涂、镀层按 GB/T10125 进行 24h乙酸盐雾试验后，达到 GB/T6461 标准中 10 级的要求。

5.3.3 产品表面涂、镀层经附着力试验后，不允许出现起皮或脱落现象。

5.4.4.1 机械式面盆水嘴在流量调节方向手柄扭力矩应不小于 $6 \mathrm { { N m } \pm 0 . 6 \mathrm { { N m } } }$ ，在温度调节方向手柄扭力矩应不小于 $3 _ { - 0 . 5 } ^ { 0 } \mathrm { N m }$ 。试验后，产品应无可见变形，并满足对水嘴密封和流量的要求。

6 试验方法

6.1 产品所使用的与饮用水直接接触的铜材质铅析出限量试验方法按 JC/T1043 的规定。

6.2 加工与装配

6.2.1 螺纹精度用测定该精度等级的螺纹量规测定。

6.2.2 表面粗糙度参照“表面粗糙度标准块”比较检查。

6.2.3 动作质量在产品组装后凭手感检查。

6.2.4 软管的试验方法按 JC886 的规定。

6.3 外观质量

6.3.1 外观质量采用目测。目测的距离为 300mm，照度不低于 300Lx，不得借助任何放大仪器。

6.3.2 按照GB/T10125 标准规定进行乙酸盐雾试验。结果评定方法应符合 GB/T6461的规定。

6.3.3 产品表面涂、镀层附着力试验方法按 GB18145－2003 中 7.2.3 的规定

## 6.4 使用性能

6.4.1 阀体的强度性能

## 6.4.1.1 进水部位（阀座下方）强度性能

将水嘴按使用状态安装在测试设备上。关闭阀芯，从进水口引入规定的压力值，在规定的保压时间内，检查阀体应无变形和渗漏。

## 6.4.1.2 出水部位（阀座上方）强度性能

将水嘴按使用状态安装在测试设备上。打开阀芯，打开出水口，从进水口引入规定的压力值，在规定的保压时间内，检查阀体应无渗漏。

## 6.4.2 密封性能

## 6.4.2.1 阀芯密封性能

将水嘴按使用状态安装在测试设备上。关闭阀芯，从进水口引入规定的压力值，在规定的保压时间内，检查出水口应无渗漏。

## 6.4.2.2 上密封性能

将水嘴按使用状态安装在测试设备上。打开阀芯，堵住出水口，从进水口引入规定的压力值，在规定的保压时间内，检查水嘴各连接处应无渗漏。

## 6.4.2.3 冷、热水隔墙密封性能

将水嘴的一个进水口连接在测试设备上，关闭阀芯，引入规定的压力值，在规定的保压时间内，检查另一进水口应无渗漏。另一进水口要重复试验。

## 6.4.3 流量性能

水嘴按使用状态连接在供水管路上，进水口引入规定的压力值。

6.4.3.1 机械式单柄双控水嘴检测流量时，在冷水端将手柄开启到最大位置，再从冷水端转动手柄到热水端最大位置，取其流量最小值。

6.4.3.2 机械式双柄双控水嘴检测流量时，分别将手柄开启到冷、热水最大位置，取两个流量的最小值。

6.4.3.3 机械式单柄单控水嘴检测流量时，将手柄开启到最大位置，取其流量值。

6.4.4 扭力矩试验

6.4.4.1 控制力矩用弹簧测力计或扭力扳手测定。扭力矩试验在室温下进行，试验过程中水嘴按正常使用状态安装在供水管路上，不供水。单柄双控水嘴手柄处于中间位置，在手柄末端沿流量调节方向在 4s～6s时间内，逐渐施加 $6 \mathrm { { N m } \pm 0 . 6 \mathrm { { N m } } }$ 的力矩，并保持 5min。在手柄末端沿温度调节方向，在 4s～6s 时间内，逐渐施加 $3 _ { - 0 . 5 } ^ { 0 }$ Nm的力矩，并保持 5min。试验后，产品应无可见变形，并满足对水嘴密封和流量的要求。

6.4.4.2 拉力用弹簧测力计测定。机械式面盆水嘴沿阀杆轴线方向应能承受 67N的拉力。试验后，产品应无可见变形，并满足对水嘴密封的要求。

6.4.4.3 面盆水嘴连接螺纹扭力矩试验用扭力扳手进行，试验后水嘴应无裂纹、损坏。

6.4.5 寿命

6.4.5.1 机械式面盆水嘴开关寿命试验方法按 GB18145－2003 中 7.3.4 的规定。

6.4.5.2 机械式面盆水嘴冷热疲劳试验方法按 GB18145－2003 中 7.3.4.1 的规定。

6.4.6 非接触式面盆水嘴试验方法按 CJ/T194-2004 第 7 章的规定。

## 7.3 型式检验

## 7.3.1 检验项目

型式检验包括本标准第 5 章技术要求的全部项目。

7.3.2 有下列情况之一，应进行型式检验：

a） 新产品或老产品转厂生产的试制定型鉴定；

b） 当正常生产的产品在设计、工艺、生产设备、管理等方面有较大改变而可能影响产品的性能时；

c） 正常情况下，每年至少进行 1 次；

d） 不生产的产品恢复生产时；

e） 出厂检验结果与上次型式检验有较大差异时；

f） 国家质量监督检验机构提出进行型式检验的要求时。

## 洁博利解读

本标准对水嘴产品的密封性能、流量控制、材料安全等核心技术指标做出了明确规定。洁博利智能厨卫在感应水龙头、厨房抽拉龙头等产品设计中，严格遵循本标准要求，尤其在陶瓷阀芯选用、流量精度控制、铅析出限值等关键指标上优于标准要求。感应式水嘴还需额外满足非接触式给水器具相关标准的电磁兼容和感应灵敏度要求。

## 应用场景

适用于洁博利全线感应水龙头产品（厨房感应龙头、面盆感应龙头、淋浴感应龙头）、厨房抽拉式智能龙头、恒温混合阀等产品的研发、生产和质量检验环节。出口产品还需同时满足目标市场的等效标准（如EN 817、ASME A112.18.1等）。
