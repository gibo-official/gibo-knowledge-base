## 标准概述

HG/T 3091-2000《橡胶密封件 给、排水管及污水管道用接口密封圈 材料规范》等效采用国际标准ISO 4633:1984《Rubber seals - Joint rings for water supply, drainage and sewerage pipelines - Specification for materials》，规定了给水、排水及污水管道接口用橡胶密封圈的材料分类、技术要求、试验方法和检验规则。该标准是管道工程密封领域的重要基础标准，保障了管道系统的密封安全。

## 标准制定背景

### 行业背景

给排水管道系统是城市基础设施的重要组成部分，管道接口密封圈是保障管道系统密封性能的关键部件。密封圈一旦失效，将导致管道渗漏、地下水污染、路面塌陷等严重后果。城市供水管网漏损率是衡量供水系统管理水平的重要指标，而密封圈质量是影响漏损率的核心因素之一。

20世纪80年代以前，我国管道密封圈的材料标准不统一，各生产企业执行各自的企业标准，材料性能参差不齐，密封圈质量难以保证。随着城市供水、排水管网建设规模不断扩大，特别是大型引水工程、城市污水处理工程的实施，对管道密封圈材料性能提出了更高要求。

国际标准ISO 4633于1984年首次发布，统一了给排水管道密封圈的材料规范。我国于2000年等效采用该国际标准，制定了HG/T 3091-2000，使我国管道密封圈材料标准与国际接轨。该标准的实施对于规范密封圈生产、提升管道工程质量、降低管网漏损率发挥了重要作用。

### 标准制定过程

| 时间节点 | 事件 |
|:---------|:-----|
| 1984年 | ISO发布ISO 4633:1984国际标准 |
| 1990年代 | 国内管道密封圈行业快速发展，亟需统一材料标准 |
| 1998年 | 全国橡胶与橡胶制品标准化技术委员会启动标准制定工作 |
| 2000年 | HG/T 3091-2000正式发布，等效采用ISO 4633:1984 |
| 2002年 | ISO发布ISO 4633:2002修订版 |

## 主要技术内容

### 材料硬度分类

标准按密封圈材料的国际橡胶硬度（IRHD）进行分类，不同硬度等级适用于不同的管道密封场景：

| 硬度等级 | 硬度值 (IRHD) | 硬度公差 | 适用场景 | 典型管径范围 |
|:--------:|:-------------:|:---------:|:---------|:------------|
| 40级 | 40 | ±5 | 大口径管道低压密封，需要高弹性补偿 | DN500~DN2000 |
| 50级 | 50 | ±5 | 通用管道密封，中等压力 | DN200~DN800 |
| 60级 | 60 | ±5 | 标准管道密封，通用压力 | DN100~DN600 |
| 70级 | 70 | ±5 | 较高压力管道密封，刚性要求较高 | DN50~DN300 |
| 80级 | 80 | ±5 | 特殊高压密封，高刚度需求 | DN50~DN200 |

## 试验方法

### 硬度试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 531《硫化橡胶或热塑性橡胶 压入硬度试验方法》 |
| 试样要求 | 试样厚度不小于6mm，面积足够测量3个点 |
| 测量方法 | 用硬度计在试样表面测量，3个测量点间距不小于5mm |
| 结果表示 | 取3次测量中值，结果修约到1 IRHD |

### 拉伸性能试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 528《硫化橡胶或热塑性橡胶 拉伸应力应变性能的测定》 |
| 试样类型 | 1型哑铃形试样（ preferred）或2型哑铃形试样 |
| 拉伸速度 | 500±50 mm/min |
| 测量参数 | 拉伸强度、扯断伸长率、定伸应力 |
| 试样数量 | 不少于5个，取中值 |
| 环境条件 | 温度23±2°C，相对湿度50±5%RH |

### 压缩永久变形试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 7759《硫化橡胶或热塑性橡胶 常温、高温和低温下压缩永久变形测定》 |
| 试验条件 | 70°C×24小时（标准条件） |
| 压缩率 | 25% |
| 试样 | 圆柱形标准试样，直径13mm、高6.3mm |
| 恢复时间 | 从夹具取出后30分钟测量 |
| 结果计算 | 压缩永久变形=(h0-h2)/(h0-h1)×100% |

### 热空气老化试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 3512《硫化橡胶或热塑性橡胶 热空气加速老化和耐热试验》 |
| 试验温度 | 70°C |
| 试验时间 | 7天（168小时） |
| 老化后检测 | 硬度变化、拉伸强度变化率、扯断伸长率变化率 |
| 结果判定 | 硬度变化≤±6 IRHD，拉伸强度变化率≤-15%，扯断伸长率变化率≤-25% |

### 耐水性试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 1690《硫化橡胶或热塑性橡胶 耐液体试验方法》 |
| 浸泡介质 | 蒸馏水或去离子水 |
| 浸泡温度 | 70°C |
| 浸泡时间 | 7天（168小时） |
| 检测项目 | 体积变化率、质量变化率、硬度变化 |
| 结果判定 | 体积变化率≤8% |

### 脆性温度试验

| 项目 | 内容 |
|:-----|:-----|
| 试验标准 | GB/T 1682《硫化橡胶低温脆性的测定 单试样法》 |
| 试验原理 | 试样在低温下冲击，观察是否脆断 |
| 温度梯度 | 每次降低5°C，直至试样出现裂纹 |
| 结果判定 | 脆性温度≤-25°C为合格 |

## 常见问题解答

**Q1: EPDM、FKM和NBR三种橡胶材料各有什么特点？如何选择？**

A: EPDM（三元乙丙橡胶）耐老化、耐温水、耐臭氧性能优异，适合水介质密封，是卫浴产品阀芯密封的首选材料。FKM（氟橡胶）耐高温和耐化学介质性能突出，但价格较高，适用于高温或特殊介质工况。NBR（丁腈橡胶）耐油性好、强度高，适用于含油介质的管路密封。洁博利根据密封部位工作条件选择：阀芯选EPDM、电磁阀选FKM、给排水管选NBR。

**Q2: 密封圈压缩永久变形不合格，对产品有什么影响？**

A: 压缩永久变形反映密封圈在长期压缩后的弹性恢复能力。变形过大意味着密封圈失去弹性补偿能力，无法跟随密封面的微小位移，导致密封力下降，最终发生渗漏。标准要求70°C×24h压缩永久变形≤20%（60级以上）或≤30%（40/50级）。洁博利要求阀芯密封圈压缩永久变形≤15%，高于标准要求，确保50万次启闭寿命。

**Q3: 饮用水管道密封圈的卫生安全有哪些特殊要求？**

A: 饮用水接触的密封圈须符合GB/T 17219《生活饮用水输配水设备及防护材料的安全性评价标准》，具体包括：浸泡液不得增加色度和浑浊度、无异臭异味、重金属（以Pb计）≤0.3mg/L、蒸发残渣≤30mg/L、高锰酸钾消耗量≤10mg/L。洁博利饮用水接触的密封圈全部采用食品级EPDM材料，每年送检卫生安全评价。

**Q4: 密封件硬度等级如何选择？**

A: 硬度选择需综合考虑密封压力、密封间隙和安装要求。低压密封选低硬度（40~50级），弹性好、补偿能力强；中压密封选中硬度（60级），兼顾弹性和强度；高压密封选高硬度（70~80级），抗挤出能力强。洁博利阀芯密封圈承受较高水压，选用70级；管路密封圈压力较低，选用60级，便于安装且密封效果好。

**Q5: 密封件供应商每年审核和每批次抽检的具体内容是什么？**

A: 供应商年度审核内容包括：①质量体系运行情况（ISO 9001证书有效性）；②生产过程控制（混料、硫化工艺参数监控记录）；③检测设备校准状态；④不良品追溯和纠正措施。每批次进料抽检内容包括：①硬度测试（GB/T 531，每批5个样品）；②拉伸强度和扯断伸长率（GB/T 528，每批3个样品）；③外观和尺寸检查（100%外观，关键尺寸抽检）。洁博利通过严格的进料检验确保密封件品质。
