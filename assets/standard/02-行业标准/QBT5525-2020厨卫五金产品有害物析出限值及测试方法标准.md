## 厨卫五金产品有害物析出限量及测试方法

## 1 范围

本标准规定了厨卫五金产品有害物析出的限量要求及测试方法。

本标准适用于厨房、卫生间或类似场合使用，与生活饮用水直接接触的产品，如厨房水嘴、面盆水嘴、直饮水嘴、角阀、进水软管、阀芯、单向阀、起泡器等。

## 4测试方法

## 4.1 原理

用含碳酸氢钠和次氯酸钠模拟自来水浸泡样品表面与水接触部分，用满足测试要求的仪器设备测定浸泡液中金属污染物及有机化合物的浓度。测得的浓度值经标准化处理后再经过数据运算与标准规定的限值比较。

## 4.2 样品

水嘴、软管、角阀等腔体过水类产品：金属污染物析出测试取相同规格样品3个：有机化合物析出测试样品数应满足所取样品的过水体积总和不小于1L。

阀芯、起泡器、单向阀等整体过水类产品：金属污染物析出测试取相同规格样品6个，每2个样品为1组共3组；有机化合物析出测试取相同规格样品6个为1组。测试时需把样品完全拆开。

当满足以下条件时，所测试的样品可以代表其他各种型号的产品系列：

a）材料具有相同合金、成分或配方；

b）设计和制作过程相似；

c）具有最大过水的表面积与体积比。

## 4.3试剂

4.3.1 蒸馏水或去离子水（简称纯水），电导率≤0.1 uS/cm;

4.3.2次氯酸钠(溶液)（分析纯，有效氯含量≥5%）；

4.3.3 无水碳酸氢钠（分析纯）；

4.3.4 浓硝酸（优级纯）；

4.3.5浓盐酸（优级纯）；

4.3.6抗坏血酸（优级纯）；

4.3.7 无水亚硫酸钠（分析纯）；

4.3.8 被测元素的标准溶液。

## 4.4 试验用浸泡液的配制

## 4.4.1 0.025 mol/L 含氯常备溶液

取7.3mL次氯酸钠溶液（4.3.2），用纯水稀释至200mL，贮存于密闭带塞的棕色瓶中，避光保存，此溶液为含氯常备溶液。每周需配制新鲜的溶液。

取1.0mL含氯常备溶液用试剂水稀释至1L，立即分析总余氯，测定值为A。

为了配制余氯浓度为2mg/L的溶液，需要向试验用浸泡液中加入含氯常备溶液的体积，按式（1)计算：

$$
V = ~ { \frac { 2 . 0 \times B } { A } } ~\tag{……………………………………… (1}
$$

式中： $V$ ——需加入含氯常备溶液的体积，单位为毫升（mL）；

$B$ ——试验用浸泡液的体积，单位为升（L）；

$A$ ——含氯溶液总余氯的浓度，单位为毫克每毫升（mg/mL）。

## 4.4.2 0.4 mol/L 碳酸氢钠溶液

将33.6g无水碳酸氢钠溶解于纯水中，并用纯水稀释至1L，充分混匀，每周配制新鲜的溶液。

## 4.4.3 试验用浸泡液

配制1L浸泡液：取25mL 0.4mol/L碳酸氢钠溶液（4.4.2）、适量含氯常备溶液（4.4.1），用纯水稀释至1L，用0.1mol/L盐酸调整pH值，使溶液符合下列要求：pH为 $8 . 0 \pm 0 . 5$ ，碱度(以 $\mathrm { C a C 0 _ { 3 } }$ 计)为 $5 0 0 \mathrm { \ m g / L \pm 2 5 \mathrm { \ m g / L } }$ ，无机碳为 $1 2 2 ~ \mathrm { m g / L } \pm 5 ~ \mathrm { m g / L }$ ，余氯为 $2 . 0 \mathrm { \ m g / L } \pm 0 . 5 \mathrm { \ m g / L }$ 0

按照上述比例配制实际所需要的浸泡液。

## 4.4.4 样品洗涤与稳定化

## 4.4.4.1 水嘴、软管、角阀等腔体过水类产品

用自来水冲洗样品15min，然后用纯水洗涤3次，洗去样品内的残渣和污物。在室温 $2 3 \ \mathrm { ~ \textdegree C } \pm 2 \ \mathrm { ~ \textdegree C }$ 用浸泡液洗涤样品3次，并用浸泡液完全充满样品，浸泡一段时间后将浸泡液倒掉，浸泡时间应不超过72 h。

## 4.4.4.2阀芯、起泡器、单向阀等整体过水类产品

把每组过水部件全部放进容器（金属污染物测试使用聚四氟乙烯容器、有机化合物测试使用棕色玻璃容器）里面，用自来水浸泡样品15min（金属污染物测试用200mL自来水，有机化合物测试用1L自来水)，然后用纯水洗涤3次，洗去样品内的残渣和污物。在室温 $2 3 \ \mathrm { ~ \textbar { ~ } C \pm 2 \mathrm { ~ \textbar { ~ } C ~ } }$ ，用浸泡液洗涤样品3次，并用浸泡液浸泡样品（金属污染物测试用200mL浸泡液，有机化合物测试用1L浸泡液），浸泡一段时间后将浸泡液倒掉，浸泡时间应不超过72h。

## 4.4.5 样品的浸泡

4.4.5.1 样品在 $2 3 \ \mathrm { ~ \textdegree C } \pm 2 \ \mathrm { ~ \textdegree C }$ 条件下进行浸泡。

4.4.5.2水嘴、软管、角阀等腔体过水类产品：在对样品进行洗涤和稳定化后，用浸泡液完全充满样品内腔，根据浸泡液的用量记录样品内部体积。样品两端用包有聚四氟乙烯薄膜的干净软木塞或橡皮塞塞紧。

4.4.5.3阀芯、起泡器、单向阀等整体过水类产品：在对样品进行洗涤和稳定化后，用浸泡液浸泡样品（金属污染物测试用200mL浸泡液，有机化合物测试用1L浸泡液）。

4.4.5.4 浸泡试验按照下面的次序进行19天。测试第1天早8时充入浸泡液，2h后更换一次浸泡液，连续更换四次于16h完成当日浸泡液更换，浸泡液充满或浸泡样品保持16h：第2天早8时按第1天的过程重复进行。第3天、第4天、第5天按照第1天过程重复进行并将保持16h的浸泡液收集起来，第5天16时完成浸泡液更换，再保持64h后倒掉浸泡液。样品进入第8天和第15天重复进行第一个循环的完整浸泡过程。测定铅的浓度取第3，4，5，10，11，12，17，18，19天收集的经过16h浸泡的浸泡液进行测试。非铅元素和有机化合物测试取第19天收集的保持16h的浸泡液进行测试。测试开始时间可以根据实际情况自行安排。样品的浸泡按照图1的次序进行。

## 吹脱捕集/气相色谱一质谱法测定水中挥发性有机化合物方法

## A.1 范围

本方法适用于水样中挥发性有机化合物测试，本方法测定挥发性有机化合物的种类和检出限随仪器和操作条件而变。

## A.2 原理

将被测水样用注射器注入吹脱捕集装置的吹脱管中，于室温下通入惰性气体（氦气），把水样中低水溶性的挥发性有机化合物及加入的内标和标记化合物吹脱出来，捕集在装有适当吸附剂的捕集管内，吹脱程序完成后，捕集管被瞬间加热并以氦气反吹，将所吸附的组分解吸入毛细管气相色谱仪（GC）中，组分经程序升温色谱分离后，用质谱仪（MS）检测。

通过目标组分的质谱图和保留时间与计算机谱库中的质谱图和保留时间作对照进行定性，每个定性出来的组分的浓度取决于其定量离子与内标物定量离子的质谱响应之比。每个样品中含已知浓度的内标化合物，用内标校正程序测定。

## A.3 干扰及消除

## 固相萃取/气相色谱一质谱法测定半挥发性有机化合物方法

## B.1 范围

本方法适用于水样中可被 $\mathrm { C } _ { 1 8 }$ 固相萃取柱吸附并具有热稳定性的有机化合物测试，测试化合物的种类和检出限随仪器和操作条件而变。

## B.2 原理

水样中有机化合物被C8固相萃取柱吸附、用二氯甲烷和乙酸乙酯洗脱，洗脱液经浓缩；用气相色谱毛细柱分离各个组分后，再以质谱作为检测器，进行水中有机化合物的测定。

通过目标组分的质谱图和保留时间与计算机谱库中的质谱图和保留时间作对照进行定性，每个定性出来的组分的浓度取决于其定量离子与内标物定量离子的质谱响应之比。每个样品中含已知浓度的内标化合物，用内标校正程序测定。

## B.3 干扰及消除

B.3.1 分析过程中，污染的主要来源是试剂和固相萃取装置。现场空白和实验室试剂空白可提供污染存在的信息。

B.3.2 污染也可能发生在分析高浓度样品后立即分析低浓度样品，注射器和无分流进样口应彻底清洗或更换，以去除此类污染。分析过程如遇到高浓度样品时，应紧随着分析溶剂空白，以保证样品没有交叉污染。

## B.4.5 标准溶液

## B.4.5.1 标准储备液

可直接购买具有标准物质证书的标准溶液。标准储液应包含所有相关的分析组分、内标及标记物。也可用纯的标准参考品制备（称重法），使用预先确认过成分纯度的标准参考品来制备，以甲醇、乙酸乙酯或丙酮为溶剂的标准储备液，常用浓度为1 $\mathrm { m g / L } { \sim } 5 \ \mathrm { m g / L }$ 0

制备方法：准确称取10.0 mg标准参考品放于2 mL容量瓶中，加入约 1.8mL甲醇、乙酸乙酯或丙酮溶解，定容到刻度。把标准储备液转移到安瓿瓶中于4℃以下保存。多环芳烃的标样用甲苯作为溶剂。

## B.4.5.2 标准中间液

将标准储备液（B.4.5.1）用丙酮或乙酸乙酯稀释配制成所需的单一或混合化合物的标准中间液。将标准中间液转移到安瓿瓶中于4℃以下保存。

## B.4.5.3 内标及标记物添加液

用甲醇、乙酸乙酯或丙酮配制浓度为500μg/mL的二氢苊 $\mathrm { - d } _ { 1 0 } ,$ 菲 ${ \bf - d } _ { 1 0 }$ 和䓛 $- \mathrm { d } _ { 1 2 }$ 内标溶液，作为制备校准曲线用；将内标液稀释10倍后，使其浓度为 $5 0 ~ \mathrm { ~ \textmu ~ g / m L }$ ，该混合液要加到样品和空白中。用甲醇、乙酸乙酯或丙酮配制浓度为 $5 0 0 ~ \mathrm { ~ \textmu ~ g / m L }$ 和 $5 0 ~ \mathrm { ~ \textmu ~ g / m l }$ 的1，3-二甲基-2-硝基苯、花 ${ \bf - d } _ { 1 0 }$ 和三苯基膦的标记溶液，分别作为标准和添加用。内标和标记物添加液放于安瓿瓶中 $4 \mathrm { ~ } ^ { \circ } \mathrm { C }$ 以下保存。

## B.4.5.4 GC-MS性能校准液

用二氯甲烷配制浓度为5.0μg/mL的十氟三苯基膦（DFTPP）、艾氏剂、4，4’-双对氯苯基三氯乙烷校准液，放于安瓿瓶中4℃保存。

## B.4.5.5 标准使用液

用乙酸乙酯将一定量的标准中间液（B.4.5.2）（五氯酚除外）配制成浓度为0.1μ $\mathrm { g / m L }$ 、0.5 μg/mL、1μg/mL、2 μg/mL、5μg/mL、10μg/mL，内标和标记物浓度均为5μg/mL的标准使用液。所有的标准使用液需含有80%以上的乙酸乙酯以防止气相色谱的问题。如果要分析方法中的所有化合物，需配制（2～3）套标准使用液。

在标准使用液中，五氯酚浓度为其他组分浓度的4倍。

标准使用液放于安瓿瓶中避光 $4 \mathrm { ~ \ } ^ { \circ } \mathrm { C }$ 以下保存，经常检查是否发生降解。

## B.5仪器

B.5.1固相萃取装置：包括真空泵、支架和 $\mathrm { { I C } _ { 1 8 } }$ 固相萃取柱。

B.5.2 洗脱装置。

B.5.3 干燥柱：装有（5\~7）g无水硫酸钠的玻璃柱。

B.5.4 微量注射器：10μL。

B.5.5 分析天平：可准确称重至 0.1 mg。

B.5.6 小样品瓶：2 mL，供配制标准品用。

B.5.7 样品瓶：1000 mL，带螺旋盖及聚四氟乙烯垫片的棕色玻璃瓶。

B.5.8气相色谱仪：可程序升温，所有的玻璃元件（如进样口插件）均是用硅烷化试剂处理脱活。

B.5.9 气相色谱柱：DB-5MS柱或等同石英毛细色谱柱 $3 0 \ \mathrm { m } { \times 0 . 2 5 } \ \mathrm { m m }$ (内径)，液膜厚度0.25μm。

B.5.10 质谱仪：当注射进约 5ng DFTPP时，GC-MS系统所产生的质谱应符合表B.3的要求。性能测试要求仪器参数为：电子能量 70 eV，质量范围 35 amu\~500 amu，扫描时间为每个峰至少有 5次扫描，但每次扫描不超过1s。

## B.6 仪器条件

B.6.1 气相色谱仪条件如下：

a)气化室温度：300℃；

b) 柱温：起始温度 45℃ 保持 1 min，以 40 ℃/min 升温至 130℃，再以 12 ℃/min 升到180℃，再以7 ℃/min升到240 ℃，再以 12 ℃/min 升到 320℃;

c）检测器温度：300℃；

d)载气（氦气）线速度：33 cm/s，不分流方式。

## B.6.2 质谱条件如下：

a)离子化方式：EI，70 eV;

b) 质谱扫描范围：45 amu\~450 amu，4 min 时开始采集数据；

c) 离子源温度：280℃；

d) 扫描时间：每一尖峰至少有5次扫描，且每一次扫描不得超过0.7s。

## B.8 操作步骤

## B.8.1 样品前处理

## B.8.1.1 固相萃取

B.8.1.1.1 活化：每一个固相萃取柱分别用 5 mL 二氯甲烷、5 mL 乙酸乙酯、10 mL 甲醇和 10 mL纯水活化，活化时不要让甲醇和水流干（液面不低于吸附剂顶部)。

B.8.1.1.2 吸附：把1 L 水样倒入固相萃取装置的分液漏斗中，用盐酸（B.4.3）调节pH小于2，加入5mL甲醇，混匀，加入100μL浓度为 $5 0 ~ \mathrm { ~ \textmu ~ g / m L }$ 的内标及标记物添加液(B.4.5.3)，立刻混匀，加标物在水中的浓度为5.0μg/L。水样以约 15 mL/min 的流量通过固相萃取柱。

B.8.1.1.3 干燥：用氮气干燥固相萃取柱（吹约10 min）。

## B.8.1.2 洗脱

B.8.1.2.1 把 125 mL的分液漏斗和固相萃取柱转移到洗脱装置中。用5 mL 乙酸乙酯洗 2 L 分液漏斗和样品瓶，通过固相萃取柱进入收集瓶，再用5mL二氯甲烷洗分液漏斗和样品瓶，通过固相萃取柱进入同一收集瓶。

B.8.1.2.2 使洗脱液通过干燥柱中并用10 mL 收集管收集，用2 mL 二氯甲烷洗干燥柱，液体收集于同一收集管。

B.8.1.2.3洗脱液在 45℃下，用氮气吹至约0.5 mL，用乙酸乙酯定容至1mL。

## B.8.2 标准曲线的绘制

分别取5种不同浓度的标准使用液(B.4.5.5)1.0μL进样测定，以测得的峰面积分别对相应的标准物浓度绘制标准曲线。

## B.8.3 样品的测定

取1.0 μL样品在与标准曲线相同的条件下进样分析。

## B.9 质量控制

## B.9.1 质量控制的要求

通过试剂空白、标准样品和加标样品的分析证明实验室的分析能力，应确定每个化合物的方法检出限（MDL）。实验室要有记录数据质量的文件，建议有质量管理规范。

## B.9.2 固相萃取系统的空白实验

B.9.2.1 在样品分析之前，或新购固相萃取管后，应做空白实验，保证分析的化合物不会受到污染。

B.9.2.2 影响检测的潜在污染源是萃取管中有邻苯二甲酸酯、硅酮和其他污染物。尽管固相萃取管是用惰性材料制成，但它们仍有邻苯二甲酸酯类化合物。邻苯二甲酸酯类化合物能溶于二氯甲烷和乙酸乙酯中，使水样本底变化，如果污染物的本底影响测定的准确性和精度，那么实验前就应进行处理。

B.9.2.3 本底污染的其他来源有溶剂、试剂和玻璃容器。本底污染应该控制在可接受的范围内，通常应低于方法检出限。

B.9.2.4 萃取时间不宜变化太大。

## B.9.3 准确度和精密度

B.9.3.1 分析 4个\~7个浓度为 $2 \ \textrm { \textmu g } / \mathrm { L } { \sim } 5 \ \textrm { \textmu g } / \mathrm { L }$ 的标准样品，根据仪器的灵敏度，浓度应选择在校正曲线的中间范围。

B.9.3.2 根据样品组分添加亚硫酸钠或盐酸，用标准原液或质控样加到试剂水中，配制标准样品。

B.9.3.3测出标准样品中每个组分的浓度、平均浓度、平均准确度（真值的百分比）、精密度（相对标准偏差，RSD)。

B.9.3.4 每个待测化合物和内标化合物的准确度应在 70%～130%，RSD应小于30%，如果不符合这个标准，应查找问题的来源，配制新的标准样品，重新测定。

B.9.3.5 配制 7个包含所有待测组分的标准样品，每个组分的浓度为 0.5 μg/L 左右，计算出每个组分的方法检出限。建议分析过程跨越3 ${ \mathrm { d } } \sim 4 { \mathrm { ~ d } }$ ，这样更符合实际的方法检出限。

B.9.3.6 绘制待测化合物和内标化合物检测准确度和精密度对时间的质量控制图。内标化合物回收率的质量控制图很有用，因为它们加在所有的样品中，他们的分析结果对分析质量有显著的影响。

B.9.3.7 连续监测内标化合物定量离子的峰面积。在标准样品或加标样品分析中，虽然内标化合物定量离子的峰面积不恒定，但它们与标准样品峰面积的比率应合理稳定。建议加 10 μL浓度为500 μg/mL的三联苯-d14做回收率测定标准，内标回收率应大于70%。

B.9.3.8 同一批次的样品在12h内应做一次空白实验，以确定系统的背景污染状况。当更换新的固相萃取管或试剂时，也要进行本底空白实验。

B.9.3.9 同一批次的样品可以进行一个标准样品分析。如果样品量超过20个，应每20个样品增加一个标准样品分析。如果准确度达不到要求，应查处原因并解决，将结果记录下来，加到质量控制图中。

B.9.3.10 检测样品基体是否含有影响测定结果的物质，可以通过基体加标样品的测定来完成，确定基体加标样品的准确度、精密度及检出限是否与无基体干扰时一致。

B.9.3.11 同一批次的样品应做一个现场试剂空白，以确认污染是由采样现场产生的，还是由样品转运过程中产生的。

B.9.3.12 至少每季度分析一次外面来源的质控样品。如果结果不在允许范围内，检查整个分析过程，找出问题的原因并纠正。

B.9.3.13 还有大量其他的质量控制措施可结合在这个过程的其他方面，提醒分析人员一些潜在的问题。

## B.10 结果处理

## B.10.1 定性分析

本方法中测定的各化合物的定性鉴定是根据保留时间和扣除背景后的样品质谱图与参考质谱图中的特征离子比较完成的。参考质谱图中的特征离子被定义为最大相对强度的三个离子，或者任何相对强度超过30%的离子。

## B.10.2 定量分析

用5种不同浓度的标准品（其中内标的浓度恒定）绘制标准曲线，该曲线的纵坐标为组分定量离子峰面积 $A _ { x }$ 与其浓度 $c _ { x }$ 之比，横坐标为内标的定量离子峰面积 $A _ { i s }$ 与其浓度 $c _ { i s }$ 之比。由此求得响应因子$R F$ o

实际样品在测定前加入同样浓度的内标，测得未知物的定量离子峰面积 $A _ { x }$ 后，通过校准曲线并根据式（B.1）计算实际样品浓度 $c _ { x }$ …

$$
c _ { x } \ = \frac { ( A _ { x } \times \mathcal { Q } _ { i s } ) } { ( A _ { i s } \times R F \times V _ { s } ) }\tag{…}
$$

(B.1)

式中：

$c _ { x }$ ——实际样品被测组分浓度，单位为微克每升（μg/L）；

$A _ { x }$ ——各组分定量离子峰面积；

$Q _ { i s }$ ——加入水样中内标物质，单位为微克（μg）；

$A _ { i s }$ ——内标物定量离子峰面积；

$R F$ —— 响应因子；

$V _ { s }$ ——水样体积，单位为升（L）。
