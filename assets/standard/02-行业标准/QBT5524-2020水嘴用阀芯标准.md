## 水嘴用阀芯

## 1 范围

本标准规定了水嘴用阀芯(以下简称“阀芯”)的术语和定义、分类、材料、要求、试验方法、检验规则、标志、包装、运输和贮存。

本标准适用于安装在水嘴中，工作压力(静压)不大于1.0MPa、供水温度4℃至90℃条件下使用的各类阀芯。

本标准不适用于恒温阀芯、恒压阀芯。

## 3 术语和定义

GB/T 33733界定的及下列术语和定义适用于本文件。

3.1

水嘴用阀芯 cartridges for faucet

安装在水嘴中，用于启闭或调节流量和/或出水温度的一种装置。

## 3.2

机械阀芯 mechanical cartridge

采用机械传动方式实现启闭功能的阀芯。

## 3.3

电磁阀芯 electromagnetic valve

通过控制电磁铁电流的通断，实现启闭功能的阀芯。

## 3.4

切换阀芯 switch valve

实现水嘴出水的模式和/或方向改变的阀芯。

## 4 分类

4.1 按控制方式分为机械阀芯和电磁阀芯。

4.2机械阀芯按品种分为单柄单控阀芯、单柄双控阀芯、提拉切换阀芯、旋转切换阀芯、延时自闭阀芯、按压阀芯等。

## 5 材料

5.1与水接触的材料，在本标准规定的使用条件下，不应对人体健康造成危害，不应对水造成任何水质、外观、味觉、嗅觉上的变化。

5.2 与水接触的部件不应使用锌合金等易被腐蚀的材料。

5.3 与饮用水接触的金属材料铅含量应不大于1.9%。

5.4 不锈钢材料应采用GB/T 20878-2007中规定的06Cr19Ni10或采用耐腐蚀性能不低于上述牌号的其他不锈钢材料。

5.5 机加工铜件材质应符合 GB/T 5231 的规定。

5.6 润滑剂应采用食品级或饮用水级。

5.7 其他材料应符合相应的国家标准或行业标准。

## 6 要求

## 6.1 外观

6.1.1阀芯表面应光洁、平整，不得有缺料、裂纹、毛刺、锐边等缺陷。

6.1.2陶瓷片密封表面不应有崩瓷、缺角、裂纹、针孔和划痕等缺陷。

6.1.3塑料件表面不应有明显的填料斑、波纹、溢料、缩痕、翘曲和熔接痕，也不应有明显的擦伤、划伤等不良现象。

6.1.4橡胶件表面不应有流痕、开模缩裂、飞边、杂质、凹痕等缺陷。

6.1.5螺纹表面应光洁，不应有毛刺、凹痕、断牙等明显缺陷。

6.2 加工与装配

6.2.1 安装连接管螺纹应符合 GB/T 7306.1 或 GB/T 7306.2 或 GB/T 7307 或 GB/T 197 的规定。

## 6.2.2 有效连接螺纹牙数应不少于3牙。

## 6.3 尺寸

几种典型的阀芯安装尺寸应满足附录A的规定。其他阀芯的尺寸由供需双方协商确定。

## 6.4 有害物析出限量

应满足QB/T XXXX《厨卫五金产品有害物析出限量及测试方法》的规定。

注：淋浴专用阀芯不适用于本条款。

## 8 检验规则

## 8.1 检验分类

产品检验分出厂检验和型式检验。

## 灵敏度试验

## C.1 原理

通过测量从 $T _ { \mathrm { m } } { - } 4 \mathrm { ~ \ ` ~ C } { \sim } T _ { \mathrm { m } } { + } 4$ ℃的温度变化区间（温度变化为8K）阀芯的转动角度评价其灵敏度。注： $T _ { \mathrm { n } } \mathrm { = } \ \left( T _ { \mathrm { c } } { + } T _ { \mathrm { h } } \right) / 2$

## C.2 测试步骤

C.2.1 将按7.5.1安装好的阀芯安装在试验设备上，测试压力为 $0 . 3 0 \mathrm { M P a } \pm 0 . 0 2 \mathrm { M P a }$ 、冷水温度（T）为 $1 0 \mathrm { ~ \~ } ^ { \circ } \mathrm { C } \sim 1 5 \mathrm { ~ \~ } ^ { \circ } \mathrm { C }$ 、热水温度（T）为 $6 0 \mathrm { ~ \~ } ^ { \circ } \mathrm { C } \sim 6 5 \mathrm { ~ \~ } ^ { \circ } \mathrm { C }$ 、中间位置的出水流量为12.5 $_ { \mathrm { L } / \mathrm { m i n } \pm 1 . 0 \mathrm { ~ L } / \mathrm { m i n } }$ 冷/热水温度波动应不大于±1K、冷/热供水温差应不小于50K。

C.2.2 在C.2.1的条件下，阀芯以0.5°/s的速率从冷水端转动到热水端，然后从热水端返回到冷水端，过程中绘制出水温度与转动角度的变化曲线，如图C.1。
