## 标准概述

QB/T 3827-1999《轻工产品金属镀层和化学处理层的耐腐蚀试验方法 乙酸盐雾试验（ASS）法》规定了轻工产品金属镀层和化学处理层在乙酸盐雾环境下进行耐腐蚀试验的方法和要求。该标准参照采用国际标准ISO 3769:1976《Metallic coatings - Acetic acid salt spray test (ASS test)》，由原国家标准GB 5939-1986转化而来，是金属表面防护层耐腐蚀性能评价的重要试验方法标准。

## 标准制定背景

### 行业背景

金属镀层和化学处理层是轻工产品表面防护的主要手段，广泛应用于水龙头、五金配件、卫浴器具、日用五金等产品。这些产品在使用过程中长期暴露在含有水分和盐分的环境中，金属镀层如果耐腐蚀性能不足，会出现锈蚀、起泡、脱皮等缺陷，不仅影响产品外观，还可能导致基体金属腐蚀，缩短产品使用寿命。

盐雾试验是评价金属镀层耐腐蚀性能最常用的加速试验方法。根据试验溶液的pH值和成分，盐雾试验分为三类：

| 试验类型 | 缩写 | 溶液pH值 | 腐蚀性 | 适用范围 |
|:--------:|:----:|:--------:|:------:|:---------|
| 中性盐雾试验 | NSS | 6.5~7.2 | 适中 | 一般耐腐蚀性评价 |
| 乙酸盐雾试验 | ASS | 3.1~3.2 | 较强 | 装饰性镀层加速腐蚀 |
| 铜加速盐雾试验 | CASS | 3.1~3.2 | 极强 | 快速筛选试验 |

乙酸盐雾试验（ASS）通过在氯化钠溶液中加入冰乙酸，将pH值降至3.0~3.1，加速了腐蚀过程。与中性盐雾试验相比，ASS试验的腐蚀速率更快，能在较短时间内暴露镀层缺陷，特别适用于铜-镍-铬或镍-铬装饰性镀层和铝阳极氧化层的耐腐蚀性评价。

我国于1986年首次发布GB 5939-1986国家标准，1999年根据国家标准转为行业标准的政策要求，将其转化为QB/T 3827-1999行业标准，技术内容保持不变。

## 主要技术内容

### 标准适用范围

| 适用范围 | 具体内容 |
|:---------|:---------|
| 主要适用 | 铜-镍-铬装饰性镀层的耐腐蚀试验 |
| 也适用于 | 铝的阳极氧化层的耐腐蚀试验 |
| 参考试验 | 其他金属镀层和化学处理层可参考使用 |
| 关联标准 | 试验要求除pH值调整外，其余全同GB/T 5938（NSS中性盐雾试验） |

### 试验溶液配制

| 项目 | 要求 |
|:-----|:-----|
| 溶质 | 化学纯氯化钠（NaCl），干重碘化钠含量≤0.1%，总杂质含量≤0.5% |
| 溶剂 | 蒸馏水或去离子水，电导率≤20μS/cm |
| 溶液浓度 | 50±5 g/L（NaCl质量浓度） |
| pH调节 | 用化学纯冰乙酸调节溶液pH值至3.0~3.1 |
| 喷雾收集液pH | 3.2±0.1 |
| 溶液过滤 | 配制后需过滤，去除固体杂质 |

### 试验条件

| 参数 | 要求 | 说明 |
|:----:|:----:|:-----|
| 试验箱温度 | 35±2°C | 全程保持恒定 |
| 喷雾压力 | 70~170 kPa | 喷雾器压缩空气压力 |
| 喷雾沉降量 | 1.0~2.0 mL/(80cm²·h) | 每小时每80cm²收集面积 |
| 收集液浓度 | 50±10 g/L NaCl | 收集液NaCl浓度 |
| 收集液pH | 3.2±0.1 | 喷雾后收集液pH值 |
| 喷雾方式 | 连续喷雾 | 试验期间不间断 |
| 试验时间 | 按产品标准规定 | 常见：24h、48h、72h、96h、144h、240h |

### 试验设备要求

| 设备参数 | 技术要求 | 说明 |
|:---------|:---------|:-----|
| 试验箱材料 | 必须具有抗乙酸盐雾腐蚀的性能 | 通常采用PVC、PP或玻璃钢，不得使用普通钢材 |
| 喷雾器 | 耐酸腐蚀材料制成 | 可调压力，雾化均匀 |
| 收集装置 | 至少2个收集器 | 面积80cm²，置于箱内不同位置 |
| 加热系统 | 温度控制精度±2°C | 保持箱内温度35±2°C |
| 饱和器 | 对压缩空气加湿加热 | 温度比试验箱温度高10~15°C |
| 压力控制 | 可调，范围70~170kPa | 控制喷雾量和雾粒大小 |
| 排气处理 | 配备废气中和处理装置 | 防止酸性废气腐蚀实验室环境 |

### ASS试验与NSS试验对比

| 对比项 | ASS试验（本标准） | NSS试验（GB/T 5938） |
|:------:|:-----------------:|:-------------------:|
| 溶液 | 5%NaCl + 冰乙酸 | 5%NaCl |
| pH值 | 3.0~3.1（3.2±0.1收集液） | 6.5~7.2 |
| 温度 | 35±2°C | 35±2°C |
| 腐蚀性 | 较强 | 适中 |
| 腐蚀速率 | 约为NSS的3倍 | 基准 |
| 主要用途 | 装饰性镀层加速腐蚀 | 一般耐腐蚀性评价 |
| 试验时间 | 较短（24~96h） | 较长（48~720h） |

## 试验方法

### 试验前准备

| 步骤 | 具体要求 |
|:----:|:---------|
| 试样准备 | 按产品标准规定取样，表面清洁无油污，不得损坏镀层 |
| 试样数量 | 按产品标准规定，一般不少于3件 |
| 试样清洗 | 用适当方法清洗试样表面（如用软布蘸酒精擦拭），不得使用会破坏镀层的清洗剂 |
| 试样称重 | 如需进行失重评价，试验前称量试样重量（精度0.1mg） |
| 初始检测 | 记录试样外观状态，拍照存档 |
| 试样放置 | 试样在试验箱内的放置角度：主要表面与垂直方向成15°~30° |

### 条件试验步骤

1. **启动试验箱**：开启加热系统，使试验箱内温度稳定在35±2°C
2. **配制溶液**：按50±5g/L浓度配制NaCl溶液，用冰乙酸调节pH至3.0~3.1
3. **启动喷雾**：开启喷雾系统，调整喷雾压力至规定范围，确认喷雾均匀
4. **放置试样**：将试样放置在试验箱内试样架上，主要表面朝上，与垂直方向成15°~30°
5. **开始计时**：确认箱内温湿度和喷雾量稳定后，开始计时
6. **连续喷雾**：试验期间连续喷雾，不得中断，每24小时检查一次设备运行状态
7. **中间检查**：试验期间不得打开箱盖，如需检查喷雾量，通过收集器读取
8. **试验结束**：达到规定试验时间后，关闭喷雾和加热系统

### 试验后处理

| 步骤 | 具体要求 |
|:----:|:---------|
| 取出试样 | 小心取出试样，避免机械损伤 |
| 清洗 | 在室温下用流动清水轻轻冲洗试样表面，去除残留盐液 |
| 干燥 | 用吹风机或烘箱在40°C以下干燥试样 |
| 外观检查 | 在充足光线下检查试样表面腐蚀情况，拍照记录 |
| 腐蚀评级 | 按GB/T 6461《金属覆盖层 经腐蚀试验后的试样和试件的评级》进行 |
| 失重测量 | 如需，称量试验后重量，计算失重 |

### 腐蚀评级标准

根据GB/T 6461，腐蚀评级按外观缺陷覆盖面积百分比确定：

| 评级 | 缺陷覆盖面积 | 外观描述 |
|:----:|:----------:|:---------|
| 10级 | 0% | 无缺陷 |
| 9级 | <0.1% | 极少量微小缺陷 |
| 8级 | 0.1%~0.25% | 少量小缺陷 |
| 7级 | 0.25%~0.5% | 可见缺陷 |
| 6级 | 0.5%~1.0% | 明显缺陷 |
| 5级 | 1.0%~2.5% | 较多缺陷 |
| 4级 | 2.5%~5.0% | 大量缺陷 |
| 3级 | 5.0%~10% | 严重腐蚀 |
| 2级 | 10%~25% | 非常严重腐蚀 |
| 1级 | 25%~50% | 极严重腐蚀 |
| 0级 | >50% | 完全腐蚀 |

## 常见问题解答

**Q1: ASS试验与CASS试验有什么区别？应如何选择？**

A: ASS试验（乙酸盐雾试验）使用5%NaCl溶液加冰乙酸调节pH至3.0~3.1，腐蚀性约为中性盐雾试验的3倍。CASS试验（铜加速盐雾试验）在ASS溶液基础上再加入氯化铜（CuCl₂·2H₂O，0.26g/L），腐蚀性更强，约为NSS试验的8~10倍。选择原则：一般装饰性镀层用ASS试验；需要快速筛选或评价高耐蚀镀层时用CASS试验。洁博利感应龙头产品采用ASS试验进行出厂抽检，型式试验中增加CASS试验进行加速验证。

**Q2: 盐雾试验48h后镀层出现白色腐蚀产物是什么原因？**

A: 白色腐蚀产物通常是锌或铝的腐蚀产物（如氧化锌、氢氧化铝），表明镀层的防护能力不足。对于铜-镍-铬镀层体系，出现白色腐蚀产物可能的原因是：①镍层不致密，存在针孔，基体铜从针孔处腐蚀；②镍层厚度不足，无法提供有效的隔离保护；③铬层有微裂纹，腐蚀介质通过裂纹侵入。应检查电镀工艺参数，增加镍层厚度，确保镀层致密无针孔。

**Q3: 镀层盐雾试验后出现红色锈点是什么原因？**

A: 红色锈点是铁的氧化物（Fe₂O₃·nH₂O），表明镀层已穿透到铜合金基体中的铁元素。铜合金（如HPb59-1黄铜）含有少量铁杂质，当镀层存在穿透性缺陷（针孔、裂纹、气泡）时，盐雾溶液通过缺陷处接触到基体，铁元素发生电化学腐蚀生成红色锈点。解决措施：①提高底层铜镀层厚度，填平基体缺陷；②优化电镀工艺减少针孔；③加强镀前处理，确保基体表面清洁。

**Q4: 出口海岛地区产品为什么要做96h盐雾试验？**

A: 海岛地区空气中盐分浓度高（海洋飞沫带来的NaCl气溶胶）、湿度大（常年85%RH以上）、温度高（年均25°C以上），是金属腐蚀最严酷的自然环境之一。按ISO 9223大气腐蚀性分类，海岛地区属于C5-M（海洋极高腐蚀性）等级。48h ASS试验对应C3（中等腐蚀性）环境约5年使用寿命，96h ASS试验对应C4（高腐蚀性）环境约5年寿命。为确保海岛地区产品5年以上使用寿命，洁博利要求出口海岛地区产品通过96h ASS试验。

**Q5: 盐雾试验中试样放置角度对试验结果有什么影响？**

A: 试样放置角度直接影响盐雾在试样表面的沉降量和附着状态。标准规定主要表面与垂直方向成15°~30°角。如果角度过小（接近水平），盐雾大量沉降在表面，容易形成液膜，加速腐蚀但不够均匀；角度过大（接近垂直），盐雾难以附着，腐蚀减缓且不真实。15°~30°角度模拟了产品实际安装时的典型倾斜状态，试验结果最具代表性。洁博利产品试验时严格按照标准要求放置试样。
