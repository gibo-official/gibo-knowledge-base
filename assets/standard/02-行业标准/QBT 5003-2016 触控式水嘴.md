## 触控式水嘴

## 1 范围

本标准规定了触控式水嘴的术语和定义、分类及命名、使用条件、材料、配套装置、技术要求、试验方法、检验规则及标志、包装、运输和贮存。

本标准适用于安装在建筑物内的冷、热水供水管路末端，工作压力（静压）不大于0.6MPa、供水温度5℃至90℃条件下的触控式水嘴。

## 3 术语和定义

下列术语和定义适用于本文件。

## 3.1

## 触控式水嘴 touch-sensitive faucet

直接触摸水嘴或水嘴的某一部件，或根据触屏装置的信息直接触摸屏幕或按键，通过控制器实现用户需求（如出水、流量、温度、出水方向等控制）的水嘴。（以下简称“水嘴”）

## 3.2

## 触屏装置 touch screen device

由显示屏、触摸按钮等部件组成的供使用者开、关出水及调节出水温度、流量和出水方向的装置。

## 3.3

## 控制器 controller

由传感器、智能化逻辑处理、驱动等电子电路组成，能控制电动阀门启闭的组件。

## 3.4

响应时间 responding time

从触控到执行的时间。

## 3.5

## 整机 compelete type

由控制器、电动阀门、电源、触屏装置及阀体等部件组成的整套产品。

## 3.6

## 抽取式水嘴 pullout spout faucet

带连接软管的出水口，抽拉软管出水口在一定范围内可移动的水嘴。

## 3.7

## 混合水嘴 mixing faucet

可调节冷、热进水比例并混合、启闭供水的水嘴。

## 4 分类及命名

## 4.1 分类

4.1.1 按水嘴控制进水管路的数量分为单控和双控两类。

4.1.2按用途分为厨房水嘴、洗面器水嘴、淋浴水嘴、浴缸水嘴和浴缸/淋浴水嘴。

4.1.3 按出水温度分为单冷水嘴、单热水嘴和混合水嘴。

4.1.4按出水口的状态分为固定出水口水嘴、旋转式水嘴、抽取式水嘴和带喷枪水嘴。

4.1.5 按调节温度方式分为自动调温和手动调温两类。

## 4.2 命名

产品的命名宜包含控制方式、进水管路的数量及用途。

示例：

控制进水管路的数量为双控，用途为淋浴水嘴的产品可命名为：触控式双控淋浴水嘴。

## 5 使用条件

水嘴在下列条件下应能正常使用：

a) 环境温度：1℃\~55℃；

b) 环境相对湿度（RH）：≤93%;

c) 工作压力：0.05 MPa\~0.6 MPa;

d) 介质使用温度： $5 \ \mathrm { { ^ \circ C } } \sim 9 0 \ \mathrm { { ^ \circ C } }$ 0

## 6 材料

6.1 水嘴使用的所有与饮用水接触的材料，在本文件规定的使用条件下，不应对人体健康造成危害，不应对饮用水造成任何水质、外观、味觉、嗅觉等变化。

6.2 水嘴与水接触的部件不应使用锌合金等易腐蚀性材料。在保证水嘴性能的条件下，其所使用的材料应符合相应的材料标准。

## 7 配套装置

7.1 与淋浴水嘴和浴缸/淋浴水嘴配套的花洒应符合 GB/T 23447的规定。

7.2 与水嘴配套的软管应符合 GB/T 23448 的规定。

7.3 与水嘴配套的排水配件应符合JC/T 932的规定。

## 8 技术要求

## 8.1 外观质量

8.1.1 镀层表面光泽均匀，不应有脱皮、龟裂、烧焦、露底、剥落、黑斑及明显麻点、毛刺等缺陷。

8.1.2 喷涂表面组织细密、光滑、色泽均匀，不应有流挂、露底及明显的划伤和磕碰等缺陷。

8.1.3 抛光表面应光滑，不应有明显毛刺、划痕和磕碰等缺陷。

8.1.4 所有金属件不应有锈蚀。

## 8.2 加工与装配

8.2.1 产品外接密封管螺纹应符合 GB/T 7306.1 或 GB/T 7306.2 的要求；产品外接非密封管螺纹应符合GB/T 7307的要求，其中外螺纹不应低于 GB/T 7307的 B 级精度。

8.2.2 螺纹表面不应有凹痕、断牙等明显缺陷。

8.2.3 铸件不应有缩孔、裂纹和气孔等缺陷。

8.2.4塑料件表面不应有明显的填料斑、波纹、溢料、缩痕、翘曲和熔接痕，也不应有明显的擦伤、划伤、修饰损伤和污垢。

8.2.5 触摸装置面板上的标记应简洁易懂，按扭或触摸键明显、并留有间隙。

8.2.6冷、热水混合水嘴应有清晰的冷热水位标记。冷水用蓝色或字母“C”或“冷”字表示，热水用红色或字母“H”或“热”字表示，或其他易于识别的标记。

8.3 金属污染物析出限量（适用于洗面器及厨房水嘴）

铅析出统计值（Q）不大于5μg/L，非铅元素的析出量不应大于表1规定的限值。

## 8.4 电气性能

## 8.4.1 电气安全

水嘴电气部分的安全性能应符合GB4706.1的要求。

## 8.4.2 外壳防护等级

水嘴电气部分的外壳防护等级采用GB4208-2008的IPX4。

## 8.4.3 电磁兼容性

水嘴电气部分的发射应符合GB4343.1的要求，抗扰度应符合GB4343.2的要求。

## 8.4.4 电动阀性能

水嘴所使用的电动阀应符合GB14536.9的要求。

## 8.5 5尺寸

水嘴的尺寸应符合GB18145-2014的规定，特殊形式与尺寸按合同规定。

## 8.6 使用性能

## 8.6.1 涂、镀层附着强度

## 8.6.1.1 涂层附着强度

按照9.6.1.1进行划格试验，应达到1级要求。

## 8.6.1.2 金属基体镀层附着强度

按照9.6.1.2进行热震试验后，不应出现裂纹、起皮或脱落现象。

## 8.6.1.3 塑料基体镀层附着强度

按照9.6.1.3进行试验后，表面应无裂纹、水泡、疏松等现象。

## 8.6.2 表面耐腐蚀性能

水嘴整机按照9.6.2进行酸性盐雾试验后，不应低于GB/T6461—2002的表1中外观评级 $( R _ { \mathrm { { A } } } )$ 9级的要求。

## 8.6.3 防回流性能

抽取式水嘴及带喷枪的厨房水嘴应有防回流功能，按照9.6.3进行试验，不应有虹吸现象产生。

## 8.6.4 控制面板灵敏度及温度显示偏差

在使用寿命周期内，触摸装置显示清晰、触摸按钮响应时间不应大于200ms，触摸屏幕显示的温度与水嘴实际出水温度偏差绝对值不大于2℃。

## 8.6.5 初始温度设定

具备自动调温功能的水嘴初始出水温度不应大于49℃。

## 8.6.6 断电和欠压保护

## 8.6.6.1 断电保护

水嘴在开启状态下电源中断时，应能自动关闭；水嘴在关闭状态下电源中断时，应能保持关闭状态。

## 8.6.6.2 欠压保护

水嘴电源电压降至设定的欠压保护值时，应具有提示功能；当欠压至不能正常工作时，水嘴应自动关闭。

## 8.6.7 停水保护

水嘴开启后不再操作时，应在厂商明示的时间内自动关闭。

## 8.7 电池盒

电池供电的产品，电池应放入独立密封的电池盒内，应方便更换电池或充电，电池盒应易拆装，不应破损，螺丝不应溢扣。经耐湿试验后应能正常工作，盒内金属部件不应有锈蚀现象。

## 8.8 阀体强度

阀体强度性能应符合GB18145-2014中7.6.1的规定。

## 9 试验方法

## 9.1 外观质量

产品表面质量用目测检查。目测时应在自然散射光线下或在无反射光的白色透明光线下进行，光照度不应低于3001x。

## 9.2 加工与装配

9.2.1 螺纹精度用测量该精度等级的螺纹量规检测。

9.2.2 标记和外表面缺陷用目测检查。

## 9.3 金属污染物析出限量（适用于洗面器及厨房水嘴）

按照GB18145-2014附录B的规定测试。

## 9.4 电气性能

## 9.4.1 电气安全

电气安全按GB4706.1的规定测试。

## 9.4.2 外壳防护等级

外壳防护等级按照GB4208-2008的规定测试。

## 9.4.3 电磁兼容性

电气部分的发射按GB4343.1的规定测试，抗扰度按GB4343.2的规定测试。

## 9.4.4 电动阀性能

电动阀按GB14536.9的规定测试。

## 9.5 尺寸

水嘴尺寸用相应精度的量具检测。

## 9.6 使用性能

## 9.6.1 涂、镀层附着强度

9.6.1.1 涂层附着强度

按照GB/T9286-1998规定的方法进行划格试验并分级。

## 9.6.1.2 金属基体镀层附着强度

按照GB/T5270-2005的规定进行热震试验，试验后观察镀层表面。

## 9.6.1.3 塑料基体镀层附着强度

试验介质为空气，先将水嘴置入（70±2）℃的环境中，保持30min，再将水嘴置入15℃～20℃下保持15min，再放入-30℃～-25℃的环境中，保持30min，取出，在 $1 5 ^ { \circ } \mathrm { C } { \sim } 2 0 ^ { \circ } \mathrm { C }$ 下保持15min，以上过程为1个周期，连续进行5个周期后，检查镀层表面。

## 9.6.2 表面耐腐蚀性能

按GB/T10125-2012进行24 h酸性盐雾试验，结果按GB/T 6461-2002进行评级。

## 9.6.3 防回流性能

抽取式水嘴及带喷枪水嘴的防回流试验方法按照GB18145-2014附录D的规定测试。

## 9.6.4 控制面板灵敏度和温度显示偏差

## 9.6.4.1 灵敏度

用示波仪检测，记录从触摸按键开始到出水的时间间隔。

## 9.6.4.2 温度显示偏差

水嘴按使用状态安装，冷水管路水温为 $1 0 \ \mathrm { ^ { \circ } C } \sim 1 5 \ \mathrm { ^ \circ C }$ ，压力为0.30MPa\~0.32MPa，热水管路水温为 $1 6 0 \mathrm { ~ ‰ ~ }$ ，压力为0.30MPa～0.32MPa。模拟实际使用操作按键，用温度测量装置测量出水温度。9.6.5 初始温度设定

水嘴按使用状态安装，冷水管路水温为10 $\mathrm { { } ^ { \circ } C \sim } 1 5 \mathrm { { } ^ { \circ } C }$ ，压力为0.30 MPa\~0.32MPa，热水管路水温为60℃～65℃，压力为0.30MPa\~0.32MPa。按下出水按钮，用测温仪测量出水口的实际温度，观察1min并读取最高显示温度。

## 9.6.6 断电和欠压保护

## 9.6.6.1 断电保护

将样品按使用状态安装，保持动压(0.10±0.01)MPa，进行启闭操作3次，在持续供水的状态下，使水嘴保持开启状态，水流稳定后切断电源，观察水嘴是否自动关闭；在持续供水的状态下，使水嘴保持关闭状态，切断电源后，观察水嘴是否保持关闭状态。

## 9.6.6.2 欠压保护

将样品按使用状态安装，采用输出电压可调节电源替代原电源，保持动压(0.10±0.01)MPa，进行启闭操作3次。在保持供水状态，使水嘴保持开启状态或进行开启操作，同时调节电源电压降至产品明示欠压保护值，观察有无信息提示功能；在保持供水状态，使水嘴保持开启状态，同时调节电源电压降至产品明示欠压保护值或样品不能正常工作时，观察其是否能够处于关闭状态。

## 9.6.7 停水保护

将样品按使用状态安装，保持动压（0.10±0.01）MPa，开启水嘴流量开关，让水嘴始终保持出水状态，从最后一次触摸水嘴控制开关起开始计时，在供应商明示的时间t\~（t+1min）内，观察水嘴是否自动停止出水。

## 9.7 电池盒

按照产品使用说明的要求对电池盒进行3次拆装，然后按9.14试验。检查试验的整个过程中电池盒是否符合8.7的要求。

## 9.8 阀体强度

按照GB18145-2014中8.6.1的规定测试。

## 9.9 密封性能

## 9.9.1 阀芯及阀芯上游

将水嘴按使用状态安装在试验设备上，关闭阀芯，从水嘴进水口引入（1.60±0.05）MPa的压力，对于可调节温度的水嘴，在温度调节装置控制的整个范围内进行试验，保压（60±5）s，观察阀芯及上游过水通道有无渗漏。

## 9.9.2 阀芯下游

将水嘴按使用状态安装在试验设备上，打开阀芯。人工堵住出水口，从水嘴进水口引入表2规定的压力，对于可调节温度的水嘴，在温度调节装置控制的整个范围内进行试验，保压（60±5）s，减小压力至（0.05±0.01）MPa，并持续（60±5）s，检查阀芯下游的所有密封部位有无渗漏现象。

注：如果有多个出水口，则每个出水口均应重复以上测试。如出水口无法堵住，则在水嘴流量为（0.40±0.04）L/s的压力下进行测试。

## 9.9.3 转换开关

## 9.9.3.1 手动转换开关

将水嘴按使用状态安装在试验设备上，将转换开关调至水流至浴缸的位置，人工堵住浴缸出水口，淋浴出水口为开启状态，从水嘴进水口施加（0.40±0.02）MPa的静压并持续（60±5）s，逐渐减小压力到（0.05±0.01）MPa的静压并持续（60±5）s，检查淋浴出水口有无渗漏现象。再将转换开关调至水流至淋浴的位置，人工堵住淋浴出水口，浴缸出水口为开启状态，水嘴进水口施加（0.40±0.02）MPa的静压并持续（60±5）s；逐渐减小压力到（0.05±0.01）MPa的静压并持续（60±5）s，检查浴缸出水口有无渗漏现象。

## 9.9.3.2 自动复位转换开关

将水嘴按使用状态安装在试验设备上，在淋浴出水口位置安装一个流量为0.15L/s（压力为0.1MPa时）的液阻，将转换开关放至水流至浴缸的位置，浴缸出水口及淋浴出水口均为开启状态，从水嘴进水口施加（0.40±0.02）MPa的动压并持续（60±5）s，检查淋浴出水口有无渗漏现象。

将转换开关放至水流至淋浴的位置，浴缸出水口及淋浴出水口均为开启状态，从水嘴进水口施加(0.40±0.02)MPa的动压并持续（60±5)s，检查浴缸出水口有无渗漏现象。逐渐减小压力至（0.05±0.01)MPa的压力并持续（60±5）s，检查转换开关位置是否移动，浴缸出水口是否有渗漏；关闭水嘴阀芯，检查转换开关位置是否自动复位到浴缸位置。

重新打开水嘴阀芯，施加（0.05±0.01）MPa的动压并持续（60±5）s，检查淋浴出水口是否有渗漏。

## 9.9.4 冷、热水隔墙

连接混合水嘴的一个进水口到试验设备上，关闭阀芯，出水口为开启状态，水嘴进水口施加一个(0.40±0.02）MPa的静压，保压（60±5）s，在保压时间内按温度调节按钮在其控制的整个温度范围内进行试验。检查出水口和另一未连接的进水口是否有渗漏。

注：另一端进水口重复以上试验。

## 9.10 流量

按照GB18145-2014的8.6.3.1的规定测试。

## 9.11 机械强度

将被测样品安装在与样品配套的标准内螺纹或外螺纹的测试装置上，向水嘴或测试装置施加表3规定的扭矩，保持（60±5）s，检查样品的螺纹是否有裂纹或损坏现象。

## 9.12 寿命

## 9.12.1 控制机构

带按键和/或触屏的控制机构寿命试验按附录A测试；不带按键和触屏的控制机构寿命试验按附录B测试。

## 9.12.2 阀芯

按照QB/T1334-2013中8.10.3的规定测试。

## 9.12.3 旋转式出水管

按照GB18145-2014中8.6.9.3的规定测试。

## 9.12.4 抽取式出水管

按照GB18145-2014中8.6.9.4的规定测试。

## 9.15.5 转换开关

按照GB18145—2014中8.6.9.2的规定测试。

## 9.13 耐温性能

将水嘴置于（55±2）℃试验箱内4h后取出，再置于室温恢复2h，然后将产品置于（-10±3）℃试验箱内4h后，再置于室温恢复2h，最后按9.4.1、9.4.2和9.9的要求检测电气安全性、外壳防护等级和密封性能。

## 9.14 耐湿性能

将产品置于恒温恒湿箱内，在温度（40±2）℃，相对湿度（93±2）%条件下，保持48h后，按9.4.1和9.4.2的要求检测电气安全性和外壳防护等级。
