## 前 言

本技术要求 2005 年4 月1日的首次制定。

本技术要求是在 CJ 164-2002《节水型生活用水器具》强制性指标的基础上，依据 GB/T18870-2002《节水型产品技术条件与管理通则》、GB 18145-2003《陶瓷片密封水嘴》等标准，补充了产品使用寿命等与节水性能有关的技术指标，并对指标的检测方法进行了规定。

本技术要求及其中任何部分未经中标认证中心许可不得复制。

本技术要求由中标认证中心负责修订。对本技术要求的意见可以发至中标认证中心，地址是中国·北京·海淀区知春路 4号 100088。意见将提交相关专业委员会讨论。

本技术要求作为评价节水产品的基准，未通过中标认证中心认证不得明示符合此技术要求。

本技术要求所有权归中标认证中心所有。

本技术要求由中标认证中心（CSC）提出并归口。

本技术要求起草单位：中标认证中心

本技术要求主要起草人：岳宗文 邵争辉 张荣静 吴珊

## 水嘴节水产品认证技术要求

## 第 2部分：陶瓷片密封水嘴

## 1 范围

本技术要求规定了节水型陶瓷片密封水嘴技术要求、检验方法、检验规则。

本技术要求适用于安装在建筑物内的冷、热水供水管路上，公称压力≤1.0MPa，介质温度不大于 $9 0 ^ { \circ } \mathsf { C }$ 条件下的各类陶瓷片密封水嘴。

## 2 定义

陶瓷片密封水嘴是使用陶瓷片密封结构的水嘴。

## 3 技术要求

## 3.1 流量

3.1.1 按 4.1.1 进行试验，流量 ${ \tt : } { \leq } 0 \ $ .15L $\mathrm { \Delta } J { \sf S } _ { 0 }$

注：本条款不适用于浴盆、洗衣机水嘴。

3.1.2 按4.1.2 进行试验，浴盆水嘴流量 ${ \cdot } 2 0 . 3 3 \mathsf { L } / \mathsf { s }$ ，面盆、洗涤等其他水嘴 ${ \geq } 0 . 2 0 \mathrm { L } / \varsigma _ { \circ }$

## 3.2 阀体强度

按4.2进行试验，阀体应无变形和渗漏。

## 3.3 密封性能

按 4.3 进行试验，各部位应无渗漏。

## 3.4 使用寿命

## 3.4.1 启闭寿命

a) 单柄双控水嘴进行 $7 \times { 1 0 } ^ { 4 }$ 次循环寿命试验后，符合 3.3 的规定。

b) 其它水嘴进行 $2 \times 1 0 ^ { 5 }$ 次寿命试验后，符合 3.3 的规定。

3.4.2 转换开关进行 $3 \times 1 0 ^ { 4 }$ 次寿命试验后，符合 3.3 的规定。

3.4.3 旋转式出水口进行 $\mathrm { 8 \times 1 0 ^ { 4 } }$ 次寿命试验后，符合 3.3 的规定。

## 4 检验方法

## 4.1 流量

4.1.1 带附件的样品与管径 15mm 的供水管道连接成使用状态，水压调整为 $( 0 . 1 { \pm } 0 . 0 1 ) \ \mathsf { M P a }$ ，形成稳定连续的水流，根据以下要求测量相应流量。

a) 单柄单控水嘴，将手柄开启到最大位置。

b) 双柄双控水嘴，分别将手柄开启到冷、热水最大位置，取流量的最大值。

c) 单柄双控水嘴，分别将手柄开启到冷、热水开启至最大位置以及混合水最大位置（即中间位），取流量的最大值。

4.1.2 不带附件的样品与管径 15mm的供水管道连接成使用状态，水压调整为 $( 0 . 3 { \pm } 0 . 0 2 ) \ \mathsf { \ m p a }$ 形成稳定连续的水流，根据以下要求测量相应流量。

a) 单柄单控水嘴，手柄开启到最大位置。

b) 双柄双控水嘴，手柄分别开启到冷、热水最大位置，取流量的最小值。

c) 单柄双控水嘴，手柄分别开启到冷、热水开启至最大位置以及混合水最大位置（即中间

位），取流量的最小值。

## 4.2 阀体强度

## 4.2.1 进水部位（阀座下方）强度性能

样品按使用状态安装在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口施加（2.5±0.05）MPa 水压，保压 60±5s，检查阀体有无变形和渗漏。

## 4.2.2 出水部位（阀座上方）强度性能

样品按使用状态安装在测试设备上，打开阀芯，堵住出水口，进水口施加（0.4±0.02 ）MPa水压，保压 60±5s，检查阀体有无变形和渗漏。

4.3 密封性能

## 4.3.1 阀芯密封性能

样品按使用状态安装在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口引入表 1 规定的压力值，在表 1规定的保压时间内，检查出水口有无渗漏。

## 4.3.2 冷、热水隔墙密封性能

样品的一个进水口连接在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口引入表 1 规定的压力值，在表 1 规定的保压时间内，检查另一进水口有无渗漏。另一进水口重复上述试验。

## 4.3.3 上密封性能

样品按使用状态安装在测试设备上，打开阀芯，堵住出水口，进水口引入表 1 规定的压力值，在表 1 规定的保压时间内，检查样品各连接处有无渗漏。

## 4.3.4 手动转换开关密封性能

样品按使用状态安装在测试设备上，打开阀芯，转换开关置于浴盆位，堵住浴盆出水口，进水口引入表 1 规定的压力值，在表 1规定的保压时间内，检查淋浴出水口有无渗漏。

转换开关置于淋浴位，堵住淋浴出水口，重复上述试验。

## 4.3.5 自动复位转换开关密封性能

样品按使用状态安装在测试设备上，淋浴出水口安装 0.25L/s 的液阻，打开阀芯，转换开关置于浴盆位，进水口施加 $( 0 . 4 \pm 0 . 0 2 )$ MPa 动水压，保压（60±5）s，检查淋浴出水口有无渗漏。

转换开关置于淋浴位，重复上述试验。

转换开关继续在淋浴位，调整动水压至 $( 0 . 0 5 { \pm } 0 . 0 1 ) \ \mathsf { \ m p a }$ ，检查转换开关有无移动，保压（60±5）s，检查浴盆出水口有无渗漏。停止水流，转换开关自动复位在浴盆位。再次将动水压升至 $( 0 . 0 5 { \pm } 0 . 0 1 ) \ \mathsf { \ M P a }$ ，保压（60±5）s，检查淋浴出水口有无渗漏。

## 4.3.6 低压密封试验

样品按使用状态安装在测试设备上，关闭阀芯，进水口引入表 1 规定的压力值，在表 1 规定的保压时间内，检查各密封连接部位有无渗漏。

## 4.4.1.2 单柄单控

样品按使用状态安装在试验设备上，用冷水进行试验，冷水温度≤ $30 \text{‰}$ 动压、速度及每次运动时间按表 2 的要求，开启和关闭为一个循环，经过 $2 \times 1 0 ^ { 5 }$ 次循环后，检查密封性能是否符合3.3 的要求。

## 4.4.1.3 双柄双控

试验条件按表 $2 _ { \circ }$ 样品按使用状态安装在试验设备上，冷、热水端手柄分别进行寿命试验，开启和关闭为一个循环，两端分别经过 $2 \times 1 0 ^ { 5 }$ 次循环后，检查密封性能是否符合 3.3 的要求。

## 4.4.2 旋转出水管寿命试验

试验设备应保证旋转出水管按 $1 5 ^ { 0 } .$ 次/分钟交替往复动作，冷水温度≤ $30 ^ { \circ } \mathsf { C } _ { \circ }$ 若出水管从手柄旋转中心水平方向≤200mm，安装 ${ 1 \mathsf { k g } ^ { 0 } } \mathrm { - } 1 0 9$ 的配重；若出水管从手柄旋转中心水平方向 $> 2 0 0 \mathsf { m m }$ 所装配重应产生 $2 ^ { 0 } { \cdot } 0$ .2Nm的弯矩。上述配重固定在出水管末端。

样品安装在试验设备上，关闭阀芯，调节给水回路水压至（0.2～0.4）MPa 之间。打开阀芯通过遮盖出水孔将流量调节到（0.066～0.100） $\mathsf { L } / \mathsf { S }$ 之 $i \overline { { \mathtt { E } } } \rbrack _ { \circ }$ 每次循环都包括两终端位置之间的一次运动，终端位置不变，出水管应达到 $1 1 0 ^ { \circ }$ 的圆弧。移动速度应尽可能平稳。经过 ${ 8 \times 1 0 ^ { 4 } }$ 次循环后，检查密封性能是否符合 3.3的要求。

## 4.4.3 转换开关寿命试验

试验设备应保证转换开关按 15 次/min 交替动作。热水温度 $( 6 5 \pm 2 ) ~ ^ { \circ } \mathsf { C }$ ，冷水温度为≤ $3 0 ^ { \circ } \mathsf { C } _ { \mathsf { c } }$ 静压 $\mathrm { 0 . 4 M P a _ { c } }$

## 4.4.3.1 手动转换开关

样品安装在试验设备上，关闭阀芯，调节两给水回路水压至 0.4MPa，打开阀芯，通过遮盖出水孔调节流量在（0.066～0.100）L/s 之间，每次循环包括两终端位置之间的前后运动。试验过

程中，交替供应冷水 15min±30s，然后热水 15min±30s，依此类推。8×104次循环后，检查转换开关密封性能是否符合 5.3 的要求。

## 4.4.3.2 自动复位转换开关

样品安装在试验设备上，淋浴出水孔上安装液阻为 0.25L/s 的附件，关闭阀芯，调节两给水回路水压至 0.4MPa，打开阀芯，调节水流至最小值，使转换开关恰起作用。每次循环包括以下步骤，经 $3 \times 1 0 ^ { 4 }$ 次循环后，检查转换开关密封性能是否符合 3.3 的要求。

a) 转换开关处于通向浴盆的位置，使水流过出水孔（5±0.2）s；

b) 拉或压转换开关至淋浴位置，使水流过淋浴出水孔（5±0.2）s；

c) 切断水流，转换开关返回浴盆位置，再重新供给水流。

## 5 检验规则

## 5.1 检验分类

产品检验分出厂检验和型式检验。

## 5.2 出厂检验

出厂检验的项目包括 3.1、3.2、3.3。

5.2.1 出厂检验项目中的 3.3 为逐个检验项目。

5.2.2 出厂检验项目中的 3.1、3.2 为抽样检验项目。

5.2.3 判定原则

检验项目章条判定规则流量3.1n≥3, Ac=0阀体强度3.2n≥3,Ac=0

## 5.3 型式检验

## 5.3.1 检验项目

型式检验包括本标准第 3 章的全部项目。

## 5.3.2 样品

在企业生产线末端、企业成品库房、企业销售中转库房或市场进行随机抽样，每一型号抽取3 套产品，成品库房抽样基数不应少于 50 套。

## 5.3.3 判定原则

检验项目章条判定规则流量3.1n=3, Ac=0阀体强度3.2n=3, AC=0密封性能3.3n=3, AC=0使用寿命5.4n=1, Ac=0

## 6 标志、包装、运输和贮存

6.1 产品上应有明显清晰、不易涂改的注册商标和型号，并附有合格证和安装、使用、维护说明书。

6.2 产品单件包装应标明生产厂名、生产厂址、产品名称、产品型号、注册商标、标记、和节水认证标志及证书编号。

6.3 产品说明书应至少包括附件清单、产品外形尺寸、出入口连接尺寸、产品适用压力范围等参数。
