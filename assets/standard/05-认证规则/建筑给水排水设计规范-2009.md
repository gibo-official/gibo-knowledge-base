## 修订说明

根据原建设部"关于印发《2007 年工程建设标准规范制订、修订计划（第一批）》的通知"要求，由上海现代建筑设计（集团）有限公司会同有关单位对《建筑给水排水设计规范》GB 50015—2003 进行修订而成。

**本次局部修订主要内容：**

| 序号 | 修订内容 |
|:-----|:---------|
| 1 | 调整生活饮用水管道防回流污染措施的适用条件，补充倒流防止器、真空破坏器的设置要求 |
| 2 | 补充叠压供水、太阳能和热泵热水供应等节能技术原则规定 |
| 3 | 完善居住小区设计流量计算 |
| 4 | 对同层排水管道设计提出要求 |
| 5 | 推荐具有防涸功能的新型地漏，禁用钟罩（扣碗）式地漏 |
| 6 | 调整通气系统不同设置条件下排水立管最大设计通水能力，补充自循环通气系统设计内容 |
| 7 | 根据雨水管道的设计流态，确立雨水立管和雨水斗设计泄流量 |
| 8 | 修改热水供应设计小时耗热量计算参数 |
| 9 | 协调补充管道直饮水系统设计参数 |

> **强制性条文标识**：本规范中用黑体字表示的条文为强制性条文，必须严格执行。

## 1 总则

**1.0.2** 本规范适用于居住小区、公共建筑区、民用建筑给水排水设计，亦适用于工业建筑生活给水排水和厂房屋面雨水排水设计。

但设计下列工程时，还应按现行的有关专门规范或规定执行：

| 序号 | 特殊工程类型 |
|:-----|:-------------|
| 1 | 湿陷性黄土、多年冻土和胀缩土等地区的建筑物 |
| 2 | 抗震设防烈度超过 9 度的建筑物 |
| 3 | 矿泉水疗、人防建筑 |
| 4 | 工业生产给水排水 |
| 5 | 建筑中水和雨水利用 |

**1.0.3A** 本规范规定了建筑给水排水设计的基本要求。当本规范与国家法律、行政法规的规定相抵触时，应按国家法律、行政法规的规定执行。

## 2 术语和符号

### 2.1 术语

| 术语 | 定义 |
|:-----|:-----|
| **最大时用水量** | 最高日最大用水时段内的小时用水量 |

| **真空破坏器** | 一种可导入大气压消除给水管道内水流因虹吸而倒流的装置 |
| **叠压供水** | 利用室外给水管网余压直接抽水再增压的二次供水方式 |
| **自灌** | 水泵启动时水靠重力充入泵体的引水方式 |
| **自循环通气** | 通气立管在顶端、层间和排水立管相连，在底端与排出管连接，排水时在管道内产生的正负压通过连接的通气管道迂回补气而达到平衡的通气方式 |
| **真空排水** | 利用真空设备使排水管道内产生一定真空度，利用空气输送介质的排水方式 |
| **同层排水** | 排水横支管布置在排水层或室外，器具排水管不穿楼层的排水方式 |
| **埋设深度** | 埋地排水管道内底至地表面的垂直距离 |
| **隔油器** | 分隔、拦集生活废水中油脂的装置 |
| **中水** | 各种排水经适当处理达到规定的水质标准后回用的水 |
| **暴雨强度** | 单位时间内的降雨量 |
| **降雨历时** | 降雨过程中的任意连续时段 |
| **地面集水时间** | 雨水从相应汇水面积的最远点地表径流到雨水管渠入口的时间 |
| **管内流行时间** | 雨水在管渠中流行的时间 |
| **汇水面积** | 雨水管渠汇集降雨的面积 |
| **满管压力流雨水排水系统** | 按满管压力流原理设计管道内雨水流量、压力等可得到有效控制和平衡的屋面雨水排水系统 |
| **径流系数** | 一定汇水面积的径流雨水量与降雨量的比值 |
| **集中热水供应系统** | 供给一幢（不含单幢别墅）或数幢建筑物所需热水的系统 |
| **局部热水供应系统** | 供给单个或数个配水点所需热水的供应系统 |
| **全日热水供应系统** | 在全日、工作班或营业时间内不间断供应热水的系统 |
| **定时热水供应系统** | 在全日、工作班或营业时间内某一时段供应热水的系统 |
| **热泵热水供应系统** | 通过热泵机组运行吸收环境低温热能制备和供应热水的系统 |
| **水源热泵** | 以水或添加防冻剂的水溶液为低温热源的热泵 |
| **空气源热泵** | 以环境空气为低温热源的热泵 |
| **太阳能保证率** | 系统中由太阳能部分提供的热量除以系统总负荷 |
| **太阳辐照量** | 接收到太阳辐射能的面密度 |
| **燃油（气）热水机组** | 由燃烧器、水加热炉体和燃油（气）供应系统等组成的设备组合体 |
| **设计小时耗热量** | 热水供应系统中用水设备、器具最大时段内的耗热量 |
| **设计小时供热量** | 热水供应系统中加热设备最大时段内的产热量 |
| **同程热水供应系统** | 对应每个配水点的供水与回水管路长度之和基本相等的热水供应系统 |
| **第二循环系统** | 集中热水供应系统中，水加热器或热水贮水器与热水配水点之间组成的热水循环系统 |
| **管道直饮水系统** | 原水经深度净化处理，通过管道输送，供人们直接饮用的供水系统 |
| **水质阻垢缓蚀处理** | 采用电、磁、化学稳定剂等物理、化学方法稳定水中钙、镁离子，使其不形成水垢，延缓对加热设备或管道的腐蚀的水质处理 |

### 3.2 水质和防水质污染

**3.2.1 ~ 3.2.3** 生活饮用水水质应符合 GB 5749 要求。城镇给水管道严禁与自备水源的供水管道直接连接。

**3.2.3A** 中水、回用雨水等非生活饮用水管道严禁与生活饮用水管道连接。

**3.2.4 ~ 3.2.4C** 生活饮用水不得因管道内产生虹吸、背压回流而受污染。出水口不得被任何液体或杂质所淹没。生活饮用水水池（箱）的进水管口应满足空气间隙要求。

**3.2.5 ~ 3.2.5D** 下列部位应设置倒流防止器：

| 条款 | 设置部位 |
|:-----|:---------|
| 3.2.5 | 从城镇给水管网的不同管段接出两路及两路以上的引入管 |
| 3.2.5A | 从生活饮用水管道系统接至消防用水管道 |
| 3.2.5B | 接至含有对健康有危害物质的场所或设备 |
| 3.2.5C | 游泳池、水上游乐池、绿地喷灌系统等（设置真空破坏器） |

**3.2.6 ~ 3.2.13** 严禁生活饮用水管道与大便器（槽）采用非专用冲洗阀直接连接。生活饮用水水池（箱）的构造和配管应符合防污染要求。水池（箱）内贮水 48h 内不能更新时，应设置水消毒处理装置。

### 3.3 系统选择

**3.3.1 ~ 3.3.2** 小区的室外给水系统应尽量利用城镇给水管网的水压直接供水。叠压供水设计方案应经当地供水行政主管部门批准。

**3.3.3 ~ 3.3.6** 建筑物内给水系统的竖向分区要求：

| 项目 | 要求 |
|:-----|:------|
| 各分区最低卫生器具配水点处静水压 | 不宜大于 0.45MPa |
| 静水压大于 0.35MPa 的入户管 | 宜设减压或调压设施 |
| 居住建筑入户管给水压力 | 不应大于 0.35MPa |
| 建筑高度 ≤100m | 宜采用垂直分区并联供水或分区减压 |
| 建筑高度 >100m | 宜采用垂直串联供水方式 |

### 3.5 管道布置和敷设

**3.5.1 ~ 3.5.5** 小区的室外给水管网宜布置成环状网。室外给水管道外壁距建筑物外墙的净距不宜小于 1m。室内冷、热水管上下平行敷设时，冷水管应在热水管下方。

**3.5.8 ~ 3.5.18** 室内给水管道不得布置在遇水会引起燃烧、爆炸的原料、产品和设备的上面。塑料给水管道在室内宜暗设。埋地敷设的生活给水管与排水管之间的最小净距：平行埋设不宜小于 0.50m；交叉埋设不应小于 0.15m。

**暗设管道要求：**

| 敷设在垫层内的管材 | 塑料管、复合管或耐腐蚀金属管 |
| 直埋管段 | 不得中途接驳或用三通分水，采用分水器集中配水 |

### 3.8 增压设备、泵房

**3.8.1 ~ 3.8.2** 选择生活给水系统的加压水泵时，Q~H 特性曲线应是随流量增大扬程逐渐下降的曲线。水泵应在其高效区内运行。生活加压给水系统应设备用泵。

### 5.2 热水供应系统选择

**5.2.2 ~ 5.2.8** 集中热水供应系统的热源宜首先利用工业余热、废热、地热。日照条件好的地区宜优先采用太阳能。具备可再生低温能源的地区可采用热泵热水供应系统。依次选择热力管网、燃油燃气热水机组等。

|:-----|:------|
| 热效率高 | 燃烧效率一般应在 85% 以上 |
| 阻力损失小 | 被加热水侧阻力损失宜 ≤0.01MPa |
| 安全可靠 | 应有可靠温度控制，防止烫伤 |
| 构造简单 | 便于操作维修 |
| 医院热水系统 | 锅炉或水加热器不得少于两台 |
| 其他建筑 | 水加热设备不宜少于两台 |

**5.4.2A 太阳能加热系统设计要求：**

太阳能集热器的设置应和建筑专业统一规划协调。集热器总面积应根据日用水量、当地年平均日太阳辐照量和集热效率等因素计算。太阳能热水供应系统应设辅助热源及其加热设施。

**5.4.2B 热泵热水供应系统设计要求：**

水源热泵应优先考虑以空调冷却水、冷冻水为热源。空气源热泵热水供应系统在夏热冬暖地区宜采用，在最冷月平均气温小于 10℃ 且不小于 0℃ 时宜设置辅助热源。
