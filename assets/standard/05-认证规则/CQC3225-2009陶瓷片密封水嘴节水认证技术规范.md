## 前 言

本技术规范是陶瓷片密封水嘴节水产品认证依据。代替 CSC/T35.2-2006。

为贯彻实施《中华人民共和国节约能源法》以及政府有关节水的政策和要求,开展节水产品认证、保护环境、提高水资源的利用效率,引导企业的节水技术进步,特制定本技术规范。

本技术规范根据我国陶瓷片密封水嘴的生产和使用的现状制定，并参考了国外类似技术要求。

本技术规范由中国质量认证中心提出并归口。

# 陶瓷片密封水嘴节水认证技术规范

## 1 范围

本技术规范规定了陶瓷片密封水嘴的节水评价技术要求、检验方法及检验规则。

本技术规范适用于安装在建筑物内的冷、热水供水管路上，公称压力≤1.0MPa，介质温度不大于 90℃条件下的各类陶瓷片密封水嘴。

本技术要求不适用铸铁式螺旋升降水嘴、与水接触面为锌合金的水嘴、恒温水嘴。

## 2 术语和定义

本技术规范采用下列术语和定义。

## 2.1 水嘴

水嘴是对水介质实现启、闭及控制出口水流量和水温度的一种装置。

## 2.2 陶瓷片密封水嘴

陶瓷片密封水嘴是使用陶瓷片密封结构的水嘴。

## 2.2 节水型水嘴

通过减少流量、延长使用寿命、定量给水等方式实现节水效果的水嘴。

## 2.3 静态压力

水嘴完全关闭时，水嘴前的进水管路中的稳定静压值。

2.4 动态压力

水嘴完全打开时，水嘴前（300～500）mm 范围内进水管道中的稳定静压值。

## 3 检测项目及技术要求

## 3.1 流量

3.1.1 按 4.1.1 进行试验，流量≤0.15L/s。

注：本条款不适用于浴盆、淋浴、洗衣机水嘴。

3.1.2 按 4.1.2 进行试验，浴盆水嘴流量≥0.33L/s，面盆、洗涤、淋浴等其他水嘴≥0.20L/s。

## 3.2 阀体强度

按4.2进行试验，阀体应无变形和渗漏。

## 3.3 密封性能

按 4.3 进行试验，各部位应无渗漏。

## 3.4 使用寿命

## 3.4.1 启闭寿命

a) 单柄双控水嘴进行 $7 \times { { 1 0 } ^ { 4 } }$ 次循环寿命试验后，符合 3.3 的规定。

b) 其它水嘴进行 $2 \times 1 0 ^ { 5 }$ 次寿命试验后，符合 3.3的规定。

3.4.2 转换开关进行 $3 \times 1 0 ^ { 4 }$ 次寿命试验后，符合 3.3 的规定。

3.4.3 旋转式出水口进行 $8 \times { 1 0 } ^ { 4 }$ 次寿命试验后，符合 3.3的规定。

## 4 试验方法

## 4.1 流量

4.1.1 带附件的样品与管径 15mm 的供水管道连接成使用状态，手柄开启到下列位置，动态压力调整为（0.1±0.01）MPa，形成稳定连续的水流，测定相应流量。

a) 单柄单控水嘴，将手柄开启到最大位置。

b) 双柄双控水嘴，分别将手柄开启到冷、热水最大位置，取流量的最大值。

c) 单柄双控水嘴，分别将手柄开启到冷、热水开启至最大位置以及混合水最大位置（即中间位），取流量的最大值。

4.1.2 不带附件的样品与管径 15mm 的供水管道连接成使用状态，手柄开启到下列位置，动态压力调整为（0.3±0.02）MPa，形成稳定连续的水流，测定相应流量。

a) 单柄单控水嘴，手柄开启到最大位置。

b) 双柄双控水嘴，手柄分别开启到冷、热水最大位置，取流量的最小值。

c) 单柄双控水嘴，手柄分别开启到冷、热水开启至最大位置以及混合水最大位置（即中间位），取流量的最小值。

## 4.2 阀体强度

## 4.2.1 进水部位（阀座下方）强度性能

样品按使用状态安装在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口施加（2.5±0.05）MPa 静态压力，保压（60±5）s 后，检查阀体有无变形和渗漏。

## 4.2.2 出水部位（阀座上方）强度性能

样品按使用状态安装在测试设备上，打开阀芯，堵住出水口，进水口施加（0.4±0.02 ）MPa 静态压力，保压（60±5）s 后，检查阀体有无变形和渗漏。

## 4.3 密封性能

## 4.3.1 阀芯密封性能

样品按使用状态安装在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口引入表 1 规定的压力值，按照表 1 规定时间进行保压后，检查出水口有无渗漏。

## 4.3.2 冷、热水隔墙密封性能

样品的一个进水口连接在测试设备上，使用 1.5Nm 力矩关闭阀芯，进水口引入表 1 规定的压力值，按照表 1 规定时间进行保压后，检查另一进水口有无渗漏。另一进水口重复上述试验。

## 4.3.3 上密封性能

样品按使用状态安装在测试设备上，打开阀芯，堵住出水口，进水口引入表 1 规定的压力值，按照表1 规定时间进行保压后，检查样品各连接处有无渗漏。

## 4.3.4 手动转换开关密封性能

样品按使用状态安装在测试设备上，打开阀芯，转换开关置于浴盆位，堵住浴盆出水口，进水口引入表 1 规定的压力值，按照表 1 规定时间进行保压后，检查淋浴出水口有无渗漏。

转换开关置于淋浴位，堵住淋浴出水口，重复上述试验。

## 4.3.5 自动复位转换开关密封性能

样品按使用状态安装在测试设备上，淋浴出水口安装 0.25L/s 的液阻，打开阀芯，转换开关置于浴盆位，进水口施加（0.4±0.02）MPa 动态压力，保压（60±5）s 后，检查淋浴出水口有无渗漏。

转换开关置于淋浴位，重复上述试验。

转换开关继续在淋浴位，调整动态压力至（0.05±0.01）MPa，检查转换开关有无移动，保压（60±5）s 后，检查浴盆出水口有无渗漏。停止水流，转换开关自动复位在浴盆位。再次将动态压力升至（0.05±0.01）MPa，保压 $( 6 0 \pm 5 ) \textrm { s } \sqrt { \Pi }$ ，检查淋浴出水口有无渗漏。

## 4.4 使用寿命

## 4.4.1 启闭寿命

## 4.4.1.1 单柄双控

样品按使用状态安装在试验设备上，试验设备包括两条供水回路（冷、热水），每条回路带有一台泵，以提供所需的压力，试验设备应满足表 2 规定的试验条件，并保证手柄按图 1 所示运动，一次循环包括三次开关运动。

表 2：试验条件
热水温度(65±2)℃冷水温度≤30℃动态压力(0.3±0.05)Mpa速度90°/(1.5±0.2)s停留时间(5±0.2)s每次运动时间(0.5±0.2)s

## 4.4.1.2 单柄单控

样品按使用状态安装在试验设备上，用冷水进行试验，冷水温度≤30℃。动态压力、速度及每次运动时间按表 2的要求，开启和关闭为一个循环，经过 $2 \times { 1 0 } ^ { 5 }$ 次循环后，检查密封性能是否符合 3.3 的要求。4.4.1.3 双柄双控

试验条件按表 2。样品按使用状态安装在试验设备上，冷、热水端手柄分别进行寿命试验，开启和关闭为一个循环，两端分别经过 $2 \times 1 0 ^ { 5 }$ 次循环后，检查密封性能是否符合 3.3 的要求。

## 4.4.2 旋转出水管寿命试验

试验设备应保证旋转出水管按 $1 5 ^ { 0 } -$ 1次/分钟交替往复动作，冷水温度 ${ \leqslant } 3 0 ^ { \circ } \mathrm { C }$ 。若出水管从手柄旋转中心水平方向≤200mm，安装 ${ { 1 \mathrm { k g } } ^ { 0 } } _ { - 1 0 } { \mathrm { g } }$ 的配重；若出水管从手柄旋转中心水平方向＞200mm，所装配重应产生$2 ^ { 0 } { \mathrm { - } } 0 . 2 \mathrm { N m }$ 的弯矩。上述配重固定在出水管末端。

样品安装在试验设备上，关闭阀芯，调节给水回路静态压力至（0.2～0.4）MPa 之间。打开阀芯通过遮盖出水孔将流量调节到（0.066～0.100）L/s 之间。每次循环都包括两终端位置之间的一次运动，终端位置不变，出水管应达到 $1 1 0 ^ { \circ }$ 的圆弧。移动速度应尽可能平稳。经过 $\mathrm { 8 \times 1 0 ^ { 4 } }$ 次循环后，检查密封性能是否符合 3.3的要求。

## 4.4.3 转换开关寿命试验

试验设备应保证转换开关按 15 次/60s 交替动作。热水温度 $( 6 5 \pm 2 ) \textrm { ‰}$ ，冷水温度为 ${ \leqslant } 3 0 ^ { \circ } \mathrm { C }$ 。静态压力 0.4MPa。

## 4.4.3.1 手动转换开关

样品安装在试验设备上，关闭阀芯，调节两给水回路静态压力至 0.4MPa，打开阀芯，通过遮盖出水孔调节流量在（0.066～0.100）L/s 之间，每次循环包括两终端位置之间的前后运动。试验过程中，交替供应冷水 $( 9 0 0 \pm 3 0 ) \textrm { s }$ ，然后热水 $( 9 0 0 \pm 3 0 )$ s，依此类推。 $\mathrm { 3 \times 1 0 ^ { 4 } }$ 次循环后，检查转换开关密封性能是否符合 3.3的要求。

## 4.4.3.2 自动复位转换开关

样品安装在试验设备上，淋浴出水孔上安装液阻为 0.25L/s 的附件，关闭阀芯，调节两给水回路静态压力至 0.4MPa，打开阀芯，调节水流至最小值，使转换开关恰起作用。每次循环包括以下步骤，经 $3 \times { 1 0 } ^ { 4 }$ 次循环后，检查转换开关密封性能是否符合 3.3 的要求。

a) 转换开关处于通向浴盆的位置，使水流过出水孔 $( 5 \pm 0 . 2 ) \ \mathrm { \ s } ;$

b) 拉或压转换开关至淋浴位置，使水流过淋浴出水孔 $( 5 \pm 0 . 2 ) \mathrm { ~ s ~ }$

c) 切断水流，转换开关返回浴盆位置，再重新供给水流。

## 5 判定

## 5.1 检验分类

产品检验分出厂检验和认证检验。

## 5.2 出厂检验

出厂检验的项目包括 3.1、3.2、3.3。

5.2.1 出厂检验项目中的 3.3 为逐个检验项目。

5.2.2 出厂检验项目中的 3.1、3.2 为抽样检验项目。

5.2.3 判定原则

检验项目章条判定规则流量3.1 $\mathrm { n } { \geqslant } 3 , \mathrm { A c } { = } 0$ 阀体强度3.2 $\mathrm { n } { \geqslant } 3 , \mathrm { A c } { = } 0$ 

## 5.3认证检验

## 5.3.1 检验项目

认证检验包括本标准第 3 章的全部项目。

## 5.3.2 判定原则

检验项目 $\frac { 3 x } { 5 } = \frac { 5 } { 5 }$ 判定规则流量3.1 $\mathrm { n } { = } 1 , \mathrm { A c } { = } 0$ 阀体强度3.2 $\mathrm { n } { = } 1 , \mathrm { A c } { = } 0$ 密封性能3.3 $\mathrm { n } { = } 1 , \mathrm { A c } { = } 0$ 使用寿命3.4 $\mathrm { n } { = } 1 , \mathrm { A c } { = } 0$
