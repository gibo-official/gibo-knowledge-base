## 数显花洒

## 1 范围

本标准规定了数显花洒（以下简称“花洒”）的术语和定义、配套装置、要求、试验方法、检验规则及标志、包装、运输和贮存。

本标准适用于安装在建筑物内的冷、热水供水管路末端，工作压力（动压）0.10MPa\~0.50MPa、供水温度4℃～70℃条件下的花洒。

## 3 术语和定义

下列术语和定义适用于本文件。

## 3.1

## 花洒 shower

一种以淋浴为目的的能使水以小水滴或喷射状发散流出的装置，为花洒头、手持花洒、固定花洒和花洒组的统称。

[GB/T 33733-2017, 2.2.1]

## 3.2

## 数显花酒 digital display shower

具有水温数据显示功能的花洒，显示方式可以采用数字和/或灯光颜色的形式。

## 3.3

## 动压 flowing pressure

水在流动状态下对管路单位面积所产生的压力。

注：单位为kPa或MPa。

## 3.4

## 灯光响应时间 light response time

从指定温度的水流进花洒进水口开始计时至显示进水温度对应的灯光颜色之间的时间。

注：单位为s。

## 4 配套装置

4.1 与花洒配套的水嘴应符合 QB/T 1334的规定。

4.2 与花洒配套的软管应符合GB/T 23448的规定。

## 5 要求

## 5.1 外观质量

5.1.1 金属铸件外表面不应有缩孔、砂眼、裂纹和气孔等缺陷，内腔不应粘附型砂。

5.1.2 塑料件外表面不应有明显的波纹、擦划伤、修饰损伤等缺陷。

5.1.3 所有在使用中人体可触及的表面不应有尖锐棱角等可能使人体产生伤害的隐患。

5.1.4 有涂层或镀层的，安装后的可视面不应有漏涂或漏镀，涂层或镀层应均匀一致，无起皮、剥落、起泡、损伤等现象

## 5.2 螺纹精度

花洒外连接部位的管螺纹精度应符合GB/T 7307-2001的要求。其中，外螺纹不应低于GB/T 7307一2001的B级精度。特殊螺纹按合同要求。

## 5.3 涂、镀层附着强度

## 5.3.1 涂层附着强度

按照6.3.1进行划格试验，应达到1级要求。

## 5.3.2 金属基体镀层附着强度

按照6.3.2进行热震试验后，不应出现裂纹、起皮或脱落现象。

## 5.3.3 塑料基体镀层附着强度

按照6.3.3进行试验后，表面应无裂纹、水泡、疏松等现象。

## 5.4 表面耐腐蚀性能

按照6.4进行酸性盐雾试验后，不应低于GB/T6461-2002的表1中外观评级（RA）9级的要求。

## 5.5 显示功能

## 5.5.1 精准度

带温度显示功能的花酒，按6.5.1的规定进行试验，其温度显示的数值与实际温度的偏差应在±2℃之内。

## 5.5.2 灵敏度

带灯光显示功能的花洒，按6.52的规定进行试验，灯光响应时间应小于5s。

## 5.5.3 低压显示

按6.5.3的规定进行试验，数字显示应清晰和/或灯光显示应稳定。

## 5.5.4 警示灯光

带灯光显示功能的花洒，按6.5.4的规定进行试验，出水温度在不小于42℃时应显示红色。使用说明书应明示各温度区间的灯光颜色。

## 5.6 安全要求

5.6.1 按6.6.1 进行试验，其水流喷射方式不应发生变化。

5.6.2 按6.6.2 进行试验，其水流喷射方式不应发生变化。

5.6.3 按6.6.3 进行试验，电压不应大于12V。

## 5.7 密封性能

按6.7规定进行试验，各部件连接部位应无漏水现象。

## 5.8 机械强度

按6.8规定进行试验，应无裂纹、可见永久性变形或其他损坏。

## 5.9 耐冷热疲劳

按6.9规定进行试验，应无漏水、裂纹、变形和功能故障。

## 5.10 流量

按6.10规定进行试验，花洒的流量应符合表1的要求。

## 5.11 整体抗拉性能

按6.11规定进行试验，花洒软管接头、花洒软管、花洒软管和花洒的连接部位、花洒不应有明显损坏和任何渗漏现象

## 5.12 温降

按6.12规定进行试验，温降不应大于3K。

## 5.13 旋转连接性能

对带有旋转连接接头的花洒按6.13规定进行试验，花洒发生旋转时的扭矩不应超过0.1N·m。

## 5.14 寿命

## 5.14.1 功能转换寿命

对于具有两个或两个以上水流喷射方式的花洒，按6.14.1规定进行10-000次循环后，应满足5.7的要求。

## 5.14.2 球形连接摇摆寿命

对于带有球形连接的可活动的固定式花洒或花洒喷头，按6.14.2进行10000次循环后，球形连接部位应无渗漏。

## 5.14.3 显示寿命

按6.14.3规定的方法进行试验，试验过程中灯光无异常，完成2000次循环寿命后应满足5.5的要求。

## 5.15 防虹吸性能

手持式花洒按6.15规定的方法进行试验，水位上升高度不应大于13mm。

## 5.16 电路防护性能

按6.16规定的方法进行试验后，花洒应满足5.5的要求。

## 5.17 抗跌落性能

按6.17规定的方法进行试验后，花洒应满足5.5的要求。

## 6 试验方法

## 6.1 外观质量

在距离（600±50）mm处，光照度（300±20）1x的条件下目测。

## 6.2 螺纹精度

用相应精度等级的螺纹量规测定。

## 6.3 涂、镀层附着强度

## 6.3.1 涂层附着强度

按照GB/T9286—1998规定的方法进行试验。

## 6.3.2 金属基体镀层附着强度

按照GB/T5270一2005规定的方法进行热震试验，试验后观察镀层表面。

## 6.3.3 塑料基体镀层附着强度

试验介质为空气，先将花洒置入（70±2）℃的环境中，保持30min，再将花洒置入 $. 1 5 ^ { \circ } \mathrm { C } \sim 2 0 ^ { \circ } \mathrm { C }$ 下保持15min，再放 $\lambda - 3 0 ^ { \circ } C \sim - 2 5 ^ { \circ } C$ 的环境中，保持30min，取出，在15℃～20℃下保持15min，以上过程为1个周期，连续进行5个周期后，检查镀层表面。

## 6.4 表面耐腐蚀性能

按GB/T10125-2012进行24h酸性盐雾试验，按GB/T 6461-2002进行评级。

## 6.5 显示功能

## 6.5.1 精准度

按附录A规定的方法进行测试。

## 6.5.2 灵敏度

将花洒安装在图1的试验设备上，保持动压为（0.30±0.02）MPa、流量为（9.5±1.0）L/min的试验条件，如果流量无法调节至（9.5±1.0）L/min，按最大出水流量进行测试。试验步骤如下：

a) 将供水温度调为（20±2）℃，启动供水开关并使水从排水口流出至温度稳定，然后将水流切换至花洒最大出水流量状态出水，并开始计时至灯光显示为使用说明书指示的颜色，重复3次取平均值；

b)将供水温度调为 $( 3 6 \pm 2 ) ^ { \circ } \mathrm { C }$ ，启动供水开关并使水从排水口流出至温度稳定，然后将水流切换至花洒最大出水流量状态出水，并开始计时至灯光显示为使用说明书指示的颜色，重复3次取平均值；

c） 将供水温度调为（44±2）℃，启动供水开关并使水从排水口流出至温度稳定，然后将水流切换至花洒最大出水流量状态出水，并开始计时至灯光显示为红色，重复3次取平均值；

d) 判定所测得的时间是否超过5 s。

## 6.6 安全要求

6.6.1 将花洒按使用状态安装，在供水温度为 $( 4 2 \pm 3 ) ^ { \circ } C$ 、动压分别为 $( 0 . 1 0 \pm 0 . 0 2 ) \ \mathrm { M P a }$ 和（0.30±0.02）MPa的条件下稳定使用 $1 0 \mathrm { { m i n } \pm 1 0 \mathrm { { s } } }$ 后，凭手感检查花洒的各部件是否灵活；检查花洒的各水流喷射方式是否发生变化。

6.6.2 将花洒按使用状态安装，在供水温度为 $( 7 0 \pm 3 ) ^ { \circ } ($ 、动压分别为 $( 0 . 0 5 \pm 0 . 0 2 ) \ \mathrm { M P a }$ 和（0.50±0.02）MPa的条件下，稳定使用 $1 0 \mathrm { m i n } { \pm } 1 0 \mathrm { s }$ 后，凭手感检查花洒的各部件是否灵活；检查花洒是否有明显变形，花洒的各水流喷射方式是否发生变化。

6.6.3 将花洒按使用状态安装，在供水温度为常温、动压为 $( 1 . 0 0 \pm 0 . 0 2 ) \ \mathrm { M P a }$ 的条件下，将花洒出水模式切换至最大流量状态，测试电源发电电压值。

## 6.14 寿命

## 6.14.1 功能转换寿命

在图3所示的管路上按使用状态进行安装，在水温不高于30℃、动压为（0.30±0.02）MPa的条件下，使花洒在各种水流喷射方式下进行转换并复原为一次循环，进行了10000次循环后，按6.7的规定进行检测。

## 6.14.2 球形连接摇摆寿命

对于带有球形连接的可活动的固定式花洒或花洒喷头，在图3所示的管路上按使用状态进行安装，在水温不高于30℃、动压为（0.30±0.02）MPa的条件下，使花洒在一个可活动平面范围内摆动并回复原位为1次循环，以10次/min\~12次/min，进行10000次循环后，调节试验动压分别为（0.05±0.02）MPa和 $( 0 . 5 0 { \scriptstyle \pm 0 . 0 2 } )$ MPa，并在各压力下保持5min±10s，检查球形连接部位是否有渗水现象。

## 6.14.3 显示寿命

花洒按正常使用状态安装，保持动压为（0.30±0.02）MPa、流量为（9.5±1）L/min的试验条件，按下列步骤进行循环：

a）在水温为（10±2）℃的情况下，测试5min;

b）在水温为（36±2）℃的情况下，测试20min，每120s停1次（停止通水时间为5s\~10s）；

c）在水温为（50±2）℃的情况下，测试5min;

步骤a、b、c、b为1个周期，共进行2000个周期，测试过程中观察灯光是否正常，试验后按照6.5进行显示功能检验。

## 6.15 防虹吸性能

如图6所示，将防虹吸装置的出水口安装一根（1000±20）mm的软管，软管的另一端连接一根内径为（13.0+0.5）mm的透明观察管，在防虹吸装置进水口施加真空度为17.0kPa，保持30s；将进水口真空度分别依次增加到34.0 kPa、51.0kPa、68.0 kPa、85.0kPa，并各保持30 s；然后将真空度逐渐从85.0kPa降至0kPa。以上步骤为1次循环，测量并记录观察管内的水位上升的最大高度。共进行5次循环，取最大值。

## 6.16 电路防护性能

将花洒浸泡在初始温度为（49±1）℃的水中，花洒上表面与水平面距离不小于1000mm，静置并自然冷却至24h后，按照6.5.3和6.5.4进行检验。

## 8 标志、包装、运输和贮存

## 8.1 标志

花洒上应有明显清晰、不易涂改的注册商标。

合格证应包含产品名称、商标或制造厂名称、检验员代号、生产日期。

包装上应标明产品名称、产品型号、商标、制造厂名称和厂址及采用的标准号。

包装内应附有合格证和使用说明书，如有附件和备件，应有装箱清单。

每套产品应分别包装，避免产品之间发生碰撞。

## 8.3 运输

产品在运输过程中应避免冲击、挤压、雨淋、受潮及化学品的腐蚀。

## 8.4 贮存

产品应贮存在通风良好、干燥的室内，不应与酸、碱等有腐蚀性的物品共贮。

## 温降试验方法

## B.1 范围

本附录适用于测定经花洒流出的水流在一定落差下温度的下降量。

## B.2 原理

在动压力为（0.25±0.02）MPa下，热水经花洒流出后，在花洒面盘下方（150±10）mm和（750±10）mm处测得的水温的差值。

## B.3 设备与环境要求

应使用以下设备，也可使用其他具有相同效果的设备。

a) 如图3所示的供水系统和管道系统，供水系统应可提供水温稳定的热水；

b)一个如图 A.1 所示的温度测量装置；

c) 精度为1mm 的直尺；

d） 环境：周围空气温度为（20±3）℃，不应有明显的空气流动。

## B.4 测试步骤

按照以下步骤进行测试：

a）将花洒按使用状态安装，若需要与手柄、软管、限流器或防回流装置等其他配件一起安装时，应按照制造商的使用说明书来进行；

b)对于两个以上功能的花洒，应把花洒设在流量最大的功能上进行；

c)将花洒安装在测试设备中并与供水系统相连接；

d）将测温装置置于花洒面盘正下方（150±10）mm处；

e）测定周围环境温度；

f）调节供水系统的温度，使供水温度高于环境温度 $( 2 0 \pm 3 ) ^ { \circ } \mathrm { C }$

g)打开供水系统，让热水流经花洒，调节供水动压为 $( 0 . 2 5 { \pm } 0 . 0 2 )$ MPa并保持稳定不少于1 min;

h）记录温度表稳定后的温度值；

i）把测温装置水平放在花洒面盘下方（750±10）mm处，选择合适的位置，使温度达到最大值，记录温度表稳定后的温度值；

j）把测温装置置于步骤d)的位置，记录温度表稳定后的温度值；

k）若在花洒面盘正下方（150±10）mm处两次测得的温度值之差大于0.5K，则重复步骤g）～步骤j）；

1）若在花洒面盘正下方（150±10）mm处两次测得的温度值之差不大于0.5K，则计算步骤g）和步骤i）的温度差，即为所测温降。
