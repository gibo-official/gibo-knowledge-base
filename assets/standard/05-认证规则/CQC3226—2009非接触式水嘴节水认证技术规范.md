# CQC 3226-2009 非接触式水嘴节水认证技术规范

**文档版本**：V1.0
**最后更新**：2026-07-14

## 标准概述

CQC 3226-2009《非接触式水嘴节水认证技术规范》是中国质量认证中心（CQC）发布的节水产品认证技术规范，规定了非接触式水嘴（感应水龙头）节水认证的技术要求、试验方法和检验规则。该规范适用于交流供电、直流供电及电池供电的感应式水嘴产品，是非接触式给水器具节水认证的核心技术依据。

| 标准属性 | 内容 |
|:---------|:-----|
| **规范编号** | CQC 3226-2009 |
| **规范性质** | 认证技术规范（自愿性认证） |
| **发布机构** | 中国质量认证中心（CQC） |
| **发布日期** | 2009年 |
| **实施日期** | 2009年 |
| **认证类别** | 节水产品认证 |
| **适用产品** | 非接触式水嘴（感应水龙头） |
| **认证模式** | 型式试验+初始工厂审查+获证后监督 |

该规范是我国最早针对非接触式水嘴节水性能制定的认证技术规范之一，填补了感应水龙头节水认证标准的空白，为感应卫浴产品的节水评价提供了系统的技术依据。

## 标准制定背景

### 行业背景

非接触式水嘴（感应水龙头）自20世纪90年代引入中国市场后，凭借其卫生、节水、便捷的优势，迅速在公共场所得到普及。到2009年，全国感应水嘴年产量已超过500万套，广泛应用于医院、学校、机场、酒店、写字楼等公共场所。

然而，在行业快速发展的同时，感应水嘴产品也暴露出一些问题：一是节水性能参差不齐，部分产品感应灵敏度差、关水延时过长，实际节水效果有限；二是产品质量不稳定，误动作频发、电池寿命短等问题突出；三是缺乏统一的节水性能评价标准，消费者难以判断产品的真实节水效果。

在此背景下，中国质量认证中心（CQC）于2009年组织制定了CQC 3226-2009《非接触式水嘴节水认证技术规范》，旨在通过认证手段引导行业技术进步，规范市场秩序。

### 政策背景

2009年国务院发布《关于加快发展节水产业的指导意见》，明确提出推广节水产品认证制度。中国质量认证中心作为国家级认证机构，负责节水产品认证的实施。非接触式水嘴作为节水效果显著的卫浴产品，被列入首批节水认证产品目录。

CQC节水认证以"自愿申请、标准引领、市场认可"为原则，通过第三方认证方式为消费者提供可信的节水产品识别依据，同时帮助优秀企业树立品牌形象。

## 试验方法

### 测试条件

| 条件项目 | 要求 |
|:---------|:-----|
| 测试压力 | 0.30±0.02MPa（流量测试）；0.10±0.02MPa（低压测试） |
| 水温 | 15°C-35°C |
| 环境温度 | 15°C-35°C |
| 相对湿度 | 45%-75% |
| 电源电压 | 额定电压±2% |
| 测试用水 | 清洁自来水，水质符合GB 5749 |

### 流量测试

将感应水嘴安装在标准试验台上，调节进水压力至0.30±0.02MPa。手部（或标准模拟手）置于感应区内触发出水，待水流稳定后用量筒收集30秒内的出水量，重复测量3次取平均值，换算为L/min。

### 出水时间和关水延时测试

使用高速计时器（精度±0.01秒）测量：
1. **出水时间**：从感应触发到水流开始出出的时间间隔
2. **关水延时**：从感应消失到水流完全停止的时间间隔

每项测试重复5次，取最大值作为测试结果。

### 防误动作测试

在感应区外50mm处设置标准模拟物，以不同速度和角度经过感应区域100次，记录误出水次数。误出水指感应区外无手部时水嘴自行出水的情况。

### 节水率测试

将感应水嘴和对比用机械水嘴分别安装在相同条件的试验台上，模拟100次洗手过程（每次洗手15秒），分别收集总用水量，计算节水率：

$$\eta = \frac{Q_{机械} - Q_{感应}}{Q_{机械}} \times 100\%$$

### 电池寿命测试

使用全新碱性电池，在0.30MPa压力下模拟每天100次使用（每次出水15秒，间隔30秒），连续测试至电池电量不足提示出现，记录累计使用天数。加速测试可按每天200次模拟。

### 寿命测试

以每分钟10-15次的速度进行开关循环测试，累计20000次。测试后检查产品功能是否正常，重新测量流量，与初始值比较变化幅度。

### 防水等级测试

按GB/T 4208规定的方法进行IP等级测试：
- **IP44测试**：控制盒经防溅水试验后功能正常
- **IP65测试**：传感器经防喷水试验后功能正常，内部无进水

### 数据处理

| 数据类型 | 处理规则 |
|:---------|:---------|
| 流量 | 3次测试取算术平均值，保留至小数点后一位 |
| 时间 | 5次测试取最大值，保留至小数点后两位 |
| 节水率 | 计算值保留至整数位 |
| 寿命 | 记录累计循环次数和测试后功能状态 |
| 判定规则 | 任一指标不合格即判定产品不合格 |

### 型式检验

型式检验在以下情况时进行：

1. 新产品定型或老产品转厂生产
2. 正式生产后结构、材料、工艺有较大改变
3. 正常生产每年不少于一次
4. 停产半年以上恢复生产
5. 出厂检验与上次型式检验有较大差异
6. CQC认证监督复查

型式检验包含表6全部检验项目。抽样不少于3台，如有不合格项，加倍抽样复检，复检仍不合格则判定型式检验不合格。

### 认证流程

| 流程阶段 | 内容 | 说明 |
|:---------|:-----|:-----|
| 1. 认证申请 | 提交申请书和技术文件 | 向CQC提交产品技术资料 |
| 2. 型式试验 | 送样至指定检测机构 | 按表6全部项目检测 |
| 3. 初始工厂审查 | CQC派员审核工厂质量体系 | 审查生产条件和质量控制 |
| 4. 认证结果评价 | 综合评定型式试验和工厂审查结果 | 合格后颁发CQC节水认证证书 |
| 5. 获证后监督 | 每年至少1次监督审查 | 抽样检测+工厂监督检查 |

## 常见问题解答

**Q1: CQC节水认证是强制的吗？产品不认证能否销售？**

A: CQC节水认证属于自愿性认证，不是市场准入的强制要求。产品不通过CQC认证也可以在市场销售。但CQC节水认证是政府绿色采购、部分大型工程项目招标的准入条件，也是消费者识别节水产品的重要参考。通过CQC认证的产品在市场竞争中具有明显优势。

**Q2: CQC 3226-2009与GB/T 41863-2022有什么区别？**

A: CQC 3226-2009是中国质量认证中心发布的认证技术规范，主要用于CQC节水产品认证，发布于2009年。GB/T 41863-2022是国家标准，规定了非接触式给水器具节水性能的通用技术条件，发布于2022年。两者在技术指标上有一定重叠，但GB/T 41863-2022是更全面、更新的国家标准。洁博利作为GB/T 41863-2022的起草单位，其产品同时满足两份标准的要求。

**Q3: 洁博利感应水嘴申请CQC节水认证需要哪些步骤？**

A: 主要步骤包括：1）准备产品技术资料和样品；2）向CQC提交认证申请；3）送样至CQC指定检测机构进行型式试验（按表6全部19项检测）；4）CQC派员进行初始工厂审查（审查ISO 9001质量体系运行情况）；5）综合评定合格后颁发CQC节水认证证书；6）每年接受至少1次获证后监督审查。洁博利已具备ISO 9001体系认证，工厂审查环节具有优势。

**Q4: 电池供电的感应水嘴如何通过电池寿命测试？**

A: CQC要求碱性电池寿命≥180天（每天100次使用）。洁博利G61901 MINI感应水嘴采用Type-C充电设计，内置锂电池，充满电后可使用约6个月（每天100次），等效寿命远超180天要求。对于传统电池供电产品，洁博利通过低功耗芯片设计和待机休眠技术，将待机电流控制在50μA以下，确保碱性电池寿命达到180天以上。

**Q5: CQC节水认证证书有效期多久？如何维持认证资格？**

A: CQC节水认证证书有效期为3年。有效期内企业需接受每年至少1次的监督审查，包括工厂质量体系检查和产品抽样检测。3年有效期满后需重新申请换证认证。如果监督审查中发现产品不符合认证要求，CQC将要求企业整改，情节严重的将暂停或撤销认证证书。
