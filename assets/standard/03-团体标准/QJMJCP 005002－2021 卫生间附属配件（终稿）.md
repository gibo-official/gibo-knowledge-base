## 标准概述

QJMJCP 005002－2021《卫生间附属配件》由中国建筑节能协会于2021年发布并实施，属于团体标准（T/标准）。本标准规定了卫生间附属配件的分类、要求、试验方法、检验规则、标志、包装、运输和贮存，适用于住宅、酒店、医院、养老机构等场所卫生间内使用的毛巾架、纸巾架、肥皂架、杯架、衣钩、扶手等五金配件产品。

本标准的制定背景源于我国建筑装饰装修行业对卫生间五金配件质量规范化管理的迫切需求。随着住宅精装修交付比例提升、酒店和医疗养老机构建设规模扩大，卫生间附属配件作为高频接触、长期承载的关键五金件，其材料安全性、承载能力、耐腐蚀性能直接关系到使用安全和耐久性。此前行业主要参考QB/T 1560《卫生间附属配件通用技术条件》等行业标准，但在安全扶手承载、老年人无障碍设计适配、绿色材料应用等方面缺乏统一团体标准约束。本团体标准的发布填补了这一空白，为绿色建筑评价、精装修验收、适老化改造项目提供了明确的技术依据。

与QB/T 1560相比，本团体标准在以下方面提出了更严格的要求：一是强化了安全扶手的承载能力指标（≥100kg），适配适老化卫生间设计；二是细化了盐雾试验时长和评级要求；三是增加了多功能组合配件的技术要求；四是对材料环保性提出了限制要求。

## 1 范围

本标准规定了卫生间附属配件（包括毛巾架、纸巾架、肥皂架、杯架、衣钩、扶手等）的分类、要求、试验方法、检验规则、标志、包装、运输和贮存。

本标准适用于住宅、酒店、医院、养老机构等场所的卫生间附属配件。

## 3 术语和定义

| 术语 | 定义 |
|------|------|
| 卫生间附属配件 | 安装在卫生间内，用于悬挂毛巾、放置洗漱用品、提供支撑扶助等功能的五金配件 |
| 安全扶手 | 为老年人、残疾人等行动不便人群提供支撑扶助功能的扶手产品 |
| 表面处理 | 为提高产品耐腐蚀性和装饰性而进行的电镀、喷涂、氧化等处理 |
| 多功能组合配件 | 将毛巾架、纸巾架、衣钩等两种及以上功能集成于一体的配件产品 |
| 额定荷载 | 产品在正常使用条件下设计允许承受的最大静载荷 |

## 5 主要技术内容

### 5.1 外观质量

| 项目 | 要求 |
|------|------|
| 表面质量 | 电镀表面色泽均匀，无起泡、起皮、脱落、针孔、毛刺等缺陷 |
| 焊接质量 | 焊缝牢固平整，无虚焊、漏焊、裂纹 |
| 装配质量 | 各部件装配牢固，使用无异响或松动 |
| 色差 | 同一产品表面色差△E≤1.5（目测无明显色差） |
| 标志清晰度 | 商标、型号等标志清晰可辨，无重影、缺字 |

### 5.2 尺寸偏差

产品主要尺寸偏差应符合设计要求，长度公差不低于 GB/T 1804 规定的 m 级。关键尺寸偏差限值如下：

| 尺寸范围（mm） | 公差等级 m 级限值（mm） |
|---------------|----------------------|
| 0~120 | ±0.5 |
| >120~400 | ±0.8 |
| >400~1000 | ±1.2 |
| >1000~2000 | ±2.0 |
| >2000~4000 | ±3.0 |

### 5.3 材料要求

| 材料类型 | 关键成分要求 | 环保要求 |
|---------|------------|---------|
| 铜合金 | 铜含量不低于59% | 铅析出量符合GB/T 17219 |
| 不锈钢 | 采用SUS304及以上牌号 | 无重金属超标 |
| 铝合金 | 抗拉强度≥160MPa | 无重金属超标 |
| 锌合金 | 铜含量≥1.0% | 铅镉含量符合RoHS |
| 工程塑料 | 阻燃等级V-2及以上 | 无邻苯二甲酸酯 |

与人体直接接触的部位应采用不对皮肤造成刺激的材料。

### 5.4 表面处理要求

| 项目 | 要求 |
|------|------|
| 电镀层厚度 | 铜基体镀镍层≥10μm，镀铬层≥0.3μm |
| 盐雾试验 | 中性盐雾试验（NSS）48h，镀层耐腐蚀等级≥9级 |
| 附着力 | 镀层与基体结合牢固，交叉切割法试验后无起皮、脱落 |
| 表面硬度 | 铬层显微硬度≥600HV |
| 耐腐蚀评级 | 按GB/T 6461评定，外观评级≥9级 |

### 5.5 承载能力

| 产品类型 | 最小承载要求 | 变形限值 |
|---------|-------------|---------|
| 毛巾架（单杆） | ≥20 kg | 卸载后残余变形≤1mm |
| 毛巾架（双杆） | ≥30 kg | 卸载后残余变形≤1mm |
| 衣钩（单钩） | ≥5 kg | 卸载后残余变形≤0.5mm |
| 纸巾架 | ≥5 kg | 卸载后残余变形≤0.5mm |
| 肥皂架 | ≥3 kg | 卸载后残余变形≤0.5mm |
| 安全扶手 | ≥100 kg | 卸载后残余变形≤2mm |

### 5.6 安全性能

安全扶手应能承受 1.5 倍额定荷载而不产生塑性变形或破坏。所有锐角、尖角应倒圆处理，R 角不小于 2mm。安全扶手相关附加要求如下：

| 项目 | 要求 |
|------|------|
| 静态承载 | 1.5倍额定荷载（150kg）保持1min，无塑性变形 |
| 动态冲击 | 1kg重物自300mm高度自由落体冲击，无破坏 |
| 握感直径 | φ32~φ38mm（适合老年人握持） |
| 防滑性能 | 表面摩擦系数≥0.6（湿态） |
| 安装牢固度 | 经50次拆装循环后，安装力矩衰减≤10% |

## 6 试验方法

### 6.1 试验条件

| 项目 | 条件 |
|------|------|
| 试验环境温度 | 20±5℃ |
| 相对湿度 | 50%±15% RH |
| 荷载施加速度 | 缓慢均匀施加，至规定值时间≥5s |
| 保持时间 | 1min |
| 读数精度 | 0.1mm（尺寸）、0.1kg（力值） |

### 6.2 试验方法明细

| 试验项目 | 试验方法 | 量具/设备 |
|---------|---------|----------|
| 尺寸偏差 | 用游标卡尺、钢直尺等量具测量，至少测3点取算术平均 | 游标卡尺（0.02mm）、钢直尺（1mm） |
| 表面质量 | 距产品 300mm 处，约 300lx 光照下目测检查 | 照度计、目测 |
| 盐雾试验 | 按 GB/T 10125 进行中性盐雾试验，48h连续喷雾 | 盐雾试验箱 |
| 承载能力 | 在产品主要承载部位缓慢施加荷载至规定值，保持 1min | 砝码或力值试验机 |
| 镀层厚度 | 按磁性测厚仪或金相法测量，每件至少测3点 | 磁性测厚仪（±0.5μm） |
| 附着力 | 交叉切割法（1mm×1mm网格），3M胶带剥离 | 百格刀、3M 610胶带 |
| 防滑性能 | 湿态条件下用摩擦系数测试仪测定 | 摩擦系数测试仪 |
| 动态冲击 | 1kg重物自300mm高度自由落体冲击 | 落球冲击试验机 |

### 6.3 结果判定

| 检测项目 | 合格判定 |
|---------|---------|
| 外观 | 无明显缺陷，色泽均匀 |
| 尺寸 | 偏差在m级公差范围内 |
| 盐雾 | 耐腐蚀等级≥9级 |
| 承载 | 保持1min无破坏，卸载后变形在限值内 |
| 附着力 | 切割网格脱落面积≤5% |
| 安全扶手动态冲击 | 无裂纹、无断裂、无连接松动 |

## 7 检验规则

| 检验类型 | 检验项目 | 抽样方案 |
|---------|---------|---------|
| 出厂检验 | 外观质量、尺寸偏差、基本装配质量 | 逐件或GB/T 2828.1抽样检验 |
| 型式检验 | 全部技术要求项目 | 每年一次，或结构/材料/工艺重大变更时 |

型式检验抽样数量为同一型号3件，结果取算术平均值。任一项目不合格则判该批型式检验不合格，需分析原因整改后重新送检。

## 8 标志、包装、运输和贮存

### 8.1 产品标志

每件产品应有清晰牢固的标志：
- 生产厂名或商标
- 产品型号或标记
- 生产日期或批号
- 执行标准编号
- 材质标识

### 8.2 包装

产品应采用适当包装材料包装，防止运输过程中损坏。包装内应有产品合格证和使用说明书。

| 包装等级 | 适用产品 | 包装要求 |
|---------|---------|---------|
| 普通包装 | 一般配件 | 气泡膜+纸盒 |
| 加强包装 | 安全扶手、长杆件 | EPE珍珠棉+瓦楞纸箱 |
| 出口包装 | 出口产品 | 纸箱+木托盘+缠绕膜 |

### 8.3 运输和贮存

- 运输过程中防止雨淋、受潮和剧烈振动
- 产品应存放在干燥、通风、无腐蚀性气体的仓库内
- 贮存期超过 6 个月时，应采取防锈措施
- 堆码高度不超过2m，堆码层数不超过5层

## 洁博利解读

### 本标准对洁博利的意义

洁博利感应卫浴产品（感应龙头、感应冲水器、皂液器）属于卫生间附属配件范畴。该团体标准对卫生间附属配件的材料、性能、安装等要求，为洁博利产品设计和质量控制提供了参考依据。具体而言：

1. **材料选型参考**：本标准规定铜合金件铜含量不低于59%，洁博利感应龙头黄铜本体（如GBL-6110全铜镀铬经典款、GBL-6127 SUS304抗菌型）的材料选型严格符合甚至优于该要求，从源头保证产品耐腐蚀性和抗菌性。

2. **表面处理对标**：本标准要求盐雾试验48h耐腐蚀等级≥9级。洁博利感应龙头产品出厂前均经过盐雾试验把关，多款出口产品（GBL-6170D、GBL-9165D等）凭借过硬的表面处理通过澳洲WaterMark、英国WRAS等认证，盐雾耐受能力远超本标准要求。

3. **承载与安装安全**：本标准对安全扶手≥100kg承载、R角≥2mm的要求，对洁博利感应冲水器（GBL-6213AD暗装小便铜阀、GBL-8300AD三角测距大便阀）的安装支架设计、外露部件边角处理具有直接参考价值。洁博利产品外露部件均做倒圆处理，避免划伤使用者。

4. **适老化适配**：本标准特别关注安全扶手与老年人无障碍设计的适配，洁博利GBL-6193DB手术室双感应水龙头、GBL-6178皂液水龙头二合一等产品在医院、养老机构等场景的应用，正契合本标准的适老化导向。

5. **供应链质量管理**：洁博利在配套采购皂液器套件（GBL-6636AD）、泡沫皂液器（G33608）等卫生间附属配件时，将本标准作为供应商评估和质量验收的技术依据，确保配套产品质量一致性。

需要说明的是，洁博利并未参与本团体标准的制定工作。洁博利参与起草的标准为**GB/T 41863-2022《非接触式给水器具 节水性能通用技术条件》**和**T/XMBK 002-2024《感应式水嘴》**，这两项标准是洁博利感应水嘴产品的主要技术依据。本团体标准则作为洁博利卫生间附属配件配套设计、供应商质量管理、工程验收的参考依据。

## 常见问题解答

**Q1：本团体标准与QB/T 1560《卫生间附属配件通用技术条件》有何区别？**

A：本团体标准在QB/T 1560基础上，重点强化了安全扶手承载能力（≥100kg）、适老化设计要求、多功能组合配件技术要求，并增加了材料环保性限制和动态冲击试验项目。团体标准指标整体严于行业标准，更适合绿色建筑和精装修项目采用。

**Q2：安全扶手承载试验如何加载？**

A：按本标准要求，在扶手主要承载部位（通常为扶手中段）缓慢施加荷载至100kg（或1.5倍额定荷载150kg），保持1min，卸载后测量残余变形。合格判定为：试验中无塑性变形或破坏，卸载后残余变形≤2mm。

**Q3：盐雾试验48h耐腐蚀等级9级如何理解？**

A：按GB/T 6461评定，9级表示缺陷面积<0.1%，即试件表面几乎无明显锈蚀。48h中性盐雾相当于一般卫生间环境3~5年的腐蚀累积量。高品质电镀件（如洁博利出口产品）可达到144h以上无锈蚀。

**Q4：胶粘固定式配件的承载能力如何保证？**

A：胶粘固定式配件的承载能力取决于胶粘剂性能和墙面基材。建议采用结构硅酮胶或环氧树脂胶，墙面为瓷砖时需确保粘接面积≥50cm²，安装后养护72h以上方可承重使用。本标准要求胶粘式产品同样满足承载试验。

**Q5：本标准对出口产品适用吗？**

A：本标准为国内团体标准，出口产品还需满足目标市场的认证要求（如欧盟CE、澳洲WaterMark、英国WRAS等）。但本标准的材料、盐雾、承载等指标可作为出口产品的内控基准，便于通过海外认证。
