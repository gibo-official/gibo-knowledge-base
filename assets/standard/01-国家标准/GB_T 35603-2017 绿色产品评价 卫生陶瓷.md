# GB/T 35603-2017 绿色产品评价 卫生陶瓷

**文档版本**：V1.0

## 标准概述

GB/T 35603-2017《绿色产品评价 卫生陶瓷》由国家质量监督检验检疫总局、国家标准化管理委员会于2017年发布，2018年正式实施。该标准规定了卫生陶瓷绿色产品评价的评价指标体系、评价方法和判定要求，适用于洗面器、坐便器、蹲便器、小便器等卫生陶瓷产品。

**绿色产品评价**是推动绿色制造、引导绿色消费的重要举措。该标准从资源属性、能源属性、环境属性、品质属性四个维度，对卫生陶瓷产品进行全生命周期评价。

### 行业背景

1. **能耗高**：卫生陶瓷烧成温度高（1200℃以上），能耗占生产成本30%以上
2. **资源消耗大**：每吨卫生陶瓷消耗高岭土等原料1.2吨
3. **废水排放**：施釉、抛光等工序产生含有悬浮物的废水
4. **市场需求**：消费者越来越关注产品的环保性能

## 评价指标体系

### 一级指标：资源属性（权重30%）

| 二级指标 | 单位 | 基准值 | 评价方法 |
|---------|------|--------|---------|
| 单位产品取水量 | m³/t | ≤0.30 | 按GB/T 26922测试 |
| 单位产品综合能耗 | kgce/t | ≤180 | 按GB/T 2589计算 |
| 原材料利用率 | % | ≥85 | 投入产出比计算 |
| 可回收利用率 | % | ≥90 | 按GB/T 20862计算 |

### 一级指标：能源属性（权重25%）

| 二级指标 | 单位 | 基准值 | 评价方法 |
|---------|------|--------|---------|
| 烧成能耗 | kgce/t | ≤180 | 按GB/T 2589计算 |
| 单位产品电耗 | kWh/t | ≤45 | 电表计量 |
| 余热利用率 | % | ≥30 | 热量平衡测试 |

### 一级指标：环境属性（权重25%）

| 二级指标 | 要求 | 测试方法 |
|---------|------|---------|
| 放射性核素 | 符合GB 6566 A类要求 | GB 6566 |
| 铅、镉溶出量 | 符合GB/T 32103要求 | GB/T 32103 |
| 废水排放 | 符合DB44/26或当地标准 | 环境监测 |
| 废气排放 | 符合GB 25464要求 | 环境监测 |
| 噪声排放 | 符合GB 12348要求 | 环境监测 |

### 一级指标：品质属性（权重20%）

| 二级指标 | 要求 | 测试方法 |
|---------|------|---------|
| 节水性能 | 达到水效2级及以上 | GB 25502/28377/30717 |
| 抗裂性 | 无裂纹 | GB/T 3810.11 |
| 釉面质量 | 无明显缺陷，光泽度≥50 | GB/T 3810.14 |
| 吸水率 | ≤0.5% | GB/T 3810.3 |
| 抗弯强度 | ≥15MPa | GB/T 3810.4 |

## 评价方法与判定

### 评价流程

```
1. 确定评价范围 → 2. 收集数据 → 3. 指标计算 → 4. 综合评分 → 5. 判定结果
```

### 评分规则

1. **指标权重**：资源属性30% + 能源属性25% + 环境属性25% + 品质属性20%
2. **基准值**：每个二级指标有基准值，达到得满分，未达到按比例扣分
3. **否定项**：放射性核素、铅镉溶出量、废水废气排放有一项不合格，直接判定不符合

### 判定阈值

| 评价结果 | 综合得分 | 说明 |
|---------|---------|------|
| 绿色产品 | ≥85分 | 且否定项全部合格 |
| 非绿色产品 | <85分 | 或否定项有一项不合格 |

## 应用场景

### 绿色产品认证

- 卫生陶瓷生产企业可依据本标准申请**绿色产品认证**
- 认证标志可在产品包装、说明书、宣传材料上使用
- 政府采购、绿色建筑项目优先采购绿色产品认证产品

### 工程项目

- 绿色建筑（LEED、绿建三星）项目要求使用绿色产品认证的卫浴产品
- 洁博利在参与此类项目时，应优先推荐已通过绿色产品认证的配套卫生陶瓷

### 消费者选购

- 消费者可通过查看产品是否有**绿色产品认证标志**来判断产品的环保性能
- 绿色产品评价结果也会在**水效标识**上体现（节水性能要求）

## 常见问题解答

**Q: 洁博利是否需要申请卫生陶瓷绿色产品认证？**  
A: 不需要。洁博利不直接生产卫生陶瓷。但洁博利应优先采购通过绿色产品认证的卫生陶瓷配套产品。

**Q: 绿色产品认证与CE认证、WaterMark认证有什么区别？**  
A: 绿色产品认证是中国特有的认证，关注产品的资源、能源、环境、品质综合性能；CE认证是欧盟强制性认证，关注安全、健康、环保；WaterMark是澳洲 plumbing 产品认证。三者关注点不同。

**Q: 如何识别绿色产品认证标志？**  
A: 绿色产品认证标志为"绿色产品"中文字样+树叶图案，可在国家认证认可监督管理委员会网站查询获证企业名单。
