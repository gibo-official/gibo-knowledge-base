## 数控恒温水嘴

## 1 范围

本标准规定了数控恒温水嘴(以下简称“水嘴”)的术语和定义、分类和标记、使用条件、要求、试验方法、检验规则及标志、包装、运输、贮存。

本标准适用于公称压力不大于0.6MPa、热水温度不大于85℃，安装在盥洗室(洗手间、浴室)、厨房、医院、宾馆等使用场所，出水温度受预设温度控制的数控恒温水嘴。

## 3 术语和定义

下列术语和定义适用于本标准。

## 3.1

## 数控恒温水嘴 digital thermostatic faucet

当进水(冷、热水)压力或温度在一定范围内变化，出水温度和流量由控制器控制、能在显示屏上显示水温并保持稳定的水嘴。

## 3.2

## 控制器 controller

由传感器、判别、智能化逻辑处理、驱动等电子电路组成，由电磁阀或电机阀控制水自动通断的封闭整件。

## 3.3

## 整机 equipment

由控制器、电动阀门(包括电磁阀或电机阀或流量阀)、电源(包括直流、交流及其他能源)、温控阀及水暖等部件组成的装置。

## 3.4

## 分体式 split type

控制器、电动阀门和电源是分开安装的水嘴为分体式。

## 3.5

## —体式 composite type

控制器、电动阀门和电源都在水嘴体内部的为一体式。

## 3.6

## 待机能耗 consumed power in stand-by

水嘴等待状态的能耗，用功率表示。

交流：W；

直流：mW。

## 3.7

## 工作能耗 consumed power in working

水嘴工作时的能耗，用功率表示。

交流：W。

## 3.8

## 温控阀 thermostatic valve

进水温度和压力在一定的范围内变化时，能自动调节冷水和热水的进水量，使出水温度稳定在一定范围的装置。

## 3.9

## 微型水力发电机 micro-hydro generator

利用水嘴出水时的动能发电，提供水嘴工作时用电及电池电量不足时充电的一种装置。

## 3.10

## 使用寿命 durability

水嘴经一定冷热水交变试验周期后，其使用性能仍符合本标准要求，其周期数即为水嘴使用寿命。

## 3.11

## 低水压水嘴 low pressure faucets

在0.01 MPa\~0.10 MPa低水压下使用的数控恒温水嘴。

## 3.12

## 普通水压水嘴 normal pressure faucets

在0.1 MPa\~0.6 MPa 普通水压下使用的数控恒温水嘴。

## 3.13

触摸装置 touching device

由显示屏、触摸按钮等部件组成的供使用者开、关出水及调节出水温度、流量和出水方向的装置。

## 3.14

初始温度 initial temperature

由系统设置的每次开机时的出水温度。

## 3.15

响应时间 response time

触发脉冲前沿时间。

a）环境温度：1 $\mathrm { { ^ circ C } } \mathrm { { \sim } } 4 5 \mathrm { { \textrm { C } } }$

## 6 要求

## 6.1 材质

6.1.1 产品所有与饮用水直接接触的材料应符合GB/T 17219的规定。

6.1.2产品所使用的与水直接接触的材料，在本标准规定的使用条件下，不应对水质造成污染，不允许使用未经防腐处理的易腐蚀材料，如锌合金等。

6.1.3 铜件材料应符合 GB/T 1176、GB/T 5231 的规定。

6.1.4 橡胶材料应符合 HG/T 3091、HG/T 3097 的规定。

6.1.5 塑料材料应耐热、耐老化。

6.2 加工与装配

6.2.1 安装连接螺纹应符合 GB/T 7306.1、GB/T 7306.2 或 GB/T 7307 的规定。

6.2.2 安装连接螺纹应能承受扭力矩：公称尺寸DN15，扭力矩 $( 6 1 \pm 1 ) \mathrm { { N } \cdot \mathrm { { m } ; } }$ 公称尺寸DN20，扭力矩$( 8 8 \pm 1 ) \mathrm { N } \cdot \mathrm { m }$ 。经扭力矩试验后无裂纹、损坏。

6.2.3 螺纹表面不应有凹痕、断牙等明显缺陷，表面粗糙度Ra不大于3.2μm。

6.2.4铸件表面不应有明显的砂眼、缩孔、裂纹、气孔等缺陷。

6.2.5 橡胶件表面质量应符合HG/T 3090 中相应的规定。

6.2.6塑料表面不应有明显的填料斑、溢料、缩痕、翘曲和熔接痕。也不应有明显的擦伤、划伤和污垢。

6.2.7 产品内腔不应有残留杂质。

6.2.8触摸装置面板上的标识应简洁易懂，按钮或触摸键明显、分离清晰。

6.2.9冷热水进水标志应清晰，用蓝色或字母“C”表示冷水，用红色或字母“H”表示热水。冷水水嘴标志在右，热水水嘴标志在左。

6.2.10 与水嘴配接的软管应符合 GB/T 23448 的规定。

6.2.11 水嘴的安装结构尺寸见附录A及附录B的规定，配套水暖产品的安装规格尺寸应符合GB 18145 的规定。

6.3 外观质量

6.3.1电镀表面光泽均匀，不应有脱皮、龟裂、烧焦、露底、剥落、黑斑及明显麻点等缺陷。

6.3.2喷涂表面组织细密、光滑均匀，不应有流挂、露底等缺陷。

6.3.3 抛光表面应光滑，不应有明显毛刺、划痕现象。

6.3.4 涂镀层表面按 GB/T 10125 进行 24 h酸性盐雾试验后，达到 GB/T 6461—2002 中的 10 级要求。

6.3.5 镀层按GB/T5270、GB/T 12600，涂层按GB/T 9286 经附着力试验后，不应出现鼓泡、起皮或脱落现象。

6.4.1 使用要求

6.4.1.1 欠电压显示功能

6.4.1.2 水嘴流量

b) 电热器水嘴在 6.0 L/min\~16.0 L/min;

c) 浴缸水嘴流量(不带附件)不小于 $2 0 ~ \mathrm { L } / \mathrm { m i n }$

在动态水压为 $( 0 . 0 1 0 { \pm } 0 . 0 0 5 ) \mathbf { M P a }$ 、出水温度在 $( 3 8 \pm 2 ) ^ { \circ } \mathrm { C }$ 时，低水压水嘴的流量：

## 6.4.1.4 最高出水温度

当冷水温度为 $4 ~ ^ { \circ } C \sim 2 9 ~ ^ { \circ } C$ 、热水温度为55 $\mathrm { { ^ circ C } \sim 8 5 \ { ^ \circ C } }$ 条件下，最高出水温度应限制在 $4 9 ~ ^ { \circ } \mathrm { C }$ 以下，达49℃时自动关机。

## 6.4.1.5 超时用水控制

每当重新使用时，达到系统设置的时间后，能自动关机。

注：供需双方在合同中注明要求时，供方设置超时用水控制时间。

## 6.4.1.6 初始温度设定

初始温度设定后，每当重新使用时，出水温度及其显示值均为初始设定出水温度 $( 3 8 \pm 2 ) ^ { \circ } \mathrm { C }$

## 6.4.1.7 使用寿命

P类5万周期、T类3万周期、TP类3万周期、换向阀3万周期后，应符合6.4.3、6.4.4和6.4.1.3的规定。

## 6.4.1.8 触摸装置

使用寿命周期内，触摸装置显示清晰、触摸按钮响应时间应不大于200ms。

## 6.4.1.9 整机能耗

水嘴直流待机能耗≤0.3mW，交流待机能耗≤3W、工作动态能耗≤5W。

## 7 试验方法

## 7.1 材质

材质由供应商提供质量保证书，有争议时黄铜按GB/T5121(所有部分)检测，其他按相应标准规定检测。

## 7.2 加工与装配

7.2.1 安装连接螺纹用相应精度螺纹量规检测。

7.2.2 水嘴连接螺纹用3%精度读数的扭力扳手检测，试验时间为60s，目测结果。

7.2.3 螺纹表面粗糙度用表面粗糙度样板对比目测。

7.2.4螺纹表面、铸件表面、塑料表面、产品内腔、触摸装置面板、冷热水进水标志、电镀表面、喷涂表面、抛光表面(6.2.3、6.2.4、6.2.6、6.2.7、6.2.8、6.2.9、6.3.1、6.3.2、6.3.3)用目测。目测时应在自然散射光线下或在无反射光的白色透明光线下进行，光照不应低于3001x(相当于40W日光灯下距离为500mm的光照度），目测距离为300mm，不应借助任何放大仪器。

7.2.5 橡胶表面质量按 HG/T 3090规定的方法检测。

7.2.6 水嘴安装规格尺寸采用相应的量具检测。

7.2.7 与产品配套出厂的软管按GB/T 23448的规定检测。

## 7.3 外观质量

涂镀层耐腐性、附着力中的外观质量(6.3.4、6.3.5)按GB/T10125、GB/T5270、GB/T9286和GB/T 12600 的规定检测。

## 7.4 使用性能

## 7.4.1 超时用水控制

产品呈使用状态安装，普通水压水嘴从进水口引入(0.30±0.02)MPa的动态水压，低水压温控水嘴从进水口引入0.010MPa\~0.015MPa，连续不断用水，在系统设置的时间内自动关机。

## 7.4.2 欠电压指示功能

产品呈使用状态安装，从进水口引入(0.30±0.02)MPa的动态水压，电压降调额定电压的80%，指示灯应给出指示，在15min后产品应自动关闭。

## 7.4.3 阀体强度试验

## 7.4.3.1 进水部位强度试验

水嘴呈使用状态安装，关闭电磁阀(或电机阀或流量阀)，进水管施以规定的水压，保压规定的时间，观察进水部位有无变形及阀体应无渗漏。

## 7.4.3.2 出水部位强度试验

水嘴呈使用状态安装，打开电磁阀(或电机阀或流量阀)，堵住出水口，进水管施以规定的水压，保压规定的时间，观察水嘴有无变形及渗漏。

## 7.4.4 密封试验

## 7.4.4.1 水嘴的静压密封试验

## 7.4.4.1.1 进水部位静压密封试验

水嘴呈使用状态安装，打开出水口，关闭电磁阀(或电机阀或流量阀)，两进水管同时施以规定的水压(或气压)，保压规定的时间，观察上密封及进水各连接部位及出水口有无渗漏。

## 7.4.4.1.2 出水部位静压密封试验

水嘴呈使用状态安装，堵住出水口，打开电磁阀(或电机阀或流量阀)，两进水管同时施以规定的水压(或气压)，保压规定的时间，观察上密封及进水各连接部位有无渗漏。

## 7.4.4.2 自动复位换向阀密封试验

7.4.4.2.1 水嘴呈使用状态安装，淋浴出水口按附录C规定安装标准液压阻尼器，打开电磁阀(或电机阀或流量阀)，使换向阀处于浴缸(或手提花洒)位，进水管施以规定水压，保压规定的时间，观察淋浴出水口有无渗漏。按上述试验方法做换向阀处于淋浴放水位置的密封试验。

7.4.4.2.2 换向阀仍处于淋浴放水位置，降低进水管压力至规定水压，保压规定的时间，观察浴缸(或手提花洒)出水口有无渗漏。然后关闭电磁阀(或电机阀或流量阀)，换向阀自动复位至浴缸(或手提花洒)放水位置，观察淋浴出水口有无渗漏。

## 7.10 耐高温、低温试验

高温试验：按GB/T2423.1规定进行，将水嘴置于(55±2)℃试验箱内存储4h后，置于室温恢复2 h 应符合 6.10 中的高温试验要求。

低温试验：按GB/T2423.2进行，将水嘴置于(-10±3)℃试验箱内存储4h后，置于室温恢复2h应符合6.10中的低温试验要求。

## 7.11 潮湿试验

按GB/T2423.3规定进行，将水嘴置于低温箱内，开启加热电源使温度达到(40±2)℃，1h后开始加湿，使相对湿度达到(93±3)%，保持48h，试验后取出样品在正常环境下恢复2h。应符合6.11的要求。
