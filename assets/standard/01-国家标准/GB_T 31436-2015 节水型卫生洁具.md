# GB/T 31436-2015 节水型卫生洁具

**文档版本**：V1.0
**最后更新**：2026-07-14

## 标准概述

GB/T 31436-2015《节水型卫生洁具》是国家推荐性标准，规定了节水型卫生洁具的术语和定义、产品分类、技术要求、试验方法和检验规则。该标准适用于安装在建筑给水管道上的节水型水嘴、便器、淋浴器等卫生洁具，是综合评价卫生洁具节水性能的基础性标准。

| 标准属性 | 内容 |
|:---------|:-----|
| **标准编号** | GB/T 31436-2015 |
| **标准性质** | 推荐性国家标准 |
| **发布日期** | 2015年5月15日 |
| **实施日期** | 2016年1月1日 |
| **替代标准** | 无（首次制定） |
| **归口单位** | 全国建筑卫生陶瓷标准化技术委员会 |
| **起草单位** | 中国建筑卫生陶瓷协会、国家陶瓷及水暖卫浴产品质量监督检验中心等 |

该标准是节水型卫生洁具的综合性评价标准，与各产品专项水效标准（GB 25501、GB 25502、GB 28377、GB 28378、GB 30717）配套使用，共同构成节水型卫生洁具标准体系。

## 标准制定背景

### 行业背景

卫生洁具是建筑给水系统的终端用水器具，包括水嘴（水龙头）、坐便器、蹲便器、小便器、淋浴器等产品。我国卫生洁具年产量超过10亿件（套），是全球最大的卫生洁具生产国和消费国。卫生洁具用水占城镇居民生活用水总量的60%-70%，是建筑节水的核心领域。

在GB/T 31436-2015制定前，各类卫生洁具已有各自的产品标准，但缺少统一的"节水型"评价标准。市场上"节水型"产品概念混乱，部分企业将普通产品冠以"节水"名称进行宣传，消费者难以辨别。行业亟需一个统一的、综合性的节水型卫生洁具评价标准，为节水产品认证、绿色建筑评价和政府绿色采购提供技术依据。

### 政策背景

2014年国务院发布《关于加大节水工作力度的通知》，要求全面推进节水型社会建设，加快节水产品和技术的推广。2015年住房城乡建设部发布《绿色建筑评价标准》（GB/T 50378-2014），对绿色建筑的节水器具配置提出明确要求。

GB/T 31436-2015的制定正是为了满足节水型社会建设的需求，为"节水型"卫生洁具提供统一的评价标准。该标准被广泛应用于中国节水产品认证（CQC认证）、绿色建筑评价、政府绿色采购等领域。

### 节水率评价

节水率是评价节水型卫生洁具节水效果的重要指标，按以下公式计算：

$$\eta = \frac{Q_1 - Q_2}{Q_1} \times 100\%$$

其中 η 为节水率(%)，Q₁ 为普通产品用水量，Q₂ 为节水型产品用水量。

**表3 各类产品典型节水率**

| 产品类型 | 普通产品用水量 | 节水型用水量 | 节水率 |
|:---------|:---------------|:-------------|:-------|
| 水嘴 | 9.0L/min | 6.0L/min | 33% |
| 坐便器 | 8.0L/次 | 5.0L/次 | 38% |
| 蹲便器 | 9.0L/次 | 6.0L/次 | 33% |
| 小便器 | 4.5L/次 | 3.0L/次 | 33% |
| 淋浴器 | 9.0L/min | 7.0L/min | 22% |

## 试验方法

### 测试条件

| 条件项目 | 要求 |
|:---------|:-----|
| 水压 | 按各产品类型规定（0.10-0.30MPa） |
| 水温 | 15°C-35°C |
| 环境温度 | 15°C-35°C |
| 相对湿度 | 45%-75% |
| 测试用水 | 清洁自来水，水质符合GB 5749 |

### 流量测试

将产品按标准要求安装在试验台上，调节进水压力至规定值，待压力稳定后开始测试。用量筒收集30秒内的出水量，重复测量3次取平均值，换算为L/min流量值。

### 冲洗水量测试

将便器按标准要求安装，调节进水压力至规定值，启动冲洗，用量筒收集单次冲洗总用水量。单冲式测试3次取平均值，双冲式全冲和半冲各3次取平均值后按公式计算平均用水量。

### 密封性测试

将产品进水端连接静水压试验台，缓慢升压至0.60±0.05MPa，保压60秒，观察产品各密封部位有无渗漏。

### 寿命测试

以每分钟10-15次的速度进行开关循环测试，累计20000次后检查产品功能是否正常，并重新测量流量，与初始值比较变化幅度。

### 材料安全性测试

与水接触部件按GB/T 17219进行卫生指标测试，浸泡液中有毒有害物质含量应符合生活饮用水输配水设备及防护材料卫生安全评价规范的要求。

## 检验规则

### 出厂检验

| 检验项目 | 检验方式 | 合格判定 |
|:---------|:---------|:---------|
| 流量/冲洗水量 | 逐批抽检 | 符合节水评价指标 |
| 密封性 | 逐个检验 | 0.60MPa下无渗漏 |
| 防滴漏 | 逐批抽检 | 关闭后30秒内无滴漏 |
| 外观质量 | 逐个检验 | 无缺陷 |

### 型式检验

型式检验在以下情况时进行：

1. 新产品定型或老产品转厂生产
2. 正式生产后结构、材料、工艺有较大改变
3. 正常生产每年不少于一次
4. 停产半年以上恢复生产
5. 出厂检验与上次型式检验有较大差异
6. 国家质量监督机构提出要求

型式检验包含标准全部技术要求。如有不合格项，加倍抽样复检，复检仍不合格则判定型式检验不合格。

## 常见问题解答

**Q1: GB/T 31436-2015是推荐性标准，是否可以不执行？**

A: GB/T 31436-2015为推荐性国家标准，法律上不强制执行。但该标准是节水型卫生洁具评价的基础标准，被广泛应用于CQC节水产品认证、绿色建筑评价、政府绿色采购等领域。如果企业产品需要申请节水认证或参与绿色采购，需要符合该标准要求。此外，绿色建筑评价标准（GB/T 50378）中也引用了该标准。

**Q2: 节水型卫生洁具与水效标识是什么关系？**

A: 两者密切相关但侧重点不同。水效标识制度依据各专项水效标准（如GB 25501、GB 25502等）评定产品水效等级，是市场准入管理手段。GB/T 31436是节水型产品的综合评价标准，其节水评价指标与各专项标准的节水评价值（2级水效）基本一致。产品达到GB/T 31436节水型要求，相当于达到各专项标准2级水效水平。

**Q3: 洁博利感应产品的节水率如何计算？节水率30%-60%是否有依据？**

A: 节水率按标准公式η=(Q₁-Q₂)/Q₁×100%计算。以感应水龙头为例，传统机械水嘴在0.30MPa下流量约9L/min，洁博利感应水嘴通过感应控制和流量调节器将流量控制在4-6L/min，节水率为33%-56%。以感应小便冲水器为例，传统手动冲洗阀单次冲水约4.5L，洁博利感应冲水器控制在1.5-2L，节水率为56%-67%。综合各类产品，节水率在30%-60%之间。

**Q4: 如何判断购买的卫生洁具是否属于节水型？**

A: 消费者可通过以下方式判断：1）查看产品是否粘贴水效标识，2级及以上为节水型；2）查看产品说明书中的流量/冲洗水量数据，与GB/T 31436中节水评价指标对比；3）查看产品是否通过CQC节水认证；4）查看产品是否在政府绿色采购清单中。洁博利感应产品均符合节水型卫生洁具标准要求，可提供相关检测报告。

**Q5: 非接触式感应产品相比传统产品有哪些节水优势？**

A: 非接触式感应产品的节水优势主要体现在三个方面：一是避免忘记关水导致的长流水浪费，感应离开即自动关水；二是精确控制出水时间和水量，避免过量用水；三是杜绝手动操作中的误触和重复冲洗。洁博利感应产品在此基础上还采用dTOF激光感应、双感应控制等先进技术，进一步提升了节水效果。
