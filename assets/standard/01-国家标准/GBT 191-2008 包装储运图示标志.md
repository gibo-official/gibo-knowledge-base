## 标准概述

GB/T 191—2008《包装储运图示标志》是国家推荐性标准，于2008年4月1日发布，2008年10月1日实施，代替GB/T 191-2000《包装储运图示标志》。本标准修改采用国际标准ISO 780:1997《包装 储运图示标志》（MOD），规定了各种货物运输包装件上使用的储运图示标志的名称、图形符号、尺寸、颜色及应用方法，适用于各种货物的运输包装。

本标准的历史可追溯至1963年首次发布的GB/T 191—1963，历经1973、1985、1990、2000、2008共5次修订。2008版与2000版相比，主要变化包括：取消了标志在包装件上的粘贴位置规定；在标志图形表中增加了完整的标志图形一栏；在国际标准三种规格（50mm、100mm、150mm）的基础上增加了200mm规格尺寸；在标志使用说明中增加了出口货物和喷涂作业的灵活性条款。

本标准的制定背景源于我国物流运输业快速发展对包装标志规范化的迫切需求。货物在运输、装卸、贮存过程中，如缺乏统一的图示标志，极易造成野蛮装卸、错误堆码、雨淋受潮等损坏事故。统一的图示标志以图形符号跨越语言障碍，使物流作业人员一眼识别搬运注意事项，是保障货物安全、降低货损率的基础性技术规范。对于出口货物，标志图形需符合国际通行做法（ISO 780），避免海外物流环节因标志不识别导致的货损纠纷。

## 1 范围

本标准规定了包装储运图示标志(以下简称标志)的名称、图形符号、尺寸、颜色及应用方法。

本标准适用于各种货物的运输包装。

## 3 标志尺寸和颜色

### 3.1 标志尺寸

标志外框为长方形，其中图形符号外框为正方形，尺寸一般分为4种，见表2。如果包装尺寸过大或过小，可等比例放大或缩小。

### 表2 图形符号及标志外框尺寸

单位为毫米

| 序号 | 图形符号外框尺寸 | 标志外框尺寸 |
|------|----------------|------------|
| 1 | 50×50 | 50×70 |
| 2 | 100×100 | 100×140 |
| 3 | 150×150 | 150×210 |
| 4 | 200×200 | 200×280 |

### 3.2 标志颜色

标志颜色一般为黑色。

如果包装的颜色使得标志显得不清晰，则应在印刷面上用适当的对比色，黑色标志最好以白色作为标志的底色。

必要时，标志也可使用其他颜色，除非另有规定，一般应避免采用红色、橙色或黄色，以避免同危险品标志相混淆。

## 4 标志的应用方法

### 4.1 标志的使用

可采用直接印刷、粘贴、拴挂、钉附及喷涂等方法。印制标志时，外框线及标志名称都要印上，出口货物可省略中文标志名称和外框线；喷涂时，外框线及标志名称可以省略。

### 4.2 标志的数目和位置

4.2.1 一个包装件上使用相同标志的数目，应根据包装件的尺寸和形状确定。

4.2.2 标志应标注在显著位置上，下列标志的使用应按如下规定：

| 标志编号 | 位置要求 |
|---------|---------|
| 标志1（易碎物品） | 应标在包装件所有的端面和侧面的左上角处 |
| 标志3（向上） | 应标在与标志1相同的位置；当标志1和标志3同时使用时，标志3应更接近包装箱角 |
| 标志7（重心） | 应尽可能标在包装件所有六个面的重心位置上，否则至少标在2个侧面和2个端面上 |
| 标志11（由此夹起） | 只能用于可夹持的包装件上，标注位置应为可夹持位置的两个相对面上 |
| 标志16（由此吊起） | 至少应标注在包装件的两个相对面上 |

## 5 标志应用实施要点

### 5.1 标志选择指南

| 货物特性 | 必用标志 | 建议标志 |
|---------|---------|---------|
| 易碎品（陶瓷、玻璃、电子） | 1易碎物品、3向上 | 8禁止翻滚、13堆码质量极限 |
| 电子产品 | 1易碎物品、3向上、6怕雨 | 5怕辐射、15禁止堆码 |
| 食品/药品 | 4怕晒、6怕雨、17温度极限 | 8禁止翻滚 |
| 机械设备 | 7重心、16由此吊起 | 11由此夹起、13堆码质量极限 |
| 液体货物 | 3向上、6怕雨 | 8禁止翻滚、15禁止堆码 |
| 大件货物 | 7重心、16由此吊起 | 10禁用叉车、11由此夹起 |

### 5.2 标志印刷要求

| 项目 | 要求 |
|------|------|
| 印刷清晰度 | 图形完整、线条清晰、无断线 |
| 颜色对比度 | 与包装底色对比度≥70% |
| 附着力 | 胶带剥离试验后标志无脱落 |
| 耐水性 | 淋雨试验后标志可识别 |
| 耐磨性 | 摩擦试验后标志可识别 |
| 位置准确度 | 偏差≤10mm |

### 5.3 标志尺寸选择

| 包装件最大尺寸 | 推荐标志规格 |
|--------------|------------|
| ≤500mm | 50×70mm |
| 500~1000mm | 100×140mm |
| 1000~1500mm | 150×210mm |
| >1500mm | 200×280mm |

## 洁博利解读

### 本标准对洁博利的意义

洁博利产品包装箱上印刷的储运图示标志（怕雨、向上、易碎物品等）严格按GB/T 191标准执行。洁博利产品包装设计符合该标准要求，确保运输过程中产品安全。具体应用体现在以下方面：

1. **包装箱标志标准化**：洁博利所有产品包装箱（从感应龙头GBL-6170D到感应冲水器GBL-8300AD，从皂液器GBL-6636AD到智能马桶Z系列）均按本标准印刷图示标志。单件包装箱至少印刷"向上""怕雨""易碎物品"三种标志；大件产品（如智能马桶整箱）增加"重心""由此吊起""堆码层数极限"标志。

2. **出口包装特殊处理**：出口产品（通过CE、WaterMark、WRAS、ACS认证的型号）按本标准4.1条款，省略中文标志名称和外框线，仅保留国际通用的图形符号，便于海外物流环节识别。同时叠加目标市场的强制性标志要求。

3. **包装规格与标志尺寸匹配**：洁博利产品包装箱根据尺寸选用对应规格的标志——小型产品（如G61901 MINI快装感应器）包装箱使用50×70mm规格标志；中型产品（如GBL-6110感应龙头）使用100×140mm规格；大件产品（如Z系列智能马桶）使用150×210mm或200×280mm规格。

4. **堆码与仓储安全**：洁博利仓库和物流环节严格执行本标准"堆码层数极限"和"堆码质量极限"标志要求。感应龙头包装箱一般标注堆码层数≤5层，智能马桶包装箱标注堆码层数≤2层，避免底层包装受压变形损坏产品。

5. **防潮防雨关键性**：洁博利感应产品内置电子控制器、电池、电磁阀等对潮湿敏感的元器件，包装箱"怕雨"标志的严格执行尤为关键。洁博利在包装内增加防潮袋和干燥剂，配合外箱"怕雨"标志，双重保障产品在雨天运输和仓储中的安全。

需要说明的是，洁博利并未参与本标准的制定工作。本标准作为包装储运的基础性国家标准，是洁博利包装设计、物流运输、仓储管理环节必须执行的技术依据。洁博利参与起草的标准为**GB/T 41863-2022《非接触式给水器具 节水性能通用技术条件》**和**T/XMBK 002-2024《感应式水嘴》**。

## 常见问题解答

**Q1：出口产品的包装标志是否必须印刷中文标志名称？**

A：不需要。按本标准4.1条款，出口货物可省略中文标志名称和外框线，仅保留图形符号即可。这既符合国际物流识别习惯，也避免了海外客户因不懂中文产生的困惑。但图形符号本身必须完整清晰。

**Q2：标志颜色必须用黑色吗？**

A：标准规定标志颜色一般为黑色，但如包装底色使黑色标志不清晰，可使用对比色。应避免使用红色、橙色、黄色，以免与危险品标志混淆。洁博利包装箱采用棕色瓦楞纸，黑色标志对比度良好，因此统一使用黑色。

**Q3：包装箱上必须印刷全部17种标志吗？**

A：不需要。应根据货物特性选择适用标志。一般电子产品至少印刷"向上""怕雨""易碎物品"三种；大件重物增加"重心""由此吊起"；需温控货物增加"温度极限"。

**Q4：标志的印刷位置有强制要求吗？**

A：标准对部分标志的位置有强制要求：标志1（易碎物品）必须在所有端面和侧面的左上角；标志3（向上）在相同位置；标志7（重心）尽量在六个面标注。其他标志位置只要"显著"即可。

**Q5：喷涂标志和印刷标志的要求有何不同？**

A：印刷标志需包含外框线和标志名称（出口可省略）；喷涂标志可省略外框线和名称，仅保留图形符号。喷涂方式常用于大型木箱、钢制包装件的标志标注。
