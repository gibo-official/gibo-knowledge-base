## 不锈钢水龙头

## 1 范围

本标准规定了不锈钢水龙头(以下简称水龙头)的术语和定义、分类及命名、配套装置、要求、试验方法、检验规则、标志、包装、运输和贮存。

本标准适用于安装在建筑物内的冷、热水供水管路末端，工作压力（静压)不大于1.0MPa，介质温度为4℃～90℃的各类水龙头。

## 3 术语和定义

下列术语和定义适用于本文件。

## 3.1

## 不锈钢水龙头 stainless steel faucet

主体及外露金属零部件的基体为不锈钢，以陶瓷片、橡胶件、金属片等为密封元件，利用密封元件的相对运动实现通水、关断及调节出水口流量和/或温度的一种终端装置。

## 3.2

## 主体 body

水龙头中用于装配阀芯或其他控制元件的零(部)件。

## 3.3

## 单柄 single handle

由一个手柄或手轮控制流量或兼有出水温度。

## 3.4

## 双柄 double handles

由两个手柄或手轮控制流量及出水温度。

## 3.5

## 单控 single pipeline

水龙头控制一路(冷水或热水)供水管路。

## 3.6

## 双控 double pipelines

水龙头控制两路(冷水、热水)供水管路。

## 3.7

## 流量调节器 flow rate regulator

安装在水龙头进/出水管路中，能够改变水龙头流量的装置。

## 3.8

## 阀芯上游 upstream of obturator

水龙头自进水口至阀芯之间的部分。

## 3.9

## 阀芯下游 downstream of obturator

水龙头自阀芯至出水口之间的部分。

## 4 分类及命名

## 4.1 分类

4.1.1按启闭控制方式分为单柄、双柄、感应、延时自闭等。

4.1.2 按控制进水管路的数量分为单控水龙头和双控水龙头等。

4.1.3按用途分为厨房水龙头、洗面器水龙头、浴缸(含浴缸/淋浴)水龙头、淋浴水龙头、妇洗器水龙头、普通洗涤水龙头、洗衣机水龙头、直饮水龙头等。

4.1.4按安装方式分为壁式明装水龙头、壁式暗装水龙头、台式明装水龙头和台式暗装水龙头等。

4.1.5 按流量分为普通型水龙头和节水型水龙头。

## 4.2 命名

产品的命名宜包含水龙头主体材料、启闭控制方式、水龙头控制的进水管路数量及用途。

示例：

主体材料为不锈钢、启闭控制方式为单柄、控制进水管路为双控、用途为厨房水龙头的产品可命名为：不锈钢单柄双控厨房水龙头。

## 5 配套装置

5.1 与淋浴水龙头和浴缸水龙头配套的花洒应符合 GB/T 23447 的规定。

5.2 与水龙头配套的软管应符合 GB/T 23448 的规定。

5.3 与水龙头配套的排水配件应符合JC/T 932的规定。

5.4与洗衣机水龙头配套使用的快速接头尺寸见附录A。

## 要求

## 6.1 材料

## 6.1.1 材料成分

水龙头使用的所有与饮用水直接接触的材料，不应对人体健康造成危害，不应对饮用水造成任何水质、外观、味觉、嗅觉等变化。

洗面器、厨房和直饮水龙头所使用的阀芯金属部分均应采用不锈钢材料，水龙头的不锈钢材料均应采用GB/T20878中牌号为06Cr19Ni10或采用性能不低于上述牌号的其他不锈钢材料。

水龙头所使用的其他材料应符合相应的国家、行业标准。

## 6.1.2 不锈钢原材料金相组织

按GB/T 6394要求，不锈钢金相晶粒度应达4.5级以上；按GB/T 10561要求，不锈钢铸件夹杂物应达到表1的要求。

## 6.2 外观

6.2.1水龙头表面应光滑，不应有明显的划伤、碰伤、粗砂纹、锐边、毛刺、针眼、夹渣等缺陷。

6.2.2 涂层表面组织细密、光滑、色泽均匀，不应有流挂、露底及明显的划伤、碰伤等缺陷。

6.2.3塑料件表面不应有明显的溢料、缩痕、翘曲、熔接痕等缺陷。

## 6.3 螺纹

6.3.1螺纹表面应光洁，不应有凹痕、烂牙等明显缺陷。

6.3.2 产品外接密封管螺纹应符合 GB/T 7306.1 或 GB/T 7306.2 的规定；产品外接非密封螺纹应符合GB/T 7307 的要求，其中外螺纹应不低于 GB/T 7307的 B级精度。

## 6.4 装配

6.4.1装配好的手柄或手轮动作应轻便、平稳、无卡阻。转换开关应提拉轻便、平稳、无卡阻，转换开关提拉部位与提拉杆件应连接牢固。水龙头旋转出水管应旋转轻便、无卡阻。

6.4.2冷、热水混合水龙头应有冷、热标记，标记与水龙头结合牢固。冷水标记用蓝色或字母“C”或“冷”字表示；热水标记用红色或字母“H”或“热”字表示。也可采用其他易于识别的标识标记冷、热水。双控水龙头控制装置水平排列时，冷水标记在右，热水标记在左，如图1所示；控制装置竖直排列时，冷水标记在下，热水标记在上，如图2所示。否则，应有明显的冷、热水标记。

## 6.5 尺寸

水龙头的尺寸应符合附录B规定。特殊型式与尺寸按供需双方合同规定。

## 6.6 强度

## 6.6.1 主体焊接强度

按照7.6.1试验后，焊接位置应无永久性变形，并应符合6.9.1和6.9.2的要求。

## 6.6.2 弯臂强度

除出水管外径≤12mm的直饮水龙头外，其他水龙头按照7.6.2试验后，永久变形量θ不超过7°。

## 6.7 重金属及污染物析出限量

厨房水龙头、直饮水龙头、洗面器水龙头铅析出统计值(Q)应不大于 $2 ~ \mu \mathrm { g / L }$ ，非铅元素的析出量应不大于 GB18145—2014中表1规定的限值。

## 6.8 电气特性(适用于感应水龙头)

## 6.8.1 电气安全和兼容性

交流供电的水龙头应符合GB/T14536.1—2008中Ⅱ类防触电控制器的要求；直流供电的水龙头应符合 GB/T 14536.1—2008 中Ⅲ类防触电控制器的要求。电磁兼容性应符合 GB 4343.1 和 GB/T 4343.2要求。

## 6.8.2 耐温性能

按7.8.2试验后，应符合6.8.1和6.9.2的要求。

## 6.8.3 防护等级

按7.8.3试验，应达到IPX4等级。试验后，应符合6.8.1和6.9.2的要求。

## 6.8.4 防潮湿性能

按7.8.4试验后，应符合6.8.1和6.9.2的要求。

## 7.9使用性能

## 7.9.1 抗水压机械性能试验

## 7.9.1.1 阀芯上游抗水压机械性能试验

将水龙头按使用状态安装在试验设备上，关闭阀芯，从进水口施加 $( 2 . 5 \pm 0 . 0 5 ) \mathrm { M P a }$ 的压力值，保压$( 6 0 \pm 5 ) \mathrm { s }$ ，检查水龙头阀芯上游任何零部件有无永久性变形或失效现象。

## 7.9.1.2 阀芯下游抗水压机械性能试验

将水龙头按使用状态安装在试验设备上，打开阀芯。对于出水口安装流量调节器的水龙头，在进水口施加 $( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的动压；对于出水口不带流量调节器的水龙头，在进水口处施加压力，施加的压力应使水龙头的流量达到 $( 2 4 \pm 2 . 4 ) \mathrm { L } / \mathrm { m i n }$ ，持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查水龙头阀芯下游任何零部件有无永久性变形现象。

## 7.9.2 密封性能试验

## 7.9.2.1 阀芯上游密封性能试验

将水龙头按使用状态安装在试验设备上，关闭阀芯，在水龙头进水口施加表3规定的压力，对于单柄双控混合水龙头，应转动手柄，在温度调节装置控制的整个范围内进行试验，保压 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查水龙头阀芯及上游过水通道有无渗漏现象。

## 7.9.2.2 阀芯下游密封性能试验

将水龙头按使用状态安装在试验设备上，打开阀芯。对于出水口能够被堵住的水龙头，人工堵住出水口，在水龙头进水口施加表3规定的压力，对于单柄双控混合水龙头，应转动手柄，在温度调节装置控制的整个范围内进行试验，保压 $( 6 0 \pm 5 ) \mathrm { s }$ ，减小压力至 $( 0 . 0 5 \pm 0 . 0 1 ) \mathrm { M P a }$ ，并保压 $( 6 0 \pm 5 ) \mathrm { s } ;$ 对于出水口不能被堵住的水龙头，出水口呈开启状态，在进水口处施加压力，施加的压力应使水龙头的流量达到$( 2 4 \pm 2 . 4 ) \mathrm { L } / \mathrm { m i n }$ ,持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查阀芯下游的所有密封部位有无渗漏现象。

## 7.9.2.3 手动转换开关密封性能试验

## 7.9.2.3.1 浴缸与淋浴手动转换开关密封性能试验

将水龙头按使用状态安装在试验设备上，将转换开关调至水流至浴缸的位置，人工堵住水龙头流向浴缸的出口，淋浴出口为开启状态，在水龙头进水口施加 $( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，逐渐减小压力到 $( 0 . 0 5 \pm 0 . 0 1 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查淋浴出水口有无渗漏现象。再将转换开关调至水流至淋浴的位置，人工堵住水龙头的淋浴出水口，浴缸出水口为开启状态，水龙头进水口施加$( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s } ;$ 逐渐减小压力到 $( 0 . 0 5 \pm 0 . 0 1 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ 检查浴缸出水口有无渗漏现象。

对多个淋浴出水口的水龙头应分别测试每个出水位置。

## 7.9.2.3.2 顶喷花洒与手持花洒转换开关密封性能试验

将水龙头按使用状态安装在试验设备上，将转换开关调至水流至淋浴的位置，并将顶喷花洒与手持花洒转换开关调至顶喷花洒模式，人工堵住水龙头上连接顶喷花洒的出水口，连接手持花洒的出水口为开启状态，从水龙头进水口施加 $( 0 . 4 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，逐渐减小压力到 $( 0 . 0 5 \pm 0 . 0 1 )$ $\mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查水龙头连接手持花洒的出水口有无渗漏现象。再将转换开关调至手持花洒模式，人工堵住水龙头连接手持花洒的出水口，连接顶喷花洒的出水口为开启状态，水龙头进水口施加 $( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的静压并持续 $( 6 0 \pm 5 ) \mathrm { s } ;$ 逐渐减小压力到 $( 0 . 0 5 \pm 0 . 0 1 ) \mathrm { M P a }$ 的静压并持续$( 6 0 \pm 5 ) \mathrm { s }$ ，检查水龙头上连接顶喷花洒的出水口有无渗漏现象。

## 7.9.2.3.3 抽取式厨房花洒转换开关密封性能试验

将水龙头按使用状态安装在试验设备上，将转换开关调至水流至汽泡水的位置，从水龙头进水口施加 $( 0 . 0 5 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的动压，持续 $( 3 0 0 \pm 1 0 ) \mathrm { s }$ ，检查花洒水位置是否有渗漏现象；将进水口动压调至$( 0 . 5 \pm 0 . 0 2 ) \mathrm { M P a }$ ,持续 $( 3 0 0 \pm 1 0 ) \mathrm { s }$ ，检查花洒水位置是否有渗漏现象。再将转换开关调至水流至花洒水的位置，从水龙头进水口施加 $( 0 . 0 5 \pm 0 . 0 2 ) \mathrm { M P a }$ 的动压，持续 $( 3 0 0 \pm 1 0 ) \mathrm { s }$ ，检查汽泡水位置是否有渗漏现象；将进水口动压调至 $( 0 . 5 \pm 0 . 0 2 ) \mathrm { M P a }$ ,持续 $( 3 0 0 \pm 1 0 ) \mathrm { s }$ ，检查汽泡水位置是否有渗漏现象。

## 7.9.2.4 浴缸与淋浴自动复位转换开关密封性能试验

将水龙头按使用状态安装在试验设备上，在淋浴出水口位置安装一个流量为9L/min（压力为$0 . 1 \ \mathrm { M P a }$ 时)的液阻，将转换开关放至水流至浴缸的位置，浴缸出水口及淋浴出水口均为开启状态，从水龙头进水口施加 $( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的动压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查淋浴出水口有无渗漏现象。

将转换开关放至水流至淋浴的位置，浴缸出水口及淋浴出水口均为开启状态，从水龙头进水口施加$( 0 . 4 \pm 0 . 0 2 ) \mathrm { M P a }$ 的动压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查浴缸出水口有无渗漏现象。逐渐减小压力至 $( 0 . 0 5 \pm$ $0 . 0 1 ) \mathrm { M P a }$ 的压力并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查转换开关位置是否移动，浴缸出水口是否有渗漏；关闭水龙头阀芯，检查转换开关位置是否自动复位到浴缸位置。

重新打开水龙头阀芯，施加 $( 0 . 0 5 \pm 0 . 0 1 ) \mathrm { M P a }$ 的动压并持续 $( 6 0 \pm 5 ) \mathrm { s }$ ，检查淋浴出水口是否有渗漏现象。

## 7.9.2.5 冷、热水隔墙密封性能试验(适用于单柄双控水龙头)

连接水龙头的一个进水口到试验设备上，关闭阀芯，出水口为开启状态，水龙头进水口施加 $( 0 . 4 \pm$ $0 . 0 2 ) \mathrm { M P a }$ 的静压，保压 $( 6 0 \pm 5 ) \mathrm { s }$ ，在保压时间内移动水龙头手柄在其控制的整个温度范围内进行试验。检查出水口和另一未连接的进水口是否有渗漏现象。

按上述方法对另一进水口进行试验。

## 7.9.3 延时自闭时间(适用于延时自闭水龙头)

延时自闭水龙头按使用状态安装，用冷水进行试验，在进水口施加 $( 0 . 3 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的压力，开启水龙头，用秒表测定出水持续时间，重复试验3次，取其算术平均值。

## 7.9.4 操作力(适用于延时自闭水龙头)

在静水压 $( 0 . 3 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的条件下，使操作力持续施加于操作元件直至水龙头达到最大流量，用±2%精度的测力计测量操作力。

## 7.9.5 感应水龙头操作性能

## 7.9.5.1 控制距离误差

采用表面光洁的板材制作尺寸为 $3 0 0 \ \mathrm { m m } \times 3 0 0 \ \mathrm { m m }$ 、表面粘附 $_ { 7 0 \mathrm { ~ g ~ } }$ 复印木浆纸的模拟板代替人体对水龙头进行控制。

将水龙头按使用状态安装，接通水源和电源，使水龙头进入正常工作状态，模拟板在水龙头传感器接收的主轴方向做前后相对移动，同时在传感器前方30°圆锥内、模拟板后方2m内不应有面积超过$0 . 0 2 \mathrm { ~ m ~ } ^ { 2 }$ 的障碍物，且不应有直射强光和人员走动。模拟板以缓慢的速度由远及近接近水龙头，直到水龙头开始工作时停止移动，测量水龙头与模拟板之间的距离，并与产品说明书规定的控制距离比较。

## 7.9.5.2 开启时间和关闭时间

将7.9.5.1所述模拟板迅速置于水龙头控制距离内，同时启动计时器，观察并记录水龙头的出水时间间隔，即为开启时间；将模拟板从水龙头控制距离内迅速撤离，同时启动计时器，观察并记录水龙头的断水时间间隔，即为关闭时间。分别做3次测试取其算术平均值。

## 7.9.5.3 整机能耗

交流供电的感应水龙头按使用要求接通电源、水源，在电源输入端串接电流表，并接电压表，分别测量出感应水龙头待机和工作时的电流和电压值，计算其乘积。

直流供电的感应水龙头按使用要求接通电源、水源，在电源输入端串接电流表，并接电压表，测量出感应水龙头待机时的电流和电压值，计算其乘积，测量5次，取平均值。

## 7.9.6 断电保护

## 7.9.6.1 采用电源供电

用冷水进行试验，在 $( 0 . 3 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的动压下切断电源，检查水龙头是否能够保持关闭。

## 7.9.6.2 采用电池组供电

用冷水进行试验，施以 $( 0 . 3 { \pm } 0 . 0 2 ) \mathrm { M P a }$ 的动压，调节电压至电池组额定电压的90%开始试验（电池组可用可调节电压装置替换）。启动检测系统，水龙头关闭后立即以0.1V的梯度逐渐降低电压，每隔10s以降低后的电压再次启动检测系统，重复以上过程，直至水龙头不再工作为止。

## 7.9.7 水力学性能试验

## 7.9.7.1 流量

水龙头按使用状态连接在附录D所示的试验装置上。与水龙头连接的供水软管应无折曲。将水龙头手柄按以下位置开启，保证冷水管路水温为 $1 0 \ { } ^ { \circ } \mathrm { C } \sim 1 5 \ { } ^ { \circ } \mathrm { C }$ ，压力为 $( 0 . 1 { \pm } 0 . 0 1 ) \mathrm { M P a }$ ，热水管路水温为 $6 0 \ { } ^ { \circ } \mathrm { C } \sim 6 5 \ { } ^ { \circ } \mathrm { C }$ ，压力为(0.1±0.01)MPa，冷、热水温度变化不超过±1℃。

各类水龙头的流量测试方法如下。

a）单柄单控水龙头：将水龙头连接在冷水管路上，将手柄开启至流量最大位置，水流稳定时记录流量。

b）双柄双控水龙头：将水龙头两个进水口分别连接在冷、热水管路上，分别测量冷、热水单独开启至最大及冷热水同时开启至最大时混合水的流量，取最小值。

c）单柄双控水龙头：将水龙头两个进水口分别连接在冷、热水管路上，手柄开启至流量最大，在整个温度控制范围内移动手柄，从冷水全开位置移到热水全开位置，再从热水全开位置移到冷水全开位置，在水龙头出水温度为全冷、 $3 4 ^ { \circ } \mathrm { C } \ . 3 8 ^ { \circ } \mathrm { C } \ . 4 4 ^ { \circ } \mathrm { C }$ 、全热5个位置时，记录每个位置的流量；浴缸/淋浴水龙头浴缸位全热或全冷位置流量，取冷水全开位置和热水全开位置流量的最小值：混合水位置流量，取34℃、38℃、44℃三个温度中的最小值：其他水龙头流量取5个位置的最小值。

d)带多个花洒的浴缸水龙头和淋浴水龙头：分别测试每个花洒位的流量。单个花洒有多种出水方式时，分别测试每种出水方式的流量，取其中的最大值。

e)抽取式厨房花洒有多种出水方式时，分别测试每种出水方式的流量，取其中的最大值。

f)延时自闭水龙头：水龙头按使用状态安装，在进水口施加规定的压力，打开水龙头，运行5个循环，再次打开水龙头测量其流量，并记录最大值。

g) 感应水龙头：将水龙头连接在冷水管路上。水龙头处于开启状态，调节水压至规定压力值，记录流量值，重复试验3次，取其算术平均值作为该水龙头的流量值。

## C.1 原理

用含碳酸氢钠和次氯酸钠的模拟自来水浸泡水龙头内表面与水接触部分，用满足测试要求的仪器设备测定浸泡液中的重金属及污染物。测得的浓度值经标准化处理后再经过数据运算和标准要求比较。

## C.2 样品

## C.3 试剂

C.3.1 蒸馏水或去离子水(简称纯水)，电导率小于或等于0.10 $\mu \mathrm { S / c m }$ 0

C.3.2次氯酸钠溶液(分析纯，有效氯含量不少于5%)。

C.3.4 浓硝酸(优级纯)。
