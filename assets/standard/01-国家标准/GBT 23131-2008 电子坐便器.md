## 前 言

本标准附录A为规范性附录、附录B为资料性附录。

本标准由中国轻工业联合会提出。

本标准主要起草单位：中国家用电器研究院、国家家用电器质量监督检验中心、洁利来(福建)感应设备有限公司。

本标准由全国家用电器标准化技术委员会(SAC/TC 46)归口。

本标准主要起草人：鲁建国、赵维波、王仁、朱焰、孙鹏。

## 电子坐便器

## 1 范围

本标准规定了电子坐便器的术语和定义、产品分类、技术要求、试验方法、检验规则、标志、包装、运输和贮存。

本标准适用于在家庭、商店、学校等场所，由非专业人员使用的电驱动坐便器。

本标准不适用于模制式、包装式、冷冻式以及真空式坐便器，也不适用于与电子坐便器配合使用的冲水水箱部分。

## 3 术语和定义

下列术语和定义适用于本标准。

## 3.1

电子坐便器electronical toilets

指安装在陶瓷或塑料等坐便基座上的由电子电路控制的包括用于清洗人体臀部等冲洗装置在内的器具。该器具至少具有人体臀部和女性下体的温水冲洗功能，可相应增加臀部干燥、坐垫加温以及环境除臭等辅助功能。

## 3.2

贮热式电子坐便器 electronical toilets for storage water heaters带有加温水箱，依靠电热元件加温和保温水箱内冲洗用水的器具。

## 3.3

快热式电子坐便器 electronical toilets for instantaneous water heaters

无加温水箱，由大功率电热元件直接加温冲洗水流等的器具。

## 3.4

模拟负载 analogue load

指模拟人体臀部的可安装涂抹模拟人体排泄物的负载。

## 5.8 结构

5.8.1电子坐便器由机件坐盖、保温坐垫和控制开关、供水组件和加温水箱（适用于贮热式）、冲洗装置、干燥装置、除臭装置、操作面板、控制电路以及各种保护装置等组成。

5.8.2 器具中的紧固件及其他零部件应符合相关的国家标准的规定，其易损件应便于更换。

5.8.3 器具与人体接触的表面应光滑，正常使用时，不应刮伤人体皮肤。

5.8.4 器具在正常工作状态下，当人体臀部压在坐垫上后，冲洗温水不应喷到机体外面。

5.8.5器具在正常工作状态下，应防止各种热源烫伤人体皮肤。

5.8.6 供水组件和加温水箱不允许渗漏。

## 5.9 材料

5.9.1钢铁件(不锈钢除外)表面应进行防锈蚀处理，如采用电镀、涂漆等有效的防锈蚀处理。

5.9.2电镀件表面光滑细致、色泽均匀，不得有明显剥落、露底、花斑、擦伤和划伤等缺陷。

5.9.3塑料件表面应光滑、色泽均匀，不得有裂缝、气泡、缩孔、斑痕、擦伤和划伤等缺陷。

5.9.4涂漆件或涂塑件的涂饰表面必须光滑细致，色泽均匀，漆膜牢固，不得有明显皱纹、流痕、针孔、气泡等明显缺陷。

## 6.7 整机寿命试验

器具在正常工作状态下，选择高温和人体后部强力冲洗挡位，用模拟负载(见附录B)，以喷嘴喷水5min(或按制造商规定的程序时间)为一个工作周期。试验中向保温坐垫施加900N的力，模拟负载进行上下运动时，运行速度为0.05m/s。每两个工作周期之间停歇不超过10min，试验后，整机寿命应符合5.7的规定。

## 6.8 结构及材料检查

通过视检电子坐便器的结构及材料，确定是否符合5.8\~5.9的规定，必要时通过手工测试。

## 6.9 电镀件盐雾试验

电镀件按GB/T 2423.17规定的24 h盐雾试验后，应符合5.9的规定。

## 8标志、包装、运输和贮存

## 8.1 标志和说明书

8.1.1 电子坐便器的标志应符合GB 4706.1 和 GB 4706.53 中相应条款要求。

8.1.2 电子坐便器使用说明书的编写应符合 GB 5296.2 的要求及 GB 4706.1 和 GB 4706.53 中相应条款要求。

## 8.1.3 包装箱标志

电子坐便器包装箱标志应符合 GB/T 191 和 GB /T 1019—2008 中相关要求。

## 8.2 包装

8.2.1 每台电子坐便器的包装应按照GB/T1019—2008中规定的流通条件2的防潮包装、防震包装进行包装箱设计。

8.2.2 每台电子坐便器的包装箱内应附有产品合格证、使用说明书、保修卡，放在箱内明显部位。

8.2.3 产品的包装箱应经受GB/T1019—2008相关要求，按流通条件2进行试验。

## 8.3 运输

产品在运输过程中，严禁雨淋，受潮和剧烈碰撞。

具体产品运输环境条件可由制造厂按产地至销售地区在运输过程中可能经受的环境条件，参照GB/T 4798.2规定的标准而定。

## 8.4 贮存

包装好的电子坐便器应贮存在常温，通风干燥，无腐蚀性气体的仓库内。

具体仓库的贮存条件应按贮存厂商所在地区气候环境而定，可参照GB/T4798.1规定的标准而定。

配料：以黄豆、小麦粉为原料的酿造黄豆酱。

## A.4 试验步骤

## A.4.1 试验前的准备

## A.4.1.1 耐水砂纸浸水的标识

在100 mm×20 mm 对角线找出中心点。

## A.4.1.2 耐水砂纸的浸水

每次试验前，用经过剪裁的耐水砂纸放入装有水温为 $( 2 0 \pm 2 ) ^ { \circ } \mathrm { C }$ 后从容器中捞出且除去表面水珠。

## A.4.1.3 涂抹模拟人体排泄物

称量10g模拟人体排泄物，将其均匀的涂抹到浸过水的耐水砂上。

## A.4.1.4 人体排泄物的称重

将涂有10g模拟人体排泄物且浸过水的耐水砂纸用电子天平称重，其质量的实测值记录为 $W _ { 0 }$ 然后将其固定在模拟负载的安装位置上，具体安装方法详见附录B。

## A.4.1.5 人体排泄物的安装和调整

涂有模拟人体排泄物的耐水砂纸的中心点应尽量对准喷射水流的水头，试验前应确定其中心位置，具体方法是：将模拟负载落下，它的防水的橡胶垫圈与电子坐便器的坐垫紧密接触。

按下电子坐便器控制面板的人体后部强力冲洗按钮，再按下运行按钮，喷嘴喷出的水流喷到模拟负载的透明窗上，用此种方法确定涂有模拟人体排泄物的中心位置。如有偏差，可按上述方法重新进行调整，直到找到最佳喷水位置。

## A.4.2 试验过程

按A.4.1.5的安装要求将模拟负载落在电子坐便器的坐垫上，分别按下电子坐便器控制面板的高温挡按钮和人体后部的强力冲洗按钮，再按下运行按钮使器具运转5min(可按制造商规定的程序)，喷嘴喷出的水流冲洗耐水砂纸上的模拟人体排泄物，其最高水温不应超过 $4 5 \ \mathrm { ^ \circ C }$

器具停机后，升起模拟负载，将带有残留的模拟人体排泄物的耐水砂纸再次称其质量，将其质量的实测值记录为 $W _ { \mathrm { ~ l ~ } }$

按上述试验方法测试3次，试验时间间隔以每次将冲洗水流加热到最高水温为准，取3次试验算术平均值。

## A.5 清洁率计算

清洁率按式(A.1)计算：

$$
C = \frac { ( W _ { 0 } - W _ { 1 } ) } { 1 0 }\tag{}
$$

式中：

C——清洁率，%；

$W _ { 0 }$ —带有10g模拟人体排泄物的耐水砂纸质量，单位为克 ${ \bf \Xi } ( { \bf g } )$

$W _ { 1 }$ ——带有残留的模拟人体排泄物的耐水砂纸质量，单位为克 $( \mathfrak { g } )$
